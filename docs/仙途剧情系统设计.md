# 仙途剧情系统设计 —— 「一章一局」

> 目标：把 `docs/story` 里的章节梗概 / 剧情单元，落成**每一章对应一局可完结的游戏过程**。
> 关联：`docs/story/章节目录.md`、`docs/story/batches/`、`miniprogram/data/xianChapters.js`
> 更新日期：2026-10-14（**v5：全量 265 章 · 自研 Canvas 故事**）

### 动画产能（简单生成）

1. 写旁白 → 选 `scene` → 每句选 `fx`
2. 需要打斗：加 `{ kind:'fight', foe:'xxx', taps:4, text:'…', fx:'slash' }`
3. 枚举不够只加 CSS；重点章以后可挂 Lottie（本阶段不做）

```js
beats: [
  { text: '山边小村……', fx: 'mist' },
  { kind: 'fight', foe: '舞岩', taps: 4, text: '崖顶挑衅……', fx: 'slash' }
]
```

## 1. 内容生产流程

```
① 逐章梗概        docs/story/章节梗概-第01批.md + batches/batch_NN.md
        │
② 情节单元        每批「### 单元 X-Y《标题》」= 一局游戏
        │
③ 编译章节表      node docs/story/_tools/compile_chapters.js
        │         → data/xianChapters.js + docs/story/chapters_game_units.json
        ▼
④ 运行时          选章 → 开场文案 → 本局玩法 → 达成 win → 通关解锁下一章
```

**章节粒度**：不是原著 2211 章逐章一局，而是梗概里的**剧情单元**（45 批 × 约 5.9 单元 ≈ **265 局**，覆盖原著 seq 1–2211 全书无缺口）。

---

## 2. 一局流程

```
章节目录（showChapterPick）
      │  点选已解锁章
      ▼
开场叙事（showChapterIntro）  ← chapter.lines
      │  剧情章：读完即通关
      │  其它：点「入道」开战
      ▼
本局 canvas（沿用 zombie 战斗/打坐）
      │  按 chapter.win 判定
      ▼
通关（showChapterClear）→ 下一章 / 回目录
失败（over）→ 再试本章 / 回目录
```

本地键：`hyc_xian_chapters` = `{ cleared: string[], currentId }`

## 3. 章节数据结构（摘录）

```js
{
  id: '1_a',
  unitCode: '1-A',
  title: '山边小村',
  seq: '1-2',
  mode: 'cultivate',   // story|cultivate|trial|combat|wave|boss|scripted
  major: 'mortal',      // 开局境界大类
  win: { type: 'cultivate', lingQi: 60 },
  lines: ['……'],
  nextId: '1_b'
}
```

| mode | 本局玩法 | win |
|------|----------|-----|
| story | 只播文案 | 读完 |
| cultivate | 凡人打坐 | 灵气达标 |
| trial / combat / wave | 斩妖 | 本章击杀数 |
| boss | 强制境主 | 击败境主 |
| scripted | 剧情战 | 存活若干秒 |

运行时辅助：`data/xianChapterPlay.js`（选章列表、目标文案、`checkWin`）。

## 4. 接线位置（zombie）

| 点 | 作用 |
|----|------|
| `_bootXian` | 启动打开章节目录 |
| `_startChapter` / `_enterChapterBattle` | 开章与入战 |
| `_tickChapterSession` | 每帧检 win / boss 章刷境主 |
| `_registerKill` | 累计 `_chapterKills` |
| `_onBossDefeated` | boss 章通关短路 |
| `_updateMortalCultivate` | 打坐章灵气满通关 |
| `_gameOver` / `restart` | 失败再试本章 |

UI：`zombie.wxml` 选章 / 开场 / 通关层（全屏替换 canvas，遵守原生层限制）。

---

## 5. 如何加章 / 改章

1. 改 `docs/story/batches/batch_XX.md`（或第 01 批）里的「单元」设计。
2. 运行：`node docs/story/_tools/compile_chapters.js`
3. 重新预览小程序。无需改 `zombie.js`（除非新 mode）。
