## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 11-A《内殿开启》（seq 471–475）｜触发：`enterMajor = jindan` 且持有[虚天残图]
- **叙事**：幻境考验（亲手斩杀"小妹"幻影）→ 迷宫式内殿 → 傀儡守卫 → 寒骊台。基调：幽暗、机变、步步惊心。
- **玩法**：把内殿一层做成**迷宫探索 + 清障关**——青石通道随机分岔，十字路口触发**狼首傀儡 / 蛇卫傀儡**战（复用挥剑斩杀机制，加"青铜戈/软鞭"两个连招弱点）。二层提升难度：**禁制陷阱**以地面裂缝/寒霜提示，误踩扣血。
- **奖励**：击败傀儡掉落**傀儡残片**（可研究、用于后期"傀儡"系统解锁）；拾取**狼首傀儡核心**作纪念。通道后墙的"青石夹层"做成**隐藏交互点**（敲击音效差异提示）。
- **触发钩子**：只在**结丹期首次进入内殿**时加载；未持有的玩家看不到夹层。

### 单元 11-B《虚天鼎·正魔夺宝》（seq 476–486）｜触发：单元 11-A 完成
- **叙事**：本批最高潮之一。金丝蚕失败 → 血玉蜘蛛取宝 → 正魔元婴混战 → 古宝四散争夺 → 补天丹出世 → 元婴出窍强夺。节奏密集、法宝横飞。
- **玩法**：做成**观战式动态战场 + 取宝小游戏**：
  1. **取宝阶段**——玩家操控血玉蜘蛛向深洞喷网拖拽虚天鼎（拉锯式进度条：力量与"狂暴"状态成反比，狂暴越高越快但结局越惨）；
  2. **混战阶段**——明面是元婴老怪斗法，玩家做的是**在夹缝里抢古宝**：在飞散的光华中及时出手收物（限时点击/走位判定）；
  3. **夺丹阶段**——补天丹飞出，全屏"抢丹"演出，玩家只需在元婴混战中**求生**（血玉蜘蛛必被斩，触发剧情杀）。
- **技能绑定**：本单元入手多件古宝——**五行环**（禁锢同阶，对异灵根/高修为者无效——做成"技能条件"设定）、**花篮古宝**（收摄对方法宝）、**狼首玉如意**（护罩 + 召唤器灵）。
- **奖励/伏笔**：必得的**皇鳞甲**做成"贴身被动护甲"，并在剧情中挡下一次致命偷袭（相当于一次性免死）。补天丹此段**留白不揭真效**。
- **技术约束（沿用）**：`type=2d` 原生 canvas 会盖住 view，元婴混战等剧情必须走 **wxml 顶层 `wx:if/elif` 全屏替换**，不能浮在 canvas 上。

### 单元 11-C《玄骨夺鼎·修罗圣火》（seq 487–493）｜触发：单元 11-B 完成、`bossDefeated: 结丹期`
- **叙事**：看似绝境的翻盘——玄骨交易诱饵 → 乌丑横死 → 收鼎 → 圣火反噬灭玄骨 → 收乾蓝珠 → 灭残魂、除暗记、得逃生图。基调：阴谋、反噬、冷静收尾。
- **玩法**：**双阶段 Boss 战（对玄骨）**：
  1. **拉鼎阶段**——按玄骨指示以两只蜘蛛升鼎，玩家需在**冰封扩散**中移动躲避（蓝冰判定即死）；
  2. **斗法阶段**——玄骨融合出"修罗圣火"（灰白火），玩家以**辟邪神雷护网**抵挡并向其灌注神雷；关键是**不要耗尽**——当圣火压制到达峰值时立即**破网位移**（对应韩立"拼尽神雷逃出"），随后触发玄骨**圣火反噬自爆**的剧情杀，玩家以青元剑芒**封路**结束战斗。
- **技能绑定**：本单元正式入手**辟邪神雷**（对鬼道系敌人克制，但**有次数限制**，用光需静养恢复——做成资源条）；战后得到**乾蓝珠**（暂不可炼化，标为"高境界解锁"，为后续魔火线埋线）。
- **道具/线索**：**白玉肋骨**（本批内不揭，留到 11-F 单元解锁《玄阴经》）；**内殿逃生画轴**作为下一单元的通行道具。

### 单元 11-D《元瑶·养魂木·脱殿》（seq 494–497）｜触发：单元 11-C 完成
- **叙事**：喘息段——撞见元瑶出浴、灵眼之泉、万年灵乳换养魂木，二人合力破阵出殿；回程借机摸清玉如意器灵、整理战利品。基调：香艳而不失分寸、松一口气。
- **玩法**：做成**协作解谜关 + 经营缓冲**：
  1. **破阵**——与元瑶分工，玩家负责阵眼判位（元瑶给"破阵心得"作提示），限时完成；
  2. **养魂木获取**——按约定只取根须（可选"守约取根须 / 违约抢主干"，影响元瑶好感，不影响主线通关）。
- **机制绑定**：入手的**万年灵乳**做成**恢复型消耗品**（一口回满法力，数量有限）；**养魂木根须**用于后期"养魂/神识"成长线。
- **器灵系统**：**狼首玉如意**在此正式展开——黄狼（土/含土遁）、红狼（火）、银狼（主器灵，暂不可控，标"桀骜/未炼化"），给玩家一个可长期培养的召唤位。
- **触发钩子**："五色小珠与补天丹同源"的疑点在此埋线，衔接后续 11-F 单元。

- **叙事**：世界级变局——星宫发"天星令"、正魔联手立"逆星盟"，南明岛陷落、封城盘查、韩立偷渡外星海。基调：乱世、低调、步步为营。
- **玩法**：做成**潜行 + 身份伪装 + 硬闯**的组合段：

  3. **击杀同阶**——守住于护法的条件，与**两名逆星盟结丹修士**做一场**小型 Boss 战**（五行环禁锢 + 花篮夺宝 + 青竹蜂云剑连击，示范"法宝流"打法）；

### 单元 11-F《外星海·奇渊岛》（seq 510–520）｜触发：单元 11-E 完成、进入外星海
- **叙事**：新地图立府——黑石城的灰色繁华与畸俗、寸金阁访药、雾中岛立府、虫室培育、重铸飞剑、目睹化形雷劫与毒蛟混战。基调：野蛮生长、以险换利。
- **玩法**：做成**开放式"立府 + 育虫 + 炼制"经营段**：
  1. **黑石城**作为外星海**中枢安全区**（禁斗法、可拍卖/买卖），开设"鉴宝→竞宝"小玩法（妖卵、炉鼎、原料三类商品，其中**女修炉鼎**做纯叙事呈现，不作可获取道具，避免导向问题）；
  2. **雾中岛立府**——以**幻阵 + 雾阵**隐藏洞府（潜行躲侦查的小玩法：以"雾效覆盖度"判定是否被过路修士发现）；
  3. **虫室经营**——三线培育：噬金虫（吞噬铁火蚁 → **变异新型噬金虫**，威力大增）、血玉蜘蛛、金丝蚕（喂霓裳草探催卵，本批结局为死卵）、啼魂兽；
  4. **重炼飞剑**——以炼晶重铸七十二柄青竹蜂云剑（长线 A 类强化，消耗万年灵乳维持，做成"炼制进度 + 中断即失败"的限时挑战）。
- **技能/道具绑定**：**《玄阴经》**在此解锁（获得"天都尸火弱点"情报，用于克制极阴系敌人；并开放数种结丹期可修的魔道秘术）；**五色珠**炼化后给予"吸纳灵气/转化灵力速度微增"的**永久小加成**（呼应补天丹"洗炼灵根"）。
- **事件钩子**：**化形雷劫 + 毒蛟之战**作为过场演出，正式引出"乱星海妖修之战"的世界线，作为下一批（seq 521+）的**大事件预告**。
