- **对应原著**：seq 1071–1120（原章号 1071–1120，"北冥冰岛·虚灵殿篇"）

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发，本批整体归属 `yuanying 元婴` 大境界。

### 单元 23-A《极北闭关》（seq 1071–1074）｜触发：`enterMajor = yuanying` 后首次进入"休整期"
- **叙事**：昆吾山风头未过，韩立远遁霜郡，强占灵山、闭关炼宝、强收魔头——一段"埋头经营"的过渡弧。
- **玩法**：把"闭关"做成**据点经营**——玩家布阵护山（阵旗 + 灵虫守备，抵挡随机来访的散修）、挂机炼化"培婴丹"推进度条（对应打坐吸灵气的长时段收益）。
- **奖励**：培婴丹炼化 = **元婴数值成长**（法力上限 / 元婴体外活动时长 +5%）。
- **召唤物落地**：五子同心魔作为**首个可招募的魔道召唤单位**，走"喂精血维持"的特殊资源循环（对应已锁定状态：需定期投入资源，否则反噬掉血），与既有傀儡/召唤体系并存。
- **小事件**：来访修士闯阵 → 轻量防守战（不用玩家操作也可以自动结算，避免打断经营节奏）。

### 单元 23-B《北冥冰岛》（seq 1075–1086）｜触发：新地图「北冥岛」解锁
- **叙事**：定元牌引路、冰城初见、雪猿让道、冰灵果待客、金风狸引见大长老——一次信息量密集的**新地域探索**。
- **玩法**：**禁断大阵迷失**做成导航小游戏——神念方向随机偏移，须靠"定元牌"道具校正（道具限时一年、限购，制造轻度资源压力）。冰海一段做成**探索 + 收服**：遭遇雪吼兽（杂兵）与冰狞兽（可捕获精英），收服后入灵兽袋。
- **机制绑定**：新增"**寒焰**"属性线（紫罗极火），与既有火属性伤害区分，克制冰系敌人；"风离冰焰切磋"做成**技能展示关**（只比招式、不分生死）。
- **台词重点**：冰凤之约、十级妖修的概念首次登场，为单元 23-F 的 Boss 做铺垫。

### 单元 23-C《虚灵殿·玄玉洞》（seq 1087–1090）｜触发：单元 23-B 完成、寒骊上人邀约
- **叙事**：石门开启、祖师光影、千柱迷阵、玄玉洞现——本篇的**空间奇观段**，也是"虚天鼎"悬念的正面对撞。
- **玩法**：**冰魄寒烈阵**做成纯解谜关——持阵盘者走出安全通道，玩家须跟随阵旗引路、误触则受寒蚀（不掉血，扣 buff）。玄玉洞做成**资源采集关**：用"阴灵水（沉水）"落石化金取下万年玄玉，限时限量拾取。
- **悬念钩子**：祭坛正中那只鼎形图案 + 韩立的神色变化，作为**"虚天鼎与小极宫同源"的视觉伏笔**（本批不揭底）。
- **奖励**：万年玄玉（可嵌入本命法宝，附加冰寒属性伤害）——一件高价值、可长期使用的材料。

### 单元 23-D《群妖压境 · 冲阶化神》（seq 1091–1098）｜触发：`bossDefeated` 后进入"守城"事件
- **叙事**：岛外群妖两路夹击、镇海钟定海、万妖幡破阵，对内则是四人以寒焰替大长老洗髓冲关——**双线并行的攻防高潮**。
- **玩法**：外层做**守城波次防守**（低阶妖兽成波涌来，玩家/队友清剿，重现镇海钟的"一次性大招"设定）。内层做**护法关**：玩家操作光柱寒焰、维持洗髓进度，随波次升级而耗蓝加快（呼应"法阵加持但耗法倍增"）。
- **技能提示**：太阴真火在本段首次显露出"吞噬寒气"的特性，做成**寒焰的吸收/转化机制**。
- **叙事收口**：冲关失败（正史既定结果），以"光莲崩裂、跌落惨叫"的高反差演出收束，为下一单元的反目蓄势。
- **三个十级妖修**以**"登场即压迫"的过场 CG**呈现，暂不参战。

### 单元 23-E《玄玉洞反目 · 斗法》（seq 1099–1113）｜触发：单元 23-D 结束的**境主战**
- **叙事**：从"归还虚天鼎"的索命之言，到幻术、五魔、三焰扇、傀儡、剑阵的连环斗法，再到出洞遭遇入侵妖兽——**本批体量最大的多回合战段**。
- **玩法设计**：做**五阶段 Boss 战（寒骊上人）**——
  1. 破幻：在风雪幻术中识破隐形冰剑（考观察，明清灵目标记弱点）；
  2. 三线对攻：同时面对冰蛟、雷珠与双尾人面蝎，善用召唤单位分担；
  3. 破防：以三焰扇 + 傀儡绕后打出输出窗口；
  4. 禁婴：Boss 肉身被毁后转为"**头颅内元婴逃跑**"的追逐小关；
  5. 收焰：清扫全场残局。
- **奖励 / 技能绑定**：通关得**大庚剑阵**（陷阱类范围绞杀，可作为地图上的布置型技能）、**八灵尺（佛光，克制魔/鬼系）**、两团极寒之焰（可融入紫罗极火强化）。
- **后续小段**：出洞后接"**妖兽入侵**"的**连续小遭遇战**（每个房间一波，节奏短平快），以三目妖兽作为收尾精英，并掉落第三只妖目（侦察类道具）。

### 单元 23-F《万妖幡 · 冰凤 · 传送之战》（seq 1114–1120）｜触发：单元 23-E 通关、抵达虚灵殿主殿
- **叙事**：万妖幡领域、车老妖索宝、十级冰凤缠斗、鬼母现身、光晕罩阵——**本批的最高潮**，并以"被卷入未知传送"埋下下一批的入口。
- **玩法**：做**领域战 + 空间追逐 + 限时撤离**的复合关卡——
  - **万妖幡领域**：空间内妖气与火海互压，妖兽傀儡**无限重生**，玩家目标不是清场而是"破阵生存"；
  - **冰凤战**：对手会**撕开空间**瞬移，用光晕锁定玩家落点，逼玩家放弃硬拼、转而在奔走中调整站位（对应冰凤"断阵要挟"的机制）；
  - **传送之战**：终极目标是**在双 Boss 夹击下自行启动传送阵**——纯"抢时间"关，成功即脱离。
- **关键道具**：**破界符**（一次性的空间脱身道具）在本单元消耗，做成"稀有消耗品，用一次少一次"的紧张感。
- **伏笔收口**：虚天鼎在结尾**自行放威、护住大阵**，是"宝物来历"线的重大回收点——建议以特写镜头 + 静音处理，营造"它究竟要把我带去哪"的悬念，直接衔接下一批。
