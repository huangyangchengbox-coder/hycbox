## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批的关键是**一次"法力全失"的玩法重置**——把玩家从结丹后期打回"凡人手感"，靠武技与野兽本能生存，再逐步夺回力量。

### 单元 13-A《乱星海终战·金光神焰》（seq 571–575）｜触发：`jiedan` 后期境主战「温天仁」
- **叙事**：韩立压箱底的阴魔斩 vs 温天仁的化劫 / 六极真魔 / 八门金光镜 / 金光神焰，一场顶级法宝对轰；最后以"鬼雾"强行中止战斗——**玩家赢不了也输不掉，世界把两人一起掀翻**。
- **玩法**：**四阶段 Boss 战**——
  1. 对轰阶段：躲避"六极真魔"幻影的近身夺宝（对应已有"法宝被夺"可夺回机制）；
  2. 弹幕阶段：八门金光镜的**八次折射光柱**（每反射一次加粗一格，越晚躲越难）；
  3. 围杀阶段：金光神焰困阵——玩家在光罩内**读条抗耗**（血条换成"灵力条"，不吃伤害只掉灵力）；
  4. 绝境演出：鬼雾压场，全场清屏，进入 13-B。
- **奖励/技能绑定**：斩落敌臂的**"阴魔斩"**作为一次性爆发技入库（CD 极长、耗精元）；通关得法宝碎片（避风/辟火珠等）。
- **触发钩子**：`bossDefeated` 前置条件为持有 **辟邪神雷**——此战是"金雷竹克魔"这一机制的**首次教学式高光**。
- **表现层提示**：本单元结束必须做一次**状态强制重置动画**（翅膀熄灭、法宝落地、UI 变灰）。

### 单元 13-B《鬼雾·阴冥之地》（seq 576–589）｜触发：13-A 战后剧情，进入 `mortal-like 绝灵` 状态
- **叙事**：鬼雾吞人 → 随机传送 → 绝灵之下法力尽失 → 高墙村落的"另一个世界"。这里没有灵气，只有粗浅武技与阴冥之力；玩家从"修士"跌回"凡人"，并与梅凝结成临时同盟。
- **玩法**：**一套完整的"失力"关卡链**——
  1. **罗烟步保命关**：所有技能灰掉，只剩位移与轻功（跑酷式坠落/攀爬），呼应"无需法力的身法救主"；
  2. **村防战**：狡狰兽攻城，玩家上墙用长矛/弓箭协防（对应已有"妖怪来袭挥剑斩杀"的核心玩法，但换皮为**冷兵器+紫雾触手**的守城节奏关）；
  3. **探索/潜行关**：村内打探、石台研符、封天极之夜的**一次暗杀潜行**（噬金虫穿刺）。
- **机制绑定**：
  - 新增**"阴冥兽晶"资源**（击杀阴兽掉落，用于村内布阵/临时施法）；
  - 新增**"通灵之气"一次性法力条**（由梅凝渡给，可开启储物袋、召唤啼魂兽一次），作为**限时作战窗口**——用完了就真的用完了。
- **奖励**：**啼魂兽**在阴冥之地可吞噬阴魂取晶，是本地图的核心养成宠物；支线"寻兄"以**悲剧收束**（梅兄已死，只余遗物）。
- **情感设计**：单元收尾应冷冽——"修仙者被困成凡人"，为 13-C 的翻身蓄势。

### 单元 13-C《暴风山脱困·重返天南》（seq 590–595）｜触发：阴冥之地支线（寻兄 + 兽晶）完成
- **叙事**：啼魂兽在阴冥之地异变（吞魂化银猿）成为翻盘资本 → 攀登暴风山（阴风 / 冰崖 / 幻雾 / 飞行阴兽）→ 裂缝开启、三人遁出 → 无边海漫渡 → 重返天南。
- **玩法**：**三层递进的环境压力关**——
  1. **阴风层**：避风珠护罩为"体力资源"，寒冷持续掉血；
  2. **幻雾层**：视野受限，需靠啼魂兽探路；进入迷雾后触发**遭遇战**（瞬秒温天仁的"背刺判定"——设计成一个考验玩家绕后操意的精确刺杀机制）；
  3. **空战层**：上千飞行阴兽，啼魂兽化银猿开"威慑光环"（减速敌群），玩家用**十指兽筋控剑结网**（多目标自动索敌的割草关）守住到裂缝开启。
- **技能绑定**：啼魂兽**进阶银猿形态**（大招：吞噬范围内阴魂）；**风雷翅**在脱困演出中作为"救两人"的关键位移技。
- **过场**：无边海三四个月的飞行用一张"死海长航"插画交代（无岛、无妖、无风）。
- **剧情钩子**：紫灵、梅凝的分手戏（妾室提议 + 韩立拒绝 + 赠丹）作为**女性角色弧的收结点**，并留下"南宫婉"的思念线做长期伏笔。

### 单元 13-D《落云宗·药园蛰伏》（seq 596–602）｜触发：进入 `jiedan` 后期 → 假婴准备期
- **叙事**：伪装成炼气期散修混入落云宗，一路过关（幻术石阶、护派大阵、问心术），最后被分到天泉峰做外事弟子、看管药园——**外表是小人物，实则暗中开辟洞府、清理旧患**。
- **玩法**：**"隐姓埋名"经营/生活模拟段**——
  1. **入门考验**：幻术石阶（耐心条，硬闯会掉状态）、问心符（一次"谎言判定"小游戏，玩家的回答被判定真假）；
  2. **药园经营**：以掌天瓶绿液催熟药草 → 交租 → 换修炼时长（复用批 2 的"催药"循环，规模扩大）；
  3. **洞府开凿**：用飞剑在石山中自建洞府（轻量建造/摆阵法小游戏），布**拘灵阵**把灵气波动彻底藏住。
- **机制绑定**：新增**"隐匿修为"机制**（玩家面板显示假修为，战斗输出被限制在很低水平，泄漏太高会吸引高层注意 → 失败）；**九曲灵参**作为结婴前置材料妥善安置。
- **技能/道具**：**血影遁**（借精血瞬遁百里，一次使用损失血量上限，是逃命神技也是高风险技）；**鸣魂珠**炼化（赋予啼魂兽稳定控制权）。
- **世界观图鉴**：天南四大势力（魔道/正道/天道盟/九国盟）与幕兰法士长期对峙，作为批量入库的设定条目。

### 单元 13-E《雪云狐与银月器灵》（seq 603–614）｜触发：药园安定后随机事件「绿踪沼泽」
- **叙事**：一次"帮师兄抓狐狸"的小事，滚成**三个连续反转**——妖狐装死 → 尸魈骗局 → 器灵夺舍；最后收获本批最重要的长期同伴**银月**。
- **玩法**：**长线支线链 + 一场心理战式 Boss**——
  1. **捕狐小游戏**：布五行迷踪阵围捕（限定只有一次落阵机会；白狐会"装死"，玩家若贪心上前会被反伤）；
  2. **土遁追踪**：以玉如意土器灵小狼在山体中穿梭追猎（2D 潜行/追踪，撞开土层会惊走目标）；
  3. **尸魈陷阱关**：少妇（尸魈）一番"借宝送信"的糖衣——玩家需要**识破并做出正确的行为选择**（撕符递盒 = 失败/受重创；掷盒困敌 = 正确），是**剧情推理型关卡的首次尝试**；
  4. **夺舍演出战**：白狐 vs 银狼的灵魂争夺（双方各占半边身的**双色推条**表现），最终银狼胜出。
- **角色植入**：**银月**登场并转为青竹蜂云剑的**器灵**——建议做成**可互动副人格**（战斗中插话提醒、给出敌方弱点提示），人格基调：优雅外表 + 话多娇媚 + 深藏算计。
- **奖励/技能绑定**：**剑灵觉醒**（青竹蜂云剑威力提升一档）；白狐形态作为**第二形态**可用于潜入/侦查；解锁"灵魂吞噬"图鉴条目（针对特定妖狐类敌人有克制效果）。
- **触发钩子**："点化器灵"需要**材料 + 一次耗时半日的仪式**（可做成一次基地内的多步小流程），完成后与 13-F 的峰主传音符衔接。

### 单元 13-F《试剑大会·宗内初试》（seq 615–620）｜触发：半年倒计时 / 「试剑大会」开启
- **叙事**：为**明清灵水**与**定灵丹**（结婴辅助 + 接近灵眼之树以取灵根）而参战；一边被同门看作"炼气十层的小透明"，一边用符箓与武技一路碾杀——**藏拙本身就是玩法**。
- **玩法**：**"藏拙比试"竞技关**——
  1. **海量符箓流**：可用"火弹符海"战术（一次性倾泻三四十张，输出高但消耗灵石/物资，形成经济取舍）；
  2. **武技判定流**：罗烟步瞬移绕后 + 一记手刀终结（把"境界不符的碾压"包装为**武技身法的精确操作**，而非显示修为）；
  3. **规则约束**：比试禁用致命手段，玩家被强制降级到"法器 + 符 + 身体"三件套，隐藏修为越高越需留手（做上限压制带来的张力）。
- **奖励**：宗内晋级资格 → 通往"三派试剑大会 / 前十洗目"的**下一批主线目标**；对手（天阳火脉的询通等）作为**败者立绘与怨念伏笔**。
- **触发钩子**：`试剑大会` 事件 = 本批收束点；下一批（seq 621+）应顺接**三派大会 + 明清灵水洗目 + 接近灵眼之树**。
- **人物线**：慕沛灵（冷艳师叔）与言姓修士（婚约纠缠）作为**宗内人际支线**开启；杜东（身怀阴寒之气、混入宗门的可疑之人）作为**长期悬念**留钩。
