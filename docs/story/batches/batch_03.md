# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 03 批

- **对应原著**：seq 71–120（原章号 71–120，"七玄门决战篇 → 嘉元城篇"）
- **游戏映射**：`lianqi 炼气（中后段，长春功第八层）`，处在**人界·凡俗江湖**与**低阶修仙**的交界
- **剧情弧**：神医救李长老 → 七玄门遭野狼帮突袭 → 死契血斗中韩立显威、夺剑符、焚金光上人与贾天龙 → 离山回村诀别亲情 → 赴嘉元城收服孙二狗 → 夜入墨府谋"暖阳宝玉" → 得知"升仙会"，定计夺帮
- **说明**：梗概均为原创改写，非原文摘录；本批为全书**首个凡人层面的大高潮**，也是韩立正式踏入修仙界的转折点

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。本批是玩家首次面对「会法术的敌人」，也是主角从「凡人」心态转向「修仙」心态的关键跃迁。

### 单元 3-A《神医与抽髓丸》（seq 71–74）｜触发：`lianqi` 升层 4→5 后
- **叙事**：李长老中毒垂危 → 韩立施诊拔毒（医者身份首秀）→ 溪边点破厉飞雨服抽髓丸之秘。基调"悬壶济世 + 江湖悲情"。
- **玩法**：新增轻量「**解毒**」小游戏——按提示顺序点击穴道、配比药粉（清灵散），成功则救活 NPC。可复用现有点击/拖拽交互。
- **技能绑定**：本单元解锁**御风决**（移动类法术）——在既有打坐/挥剑基础上加一条"疾行"能力，用于后续战场走位。
- **伏笔**：厉飞雨的"命不久矣"设成**支线倒计时**，为后期境界节点回调蓄势。

### 单元 3-B《法武并用·和谈》（seq 75）｜触发：单元 3-A 完成后
- **叙事**：以"闭关参悟"过场交代韩立把武学与法术结合，境界跃升。
- **玩法**：过关目标改为「**连携**」——同一波妖怪需先用火弹术烧、再用身法穿插近战，教导玩家"法武切换"操作。
- **机制**：火弹术可"只施一半"：长按不放则火球悬于掌心当兵器（近战附魔），松开则投掷（远程）。这是对现有技能的一次功能扩展。

### 单元 3-C《死契血斗》（seq 76–87）｜触发：`lianqi` 升层 6（或`bossDefeated` 首次失败重试点）
- **叙事**：谈判队伍被连珠弩伏击全灭 → 野狼帮趁夜攻山 → 落日峰自毁机关 → 双方立"死契血斗"。气氛"围城 + 绝地"。
- **玩法**：做一场**守关 + 混战**的复合关：前段抵挡涌入的敌人（对应攻山），中段触发"地动山摇"演出（屏幕震动、地面塌陷改变地形），后段进入死斗场对战。
- **演出**：曲魂"巨灵"式清场作为一次**过场高光**（一夫当关）。三位师叔以"巨灵/银针/剑芒"三种招式登场，做成本关的**小 Boss 编队**。

### 单元 3-D《魔名赫起》（seq 88–97）｜触发：单元 3-C 胜利后
- **叙事**：金光罩 → 剑芒对飞剑 → 韩立抢剑符、焚金光上人、灭野狼帮 → "火魔"传说 → 与王门主背后交易。本批**最高潮**。
- **玩法（Boss 战）**：设计**双形态 Boss「金光上人」**——一阶段金罩（需先打碎/或绕到背后规避反弹），二阶段召唤灰芒飞剑（需走位闪避穿透攻击）。胜利后**缴获剑符**。
- **奖励绑定（重要）**：掉落**「剑符（灰芒飞剑）」**——一次性的远程强力技能，有"次数/时长"限制，呼应原著"剑符缺陷"。这是本批对玩家最实在的战力跃迁，也是"飞剑"主题道具的首次出现。
- **机制**：火弹术升级为"**掌心火**"——近身碰触即焚（对应 seq 94 的渲染），对成群小怪为即死判定。
- **结局**：以一纸字条 + 厉飞雨登高远望的过场收束七玄门篇章。

### 单元 3-E《回村·离山》（seq 98–99）｜触发：`enterArea = 山边小村`（回到开场地图）
- **叙事**：回到出生的小村，恰逢小妹出阁，韩立藏身树后远望、诀别双亲。**全书最强情感段落之一**。
- **玩法**：一段**无战斗的纯叙事关**——玩家操控韩立沿村中小路行走，只可"远望/回避"，不可交互战斗；走到村口即通关。
- **设计意图**：刻意降速，与前后大战形成落差；用"回到起点"制造宿命感。可加一枚纪念道具（如"母亲缝的兽皮袋"）作收藏。

### 单元 3-F《嘉元城·墨府》（seq 100–120）｜触发：`enterMajor = 嘉元城`（新地图：岚州）
- **叙事**：码头收服孙二狗 → 蓝衣人（首个"高不可攀"的修仙者）→ 夜入墨府 → 暗信与对质 → 谋"暖阳宝玉" → 得知"升仙会" → 定计夺帮。
- **玩法**：本单元以**潜行 + 谈判/选择**为主，弱战斗：
  - **潜行关**：夜入墨府，避开明岗暗哨（对应 seq 107–108），被发现则重置。
  - **对话选择关**：与严夫人及几位师娘的谈判做成多分支——"选路"（隐居 / 出手灭一门 / 强抢）影响后续墨府是否合作。
- **机制**：新增**「腐心丸」控制**类道具（收服孙二狗），可用于策反敌方小头目；**「引魂钟」**作为曲魂的"外借控制权"道具，允许把随从暂时派驻 NPC。
- **剧情钩子（留白）**：**升仙会**作为下一步主线预告——孙二狗的消息 + 云翅鸟盯梢，为下一批"韩立正式接触修仙界"埋线。
- **关键道具**：**暖阳宝玉**（阴毒解药，本批核心目标，未到手，留悬念）。
