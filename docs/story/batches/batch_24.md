## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 24-A《虚天殿困地》（seq 1121–1125）｜触发：`bossDefeated: yuanying` 后剧情
- **叙事**：一次传送事故把韩立与冰凤双双锁进旧地虚天殿，从对峙到被迫联手，再到八十年苦修一朝进阶，是本批的"时间跳跃 + 破境"双高潮。
- **玩法**：把虚天殿做成**分层的解谜地宫**——明清灵目破幻境（视角/光线判断走对通道）、藏宝室空手而归（暗示"条件未满"）、第五层须以"虚天鼎+众力"合启控制法阵（**多角色合力条**：冰凤、五魔、傀儡各占一段，玩家需集齐才够量）。
- **奖励**：通关即**元婴中期→后期破境**（本段核心成长节点）；解锁"乾蓝冰焰"特效与虚天鼎"收宝"功能。
- **八十年跳**：用一张"潮起潮落"过场交代长修，把韩立归来后的战斗力直接抬到后期。

### 单元 24-B《乱星海问路》（seq 1126–1135）｜触发：`enterMajor = yuanying 后期`
- **叙事**：由黄沙门打探、谣言四起、凌玉灵密语，铺开"虚天鼎旧账"与天星双圣这条暗线；再以"文思月—田琴儿"带出轮回之惑，收束本批情感侧线。
- **玩法**：
  - **身份风险机制**：韩立因虚天鼎成名，凡进入"天星城/坊市"类地图，需先"改容"降低被识破值（新增**声望/通缉**轻量条），被识破率过高则触发围杀事件。
  - **双圣暗棋**：把天星双圣做成**不可战胜的压迫型 NPC**，只在剧情节点以"威压演出"出现（玩家全力出手也难取胜），呼应"元磁神光"设定。
  - **田琴儿支线**：一次"解毒+测天赋"的小型解谜关（以阵要诀为基础），完成即**收徒**，并标记其"轮回嫌疑"图鉴条目。
- **技能绑定**：解锁**明清灵目**（透视/破幻）、**神识化千**（多单位侦察视野）。

### 单元 24-C《碧灵岛夺宝》（seq 1136–1155）｜触发：到达"外海"新地图、首次遇海族妖修
- **叙事**：本批动作戏最密集的一段——巨禽青羽的奇遇、妙鹤旧账、极阴复仇、金蛟王夺矿，最后以极品灵石到手收尾，并埋下"元磁神光大成"的陷阱。
- **玩法**：
  - **潜行刺杀段**：守株待兔 + 噬金虫包围 + 神念附灵监视，做成**布控型暗杀关**（先侦察、后收网），妙鹤战可用"紫罗极火"快速破防。
  - **夺宝乱战**：碧灵岛做成**三方混战沙盘**（逆星盟 / 海族 / 玩家），极品灵石作为"移动目标"被反复易手，玩家要抢在时限内截获；金蛟王为**阶段 Boss**，首选"挡一击即遁走"的脱身判定而非硬拼取胜。
  - **异象奇遇**：巨禽与鬼雾的隔界之战做成**不可介入的过场演出**，掉落的"鲲鹏之羽"作为唯一战利品（后期风雷翅升级材料的预告）。
- **奖励**：**极品灵石**（突破瓶颈消耗品）、庚精线材料掉落、青羽（灵宝材料）。
- **伏笔**：双圣玉简中的"突破化神捷径"是**伪奖励**，界面上给足诱惑但暗标"代价未知"。

### 单元 24-D《魔湖岛藏宝》（seq 1156–1163）｜触发：携带"蛮胡子藏宝点"线索
- **叙事**：一段典型的"小局夺宝 + 奇物揭秘"——三方弟子内讧、金花老祖与鬼鸠、湖底藏宝、银蝌文与金阙玉书，引出灵界视角。
- **玩法**：
  - **多方博弈小关**：入场即遇三方各有算计（弟子/金花老祖/韩立），玩家可选择**先观后动、逐个击破**，鬼鸠与啼魂兽做成一次"灵兽对拼"演出。
  - **秘境解谜**：魔湖天然隔绝神识，做成**视野受限的湖底探索**（只能看清近处），破禁后进入藏宝密室。
  - **知识解锁**：得到"银蝌文"即为**符文/符箓系统**开篇，天澜兽作为**图鉴/交易 NPC**长期存在。
- **奖励**：庚精（补齐七十二口飞剑大阵）、金阙玉书残页（外页）、天澜兽交易线。
- **机制绑定**：新增"**灵界羁绊**"——天澜兽寄居虚天鼎，提供情报/交易，但受"不得远鼎"约束。

### 单元 24-E《回归天南》（seq 1164–1170）｜触发：`regionChanged = 天南`
