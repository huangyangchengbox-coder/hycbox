## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批的核心张力是「**境界差**」——玩家首次以炼虚之身对上合体级，打法由"硬压"转为"以巧破力"。

### 单元 32-A《重炼神山·种剑》（seq 1521–1523）｜触发：`huashen` 后期圆满
- **叙事**：密室里熔石入山、药园中剑影化竹、洞府上空五色天象——一个"厚积薄发"的破境前夜。
- **玩法**：复用**打坐积灵气**，但叠加"**种剑**"养成：把飞剑种入灵木，随时间自然转化/增伤，是长线挂机循环。天象降临即为**破境演出**（全屏五色云环 + 法相虚影）。
- **奖励**：破境后**青竹蜂云剑**入手，附带被动"**剑灵化虚**"——受击碎裂后自动重组一次（每关限一次）。
- **镜像演出**：黑隐山众妖兽远观的"灵压压迫"镜头，作为**境界威压**的视觉化。

### 单元 32-B《血杏与腾龙丹》（seq 1524–1526）｜触发：`enterMajor = lianxu`
- **叙事**：解奴痕、炼腾龙丹、被陌生神念扫过——从"经营"转入"被猎"的惊疑。
- **玩法**：新增**炼丹小游戏**（腾龙丹成丹率刻意压低，可做"控火时机"判定），失败返还部分材料，鼓励反复尝试。
- **机制绑定**：**元磁神山**重炼完成 → 可在战斗中以"**重压**"技能压制定点目标（对应后期压怪蛾、压合体老者）。
- **钩子**：结尾"神念扫过洞府"作为**下一单元的事件预警**（屏幕边缘寒意特效 + 低频音效）。

### 单元 32-C《玄天斩灵剑》（seq 1527–1534）｜触发：`lianxu` 初期、炼丹/制符阶段
- **叙事**：全批第一个大高潮——窥破两大异族、血云血祭、果实吸精血化剑、一剑劈开虚空。气氛要求"被更高层猎物盯上"的窒息感。
- **玩法**：**两段式演出关**——
  1. **血云困局**：在血色禁制中限时寻"破绽"，符篆被逐一烧毁，仅剩的玄天果实是唯一解；
  2. **一剑之威**：一次性"**代价斩**"——挥出一剑直接打断传送/劈开虚空，但清空法力与神念（表现为血量/蓝量归零的虚脱镜头）。
- **机制绑定**：**玄天果实化剑**作为限用终极技（每场战斗仅一次，且大幅自伤）；其后化为**手臂剑痕**（附着状态），后续成为可成长的隐藏底牌。
- **世界观投放**：角蚩族、海王族、"玄天斩灵剑排名第三"三条设定入库。

### 单元 32-D《火阳族·乌罗之劫》（seq 1535–1546）｜触发：传送事件后（`lianxu` 初期）
- **叙事**：从海外荒岛到异族灭族危机——蛇人火阳族求援、大祭司舍寿、女儿试探、乌罗族屠城。是**"还债式的委托"**：一颗烈阳丹换一族存亡。
- **玩法**：做一段**防守关**——土城四门守御：守护城墙、拦截潜行而入的乌罗王族；韩立作为"不可直接操控的高阶援兵"，只在**触发钩子**（乌罗王族现形）时登场。
- **新机制**：敌方核心技能"**漩灵邪光**"（反弹攻击、无视禁制、附毒）——玩家需以"噬灵天火"类**克制型火系**才可破，形成明确的"解法"教学。
- **奖励**：通关得**黑纱**（隐身道具，罩身可屏蔽视野与锁定）——直接影响后续潜行关。
- **角色植入**：白珠儿（弓手 NPC）与青筱（导师型 NPC）登场，为下一单元铺路。

### 单元 32-E《空云晶·蓝湖岛怪蛾》（seq 1547–1555）｜触发：`lianxu` 中期、持[银鲨令]
- **叙事**：为回家而猎兽——修复传送阵所需的空云晶在一头巨鲸腹中；蓝湖岛上却横插一只**双头怪蛾**。
- **玩法**：**双段 Boss 战**——
  1. **怪蛾战**：主打"**再生机制**"——打碎即重组，需先找出并压制其"毒素/核心"，再一举灭之（对应原著的邪光细丝 + 声波压血）；
  2. **海兽战**：巨鲸**水遁闪避**高，需提前布下**春黎剑阵**（范围禁锢）才能命中，考"预判布置"。
- **技能绑定**：**晶鳞小盾**（本命防具，可偏转法术）、**剑灵化虚**至此完全解锁；**春黎剑阵**作为可布置的场控技能正式加入。
- **奖励**：空云晶到手 → 传送阵修复 → 开启"雷鸣大陆"新地图。

### 单元 32-F《绿光城·角蚩追杀》（seq 1556–1570）｜触发：`bossDefeated: lianxu（怪蛾）`
- **叙事**：本批最高压段——刚落地即逢屠城、被迫带"玉匣"逃亡、识破卧底、最后以炼虚之身硬撼合体老者。贯穿情绪是**"打不过就要跑得掉"**。
- **玩法**：**逃亡 + 追猎双线**——
  1. **绿光城突围**：限时撤离关（城门开洞、躲避巨鹰/独木舟/羽蛟三波追兵）；
  2. **卧底遭遇战**：火月人战，强调**幻术识破**（玩家须通过环境细节判断真假分身）；
  3. **合体老者战**：**以巧破力**的标志战——玩家全程不可硬拼，唯一解法是"**春黎剑阵 + 元气之剑**"（清空剑阵灵力换一剑重伤），并以**噬金虫**做最后威慑逼退对手。
- **奖励**：通关解锁**噬金虫**（召唤物，短时高爆发但耗神念）、**元气之剑**（终极剑阵技）与**玉匣**（可疑任务道具，去向留白）。
- **伏笔**：殷尊者搜捕的"大鱼"与白发异族及其**兽形傀儡**，作为下一批（seq 1571+）的**接续钩子**。
