## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 18-A《血咒之门》（seq 821–823）｜触发：`enterMajor = yuanying`
- **叙事**：一边是韩立寻果途中的"地图谜团 + 通灵之宝交易"，一边是南陇侯二人私探血咒之门——**双线并进**，把"坠魔谷藏有上古大秘"的气氛推到位。
- **玩法**：复用**打坐吸灵气**，把坠落谷底的阴湿洞窟做成环境变量（灵气浓度高、但视野狭窄、地面湿滑减速）；新增轻量**寻宝探索**：玩家在洞窟中按地图指示走到标记处，触发剧情。
- **奖励/技能绑定**：解锁"**仿制通灵之宝**"研究方向（大衍神君委托），对应游戏后续的**法宝仿制/材料收集**长线。
- **触发钩子**：`yuanying` 段首次进入坠魔谷地图标记区。

### 单元 18-B《祭坛与通道》（seq 824–835）｜触发：`yuanying` 中期、首遇"破禁寻宝"
- **叙事**：佛宗金刚阵、能被唤醒的残魂画轴、遮山幻阵、夺舍吞婴、祭坛登顶、破界珠开通道——**悬疑层层加码**，末尾一句"此处非灵缈园"翻转期待。
- **玩法**：
  1. **小须弥金刚阵**做成"**持续输出磨罩**"关：护罩会自愈，须不间断攻击（对应现有的连续斩杀节奏）；
  2. **神识化千**做成**侦察小游戏**：玩家用神识分神点亮地图上的虫点，寻找路径（分神会折损，做成"可承受代价"）；
  3. **幻化之峰 + 幻阵遮山**做成**限时布阵**：在对手抵达前完成遮挡。
- **奖励**：解锁"**紫灵**"作为同伴（侦察/寻路增益）；获得"破界珠"剧情道具。
- **触发钩子**：`bossDefeated: yuanying` 且持有[紫灵好感]。

### 单元 18-C《双魔会·古魔出世》（seq 836–851）｜触发：**首个"魔潮境主战"**
- **叙事**：本批最高潮——封印魔躯、解体化形、夺舍吞婴、双魔会谈（主元神与第二元神相争）、遮天魔幕、黑刃斩山、黑矛吞婴、困魔、降灵符半蛟化、终被空间裂缝卷入。
- **玩法**：**多阶段连环战**——
  1. **逃生阶段**：白气浪碾地，玩家在冰山后躲过冲击（对应耐力/护盾机制）；
  2. **追杀战**：魔魂会**隐身 + 高频位移**，需以"明清灵眼"类**标记技能**锁敌才能输出；
  3. **灵气枯竭段**：魔幕持续吸法力，须靠"辟邪神雷"净化维持（引入**资源对抗**）；
  4. **终局战**：玩家以剑阵压缩伤害，再以"降灵符"短时**变身强化**对拼，屏幕中央随机刷出**空间裂缝**吞噬双方（伤害与走位双重压力）。
- **奖励/技能绑定**：解锁**辟邪神雷强化**、**紫罗天火**、**血魔剑**（高伤但附带"邪气/反噬"负面数值）。
- **伏笔**：给出"上古魔界、圣界、梵圣真片、三头六臂"等关键词，为后续**大晋篇**埋线。

### 单元 18-D《灵缈园残骸》（seq 852–855）｜触发：单元 18-C 结束后剧情
- **叙事**：银焰一瞬灭魔 → 残骸药园中辨出万年灵药 → 因三种药草不可移植、小瓶失效而被迫困守 → 寻得空间"薄弱之点"却无力破壁。基调**由险转静、暗藏隐忍**。
- **玩法**：把"**炼丹苦修**"做成**长线养成**：在封闭空间中反复采集—炼丹—打坐提升，用绛云丹推进修为；空间壁与薄弱点做成**解谜探索**（神识扫描找游走的淡蓝光点）。
- **奖励**：解锁万年灵药库（绛云丹、雪魄丸），对应**长期修为/冰系技能增益**。
- **表现手法**：以一张"四季轮回 / 年份跳字"过场图交代**二十七年时光**，随后进入元婴中期。

### 单元 18-E《重返天南》（seq 856–862）｜触发：`yuanying` 中期
- **叙事**：破空坠入三族灵泉 → 听闻古魔围剿与无边海大漩涡 → 重返落云宗 → 为南宫婉喂丹 → 与慕沛灵谈起结丹与颠凤培元功的双修条件。
- **玩法**：
  1. **消息打听**做成**对话支线**（以赠礼换取情报，含一次"鉴定身份"的小反转）；
  2. **喂丹**做成**轻交互仪式**（把妖丹送入冰壁，红光亮起但未醒，制造悬念）；
  3. **双修约定**做成**选择/契约界面**（接受则解锁同伴培养线）。
- **奖励**：解锁**颠凤培元功**（后期破境增益线）、**三焰扇**炼法（材料收集长线，指向大晋）。
- **触发钩子**：**南宫婉解咒未完成**作为跨批**悬念钩子**。

### 单元 18-F《七灵岛之约》（seq 863–870）｜触发：`yuanying` 突破/下一批接口
- **叙事**：云梦山观礼、金老怪试探、至阳上人密邀、一战胜金老怪、通宝决与虚天鼎之谜、七灵岛无边魔气大悬案。
- **玩法**：
  1. **观礼认主**做成**演出式关卡**（追抓乾坤塔的宝物追逐，做成微型追捕）；
  2. **斗金老怪**做成一场**非致命切磋关**：躲避"春丝斩"金网、破解冰莲封剑、最后用位移技能近身制敌（无攻击法宝即胜，强调**机制压制**）；
  3. **虚天鼎**做成**通宝决加点**：三层分别绑定元婴中期/后期/化神，第一层仅给"少量威能"，为长期目标留白。
- **奖励**：**落云宗晋升云梦山第一宗**（宗门声望/资源提升）；虚天鼎封印入体。
- **触发钩子**："**无边魔气封印阵眼受损**"作为下一批（seq 871+）的**主线悬案**，与"大晋篇"合流。
