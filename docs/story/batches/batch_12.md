## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批主线是**结丹中期→结丹后期**，并为**元婴突破**蓄势。

### 单元 12-A《虫魔之名》（seq 521–526）｜触发：`jiedan` 中期、深海归来自主闭关
- **叙事**：韩立一身凶名"虫魔"竟是被诬所致——他本人从不滥杀，却替碧云门与虚天殿的追杀背了黑锅。悬疑感来自"真假虫魔"的分辨。
- **玩法**：把"抽魂取丹"落成**引妖据点循环**——在珊瑚礁布阵、种霓裳草（现有药田玩法延伸），引怪→困阵→斩杀→抽魂取丹，形成可持续刷取妖丹的据点副本。
- **机制绑定**：新增"**养魂木串珠**"饰品位（提高法术抗性/元神类防御），替代此前单纯的恢复道具。
- **氛围**：以"被误解的通缉名声"做一次**全屏声望事件**——韩立此时是乱星海众矢之的，为后续"改名行走"埋线。

### 单元 12-B《雾海稚女》（seq 527–531）｜触发：`jiedan` 中期闭关结束
- **叙事**：三名青灵门弟子被鹰鸢兽追杀闯入雾海，引出孝女公孙杏以身救父；韩立将其领入洞府又暗中赠宝离去，全批里少见的**温情一笔**，也交代"掌天瓶噬金虫已难再进化"的困境。
- **玩法**：一场**护卫型守关**（鹰鸢兽群扑击 + 巨猿傀儡协防），接一段**纯剧情 + 道德选择**（受女为炉鼎 / 暗中赠宝）。
- **奖励**：通关得"**青灵门信物**"，开启后续内海青灵门支线钩子。
- **伏笔**：噬金虫不再随霓裳草进化 → 呼应原著"灵虫繁殖停滞"的长期限制。

### 单元 12-C《秘市交锋》（seq 532–538）｜触发：`jiedan` 后期前段、寻 `伴妖草` 主线开启
- **叙事**：荒岛秘市、交换会、文思月的求助与范夫人的算计，一次性铺开"妙音门线 + 裂风兽巢穴情报线 + 古文字铜片（梵圣真片）线"。
- **玩法**：做一段**交易/声望关**——秘市设有"听风阁"与结丹交换会两处，玩家凭珍稀材料换情报（材料换取信息，而非打怪掉落）。
- **技能绑定**：此处交出"**剑威初现**"的高光演出（十二剑合一瞬杀），首次让玩家感受结丹后期的压倒性战力。
- **触发钩子**：`持有[裂风兽海图线索]` 与 `持文思月好感` 后解锁深渊方向。
- **线索道具**：入手**古文字铜片（梵圣真片）**，作为后续妖族传承的图鉴条目。

### 单元 12-D《伴妖草与风雷翅》（seq 539–551）｜触发：`jiedan` 中期→后期突破（本批核心高潮）
- **叙事**：深渊猎伴妖草失手被擒 → 饮碧焰酒闭关突破结丹后期 → 被九级裂风兽挟制炼"风雷翅" → 三妖法力枯竭时以毒液暗算、噬金虫噬蛟、夺翅雷遁脱身。整段是**以弱制强、险中取胜**的高压剧情。
- **玩法**：本批最重的玩法单元，可拆成四层：
  1. **潜伏侦察关**（礁石监视 + 潜入洞窟偷草，失败即被抓入剧情）；
  2. **闭关炼酒关**（限时资源管理：丹火 + 万年灵液维持，进度条逼到"结丹后期"）；
  3. **炼宝仪式关**（作为"人形灵石"被迫供灵力，隐藏判定——何时出手暗算）；
  4. **翻盘战**（毒液让三妖被困 → 选择击杀对象：先灭毒蛟 → 龟妖自治之体无法斩杀 → 夺翅逃离）。
- **奖励与技能绑定**：
  - 主线奖励"**风雷翅**"法宝 —— 战斗中使用可触发"**雷遁术**"（短距瞬移闪避），是本批最重要的机制升级；
  - 击杀毒蛟掉落"**蛟龙精魂/妖丹**"，二妖储物袋得"乌黑龟壳 + 血红鳞片"（可炼高级护甲）。
- **限制机制**：全程携带"**风灵劲**"debuff（周期性打断移动/施法），须集齐材料或借辟邪神雷逐步解除 —— 制造持续的逃亡压力。

### 单元 12-E《妙音门了断》（seq 552–559）｜触发：`jiedan` 后期、借用 `幻梦石传送阵` 支线
- **叙事**：再闯妙音门 → 被范夫人以气息识破身份 → 以"除云天啸"换"借传送阵" → 诱伏斩杀云天啸 → 妙鹤破局、换形决失效暴露 → 被妙鹤与追来的风希双重夹击 → 借传送阵险胜脱身、误入内海皇明岛"六道盟任务"。
- **玩法**：
  - **潜行/伪装关**：以"换形决"伪装身份进出坊市，一旦施展超过七成法力即伪装失效（对应原著设定），做成**伪装耐久度**机制；
  - **伏杀战**：单间房内的**速决 Boss 战**（五行环锁身 → 一击必杀），强调"在援手赶到前一击立功"；
  - **双雄夹击逃杀**：妙鹤（骑血鹤）+ 风希（本体裂风兽）同场追逐，玩家须用风雷翅雷遁抢先进传送阵 —— 做成**限时奔逃关**。
- **叙事钩子**："姓厉的结丹修士"成为全外海通缉关键词，为"改名行走内海"的长期设定收口。
- **转场**：传送至皇明岛后立刻进入"误认六道盟执法使"的新身份困局，衔接下一单元。

### 单元 12-F《还魂护法与六道传人》（seq 560–570）｜触发：`jiedan` 后期圆满 / `元婴` 前夜
- **叙事**：误入六道盟抓人任务 → 认出元瑶、借头颅反杀同伴 → 元瑶赠万年灵液与拘灵阵、倾诉身世 → 应允为其"还魂术"护法 → 护法天兆引来群修围观、斩杀潜行修士 → 六道传人温天仁现身，苦斗未完。
- **玩法**：
  - **护法守关**：以还魂天兆为"引怪"事件，玩家需连续抵挡数波窥探者（低阶群修 → 结丹白影 → 六道传人），是典型的**塔防式长时间守关**；
  - **反水玩法**：任务中突然倒戈（借头颅）——韩立与"临时队友"的立场反转，可做成**信任度判定**剧情关；
  - **掌门级 Boss 战**：温天仁（六道传人）作为本批最终 Boss，具备金针破虫、紫云隐匿、青铜古盾、六极真魔功等**多阶段机制**，专克玩家的"驱虫/飞剑"两套主力，逼迫玩家切换风雷翅与符宝应对。
- **奖励与技能绑定**：
  - 元瑶处获"**万年灵液**"（恢复类至宝）与"**拘灵阵**"（洞府隐匿阵法、长期防御）；
  - 入手"**青冥针符宝**"（飞针类一次性法宝，对金针类法宝有奇效）。
- **剧情留白**：与温天仁的苦斗**未分胜负**，直接作为下一批（seq 571+）的**跨境界大战**开端，也是玩家冲击**元婴**前的最后一战。
- **情感基调**：护法段落"以己身救旧友"与元瑶身世相呼应，是韩立"冷面修仙"中难得的柔软一面。
