## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 42-A《天晶封魔 · 草原兽潮》（seq 2021–2025）｜触发：`huashen`→`合体` 过渡完成、开启"魔界"地图
- **叙事**：开篇先给一段"上位者视角"的冷场——灵族以残缺天晶塔冰封下界大敌、再以仙界符箓镇魂，另界道人为真魂牌异动而起身；镜头陡切魔界草原，韩立剑光开道。基调是"门槛极高的新地图"。
- **玩法**：把"草原兽潮"做成**无限刷怪压力关**——魔兽数量不设上限、只杀不竭，玩家须在资源耗尽前完成"斩兽王"目标；作为重复可玩的高压刷怪场景，正好复用"妖怪来袭挥剑斩杀"的核心手感。
- **奖励 / 技能绑定**：通关解锁**伪魔珠**（伪装系消耗品：短时切换成"魔气"属性以规避魔界检测），并开放"辟邪神雷"对魔物的克制加成。
- **触发钩子**：斩兽王后触发"救魔"事件，两名血鸦城护法以"事后听命"为报酬，引出下一单元的目的地。

### 单元 42-B《血鸦城 · 异魔金与拍卖》（seq 2026–2034）｜触发：`合体后期` 且首次进入"魔界城池"
- **叙事**：一段完整的"城中经营剧"：伪装进城、摊市捡漏、剖石得珠、绿气缠身、半年一度的拍卖会与压轴圣砖、真灵遗骨的竞价。悬念集中在"那颗灰白晶珠到底是什么"。
- **玩法**：
  - **异魔金寻宝**：新增"**开石**"循环——收购黑白矿石、逐块剖开，小概率得到灰白晶珠（对应本批最大成长红利），大部分为普通材料（保持低爆率的长线期待）；
  - **拍卖会**：做成**竞价小游戏**（限时出价、魔石汇率、对手抬价 AI），压轴物分三档递进：暗血五色铃 → 圣砖 → 真灵遗骨；
  - **夜半追踪**：做成一次**潜行跟随**小事件（保持距离、避开巡逻与感应类魔器）。
- **奖励**：解锁"**炼化晶珠**"养成（缓慢炼化，逐次小幅提升法力上限，配"绿气"作为副作用/风险提示）；拍得**通玄药灵遗骨**（投入长线资源后可孵化一具大乘级"芝仙灵躯"外援）。
- **触发钩子**：把"绿气"做成**未结算的负面状态图标**（银焰不化、每夜自行回体），为后续"魔婴封印"与蓝瀑湖支线留钩。

### 单元 42-C《泣灵秘藏 · 血鸦城主之战》（seq 2035–2041）｜触发：单元 42-B 完成、持有[圣砖]
- **叙事**：全批第一场高潮战——城外对峙、身外化身、七杀血煞与黑骨魔虫、夺砖、杀城主取三砖，紧接着毫无缓冲地压上"吸魔蚁海"天灾。节奏是"贪得 → 天罚"。
- **玩法**：
  - **三阶段 Boss 战·血鸦城主**：血煞领域（持续流血区）→ 第二化身（限时同时击败本体与化身）→ 黑骨魔虫（用"噬金虫"反制，形成虫对虫的清场）；
  - **秘藏拼图**：战后集齐四块圣砖，做**合图小玩法**（旋转、叠合、对齐光柱），映出"泣灵秘藏图"并入库为**长期寻路任务**（提示物标为独角黑龙标记）；
  - **吸魔蚁海**：做成**全地图灾难事件**——在"吸血式"消耗域中限时冲出包围（用一次瞬移/传送、剑光拉面、天火开路），失败不判死、仅扣资源。
- **奖励**：**噬金虫群**（反制虫类敌人与吞食宝物的清场手段）、**紫言鼎**（控场型囚笼法宝）、以及"泣灵秘藏图"支线资格。
- **伏笔**：蚁灾后众人约定"两年后幻夜城最大客栈会合"，作为下一单元的显式任务指针。

### 单元 42-D《荒中重修 · 幻夜城与小灵天之谜》（seq 2042–2055）｜触发：进入"魔界荒地/幻夜城"地图
- **叙事**：从蛮荒独修（修仙界炼体与炼神功法）到白家相遇、幻夜城落脚、万奴塔救人族女奴，再借朱果儿点出"小灵天"与素女轮回功——全批的**情感线**。收尾是白家矿脉之约与第一次进入幻啸沙漠。
- **玩法**：
  - **苦修过渡**:以"布阵重修"形式开启两条长线养成——**百脉炼宝决**（骨骼符纹逐层点亮，提升肉身减伤，修炼时会持续掉血/掉状态，需限时忍耐）与**炼神术第二层**（神念上限与侦察范围提升）；
  - **幻夜城声望**：做轻经营/关系网——四大家族与万奴塔的**好感度**，靠帮白家一次"真实委托"换来两头**八足魔蜥**（新载具：可在禁术地形中通行）；
  - **万物如市**：万奴塔可购买**魔晶傀儡**（低阶修士也能指挥的傀儡小队，可批量用于防守/挂机战斗），并可换取傀儡炼制术；
  - **沙漠禁术机制**：幻啸沙漠内"遁术失效、法力压制九成"，只能骑蜥行进——做成**规则改变型副本**（回到接近凡人的低机动状态，放大"斩怪"本体玩法）。
- **奖励 / 技能绑定**：八足魔蜥（载具）、魔晶傀儡（可派遣单位）、紫光树紫灵果（合体以下增益药）、白芸馨玉佩（白家通行凭证）。
- **触发钩子**：朱果儿的**素女轮回功线索**全批不明说，仅以"她的功法为何与你旧识一致"的方式埋线，留待后续资料片回收。

### 单元 42-E《幻啸沙漠 · 矿脉之战与白家宝库》（seq 2056–2066）｜触发：`合体后期` + 白家支线"火云石矿脉"
- **叙事**：据点弟子失踪 → 备用入口潜行 → 骸骨与熔岩湖 → 鹿首巨兽与无形魔灵双战场 → 斩角逼退、加码除魔 → 宝库三件意外之选（异魔金、金鲸珠、阴罗盘）。
- **玩法**：
  - **矿脉潜行**：以**司魂佩**（感应追踪器）代替神念搜索，做"沿血脉指针找路"的探索关；
  - **双目标 Boss 战**：熔岩巨人（火属性、强恢复，需要冰系/克制神通破其躯壳）与**无形魔灵**（刀剑难伤、免疫黑焰，仅"银焰类"手段可伤），逼玩家携带两套应对手段；
  - **限时清障**：地火中保护 NPC（白家子弟）失败会真实减员，制造压迫感；
  - **宝库抉择**：给玩家**三选三的宝物界面**，其中"巨块异魔金（内藏灰白晶珠）"表面价值最低——奖励"看穿表象"的玩家。
- **奖励**：**噬灵天火升级材料**、阴罗盘（沙漠寻路/抗迷航）、金鲸珠（后期一次性召唤物）、以及又一颗灰白晶珠（对应长线修为增益）。
- **情感基调**：冷冽克制——白芸馨等六名白家子弟的死亡、白家兄长的"亏了报酬"私语，皆以过场旁白呈现。

### 单元 42-F《群修定计 · 二进幻啸与圣祖降临》（seq 2067–2070）｜触发：单元 42-E 结束、"两年之约"到期
- **叙事**：众人会合交换伤病与情报、识破赵家反被同修将计就计、林家男子重伤退出并受托带走朱果儿，旋即被宝花圣祖擒下搜魂——"洗灵池与净莲"的秘密第一次落到敌方耳中。收尾是众人二进幻啸沙漠，一场更大的埋伏已经提前布好。
- **玩法**：
  - **情报拼图**：把"魔蜥之策"做成**多方案选择**（换取 / 竞价 / 潜入夺取），不同选择影响后续战斗强度与声望；
  - **偷夺行动**：一次**分工潜入关**——一人引开两名魔尊 Boss（只需拖延，不判胜负），其他人限时进入赵家夺得魔蜥；
  - **高维压制演出**：宝花圣祖登场做成**不可战胜的碾压型演出**（玩家只要在短时间内做出正确选择、保住关键 NPC），标注为"圣祖级威胁"，作为后续境界（大乘）的目标准星。
- **奖励 / 伏笔**：八足魔蜥队列（全员载具成组）、"洗灵池 / 净莲"两条主线物标浮现、以及**敌方圣祖已提前在目的地等候**的倒计时压力条。
- **技术约束**：圣祖登场与搜索元神段落均走剧情层全屏替换，不做浮层特效。
