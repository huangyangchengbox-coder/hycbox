## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 17-A《边界之战·圣禽降灵》（seq 771–780）｜触发：`enterMajor = yuanying` 的「边界之战」大事件
- **叙事**：十万修士大战的最后高潮——第四神师田锺、慕兰圣禽（青孔雀）、阴阳双魔、铜甲尸潮、血鬼对石人、傀儡抢灯、突兀人来袭逼停战。基调：磅礴、兵荒马乱。
- **玩法**：做成一场**动态团体混战事件**。玩家（韩立位）的目标不是清光敌人，而是限时完成"**抢灯**"——潜入乐姓女子的元明灯旁，用傀儡诱敌、以隐匿脱身（对应 778）。画面中 NPC 双方势力自行缠斗。
- **奖励/技能绑定**：**降灵符**（限时半蛟变身，全属性暴涨的爆发 buff，对应 773）；可短暂召唤"慕兰圣禽"的限时道具（用后须归还换材料，对应 780）；紫铖兜归还银月。
- **触发钩子**：`bossDefeated: 边界之战` → 触发议和过场 → 埋下"突兀人"外敌线。

### 单元 17-B《南宫惊变·大庚剑阵》（seq 781–788）｜触发：回宗事件 / 南宫婉好感度达标
- **叙事**：南宫婉中封魂咒被冰封；韩立把庚精炼入飞剑、练成大庚剑阵，赴天柱山决战阴罗宗长老；啼魂吞鬼、鬼罗幡覆灭。基调：决绝、冷厉。
- **玩法**：新增"**炼剑**"经营循环（庚精+婴火，逐口淬炼三十六口飞剑，进度可存档）；一场**BOSS 战**——对手以鬼罗幡召唤鬼火骷髅潮，须先用**啼魂兽**（召唤单位）吞噬鬼群、再以**大庚剑阵**（金丝切割+自动辟邪神雷）破幡。
- **奖励/技能绑定**：解锁**大庚剑阵**（群体金丝切割，可切断法宝）；开放啼魂兽"**吞魔啖鬼**"召唤技（专克阴鬼/炼尸）。
- **触发钩子**：`bossDefeated: 人界魔修长老` → 得**阴罗宗长老令牌** → 引出"解封魂咒"主线任务链。

### 单元 17-C《极西归来·大衍神君》（seq 789–797）｜触发：封魂咒任务链 · 第 2 环
- **叙事**：解咒须上古火蟾内丹；韩立种第二元婴、炼天绝魔尸；寄身竹筒的大衍神君登场，揭开"上古魔界 / 古魔"秘辛，为坠魔谷定调。基调：诡秘、沧桑。
- **玩法**：新增"**副元神**"系统（第二元婴=可短暂离窍侦查与瞬移的轻量分身，有冷却）；"**炼尸**"玩法（以啼魂兽抽取行尸元神，再炼成可召唤的天绝魔尸）。
- **奖励/技能绑定**：**大衍决第五层**（神识强化：扩大探测/识破范围）、结丹级傀儡炼制法；世界观图鉴新增"上古魔界 / 古魔"词条。
- **触发钩子**：接取"**坠魔谷**"主线，解锁坠魔谷地图与集结点。

### 单元 17-D《坠魔谷·集结入谷》（seq 798–807）｜触发：`enterMajor = yuanying` + 持有坠魔令
- **叙事**：故人陈巧倩病故的消息、与鲁卫英/南陇侯结盟、鬼灵门巨型单向传送阵、群修入谷、外谷空间裂缝杀机。基调：群雄荟萃、步步惊心。
- **玩法**：入谷用"**随机传送**"（玩家被落在外谷随机位）+ "**空间裂缝**"危险地形（明裂可见可躲、隐裂须**明清灵眼**或**感应铃**预警）。入谷前有"**傀儡备战**"环节：巨龟（远程/肉盾）与人虎妖（近战/高速）二选搭配。
- **奖励/技能绑定**：明清灵眼（探隐形裂缝）、感应铃（预警道具）、**两仪环**（过北极元光的钥匙，后段关键）。
- **触发钩子**：入谷后分支——赴南陇侯之约（主线）或自由探宝（支线）。

### 单元 17-E《内谷·火蟾古兽》（seq 808–820）｜触发：抵达坠魔谷内谷入口
- **叙事**：三首巨蟒、罡银沙矿脉、北极元光、紫纹蝎、火蟾兽、古修遗骸与七焰扇、血咒之门的伏笔。基调：凶险、贪婪与心机。
- **玩法**：多段递进副本——
  1. **巨蟒古兽战**：以傀儡牵制，用"千重峰"重压斩杀；
  2. **北极元光通道**：只能靠两仪环护罩通过，**全程禁用法宝/灵力**，纯走位躲避（高风险限时关）；
  3. **十绝毒"引怪"机制**：以碧鸠之毒引开飞天紫纹蝎，限时穿过蝎巢；
  4. **火蟾兽 BOSS 战**：先诱入水属性法阵锁定退路，再用**乾蓝冰焰+辟邪神雷**破其"不灭之体"（首身会自动重接），斩首后须补刀冻结碎尸才算过关。
- **奖励/技能绑定**：**火蟾妖丹**（解封魂咒关键道具）、**七焰扇炼制法**（通天灵宝线索）、罡银沙（炼器材料）、坠魔谷地图（后续路线解锁）。
- **触发钩子**：火蟾妖丹 → 续接封魂咒任务链；血咒之门 / 七焰扇 → 为后续卷（坠魔谷深处）埋线。
