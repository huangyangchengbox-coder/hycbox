## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情仍挂在「关卡之间的叙事插入 + 关卡目标绑定」上；每个单元对应一次触发，境界节点对齐 `结丹` 中→后期。

### 单元 10-A《真假虫魔·暗流》（seq 421–423）｜触发：`结丹` 初期、外海「奇渊岛」海域的夜间遭遇
- **叙事**：夜海之上，韩立被三名修士当成凶名滔天的"虫魔"跪地求饶；他不杀反释，却在盘问中得知**深渊妖兽发狂、外海已成禁区**。随后镜头切到黑石城密室——极阴祖师把虚天鼎的秘密吐给碧云门，多方元婴期老怪悄然潜入。
- **玩法**：做成**非战斗的"审问"小场景**——玩家在对话框（全屏替换页）中挑选问题（深渊之变 / 虫魔来历 / 奇渊岛近况），选满关键问题即"放人离去"过关；错误发问则触发一次无奖励的短暂遭遇战。
- **机制绑定**：新增**"凶名/通缉"系统**——玩家被 NPC 误认为"虫魔"，高凶名会改变怪物与中立修士的 AI（或逃或围攻），与第 09 批的凶名系统合并升级。
- **暗线预告**：用一段"密室黑屏对话"埋下 `元婴老怪正在找你` 的长期悬赏线，为后文妙鹤、六道传人接续。

### 单元 10-B《雾海潜修·青灵门》（seq 424–428）｜触发：回到雾海洞府（`结丹` 中期关卡起点）
- **叙事**：三年炼丹 → 霓裳草对进化虫失效（**成长线受阻**）→ 二三十年闭关突破结丹中期 → 青灵门五人入岛求救 → 公孙杏以炉鼎之诺换来赠宝、独自离去时只见一行留言。
- **玩法**：把"闭关"做成**放置型成长结算**——选丹药组合（五六级妖丹）投入炼丹室，按时间产出修为/炼丹术等级。青灵门一段做成**限时救援关**：操控韩立用巨猿傀儡（自动炮台）清掉成群的二级鹰鸢兽。
- **道德选择**：新增"**炉鼎之约**"**伪选择**——玩家可答"要她为炉鼎"或"放她离去"，两条分支结局都是**赠宝离开**（忠于原著，也让玩家体会韩立"戏言赠宝"的做法）。
- **奖励**：缠玉决（女修向功法，收藏品）、金真功等顶阶功法玉简（图鉴）、洞府库藏（法器一批）。
- **成长系统**：**霓裳草·失效事件**是一处**明确的"资源断供"提醒**——引导玩家把虫群培养目标从"繁殖"转向"进化/保种"，与第 09 批"虫室经营"闭环。

### 单元 10-C《秘市与交换会》（seq 429–435）｜触发：`结丹` 中期、进入「南黎岛秘市」
- **叙事**：易容救黄明礼 → 潜入无禁制的荒岛秘市 → 结丹修士交换会 → 一语不和斩云天啸、震慑全场 → 以情报换得文思月自由 → 婉拒范夫人"传送阵之请"，另择荒岛安置故人之女。
- **玩法**：**多线索枢纽型主城**升级版——秘市比黑石城更"地下化"：入门需熟人引荐 + 隐匿潜行（UI 上"灵气外泄度"进度条，过高会招来巡逻）。交换会做成**竞价/条件匹配小游戏**：每人出示 1–2 件宝物，玩家以"材料 / 灵石 / 情报"出价；韩立真正的目标是**"八级妖兽巢穴情报"这一隐藏条目**。
- **战斗**：**威慑型 Boss 战**（云天啸）——不是打死，而是**一击致残**：玩家需在极短窗口内选中"飞剑突袭"（对应十二柄飞剑）并打出高伤，成功后全场 NPC 态度转为"畏惧"，解锁**群修震慑**成就。
- **角色植入**：文思月（可带走、成为据点 NPC）、范夫人（后续追缉线关键人物）。
- **关键道具**：三头六臂铜片（后续妖修功法线）、五级妖丹。

### 单元 10-D《裂风兽·风雷翅》（seq 436–448）｜触发：进入深渊边缘「裂风兽巢穴」
- **叙事**：本批前半段最高潮。取伴妖草 → 撞上九级妖修风希 → 被迫饮碧焰酒、困密室炼化 → 意外突破结丹后期 → 三妖合炼风雷翅、暗算反被暗算 → 噬蛟夺翅 → 踢妖入火、带翅逃命。
- **玩法**：做成**"卧底 + 反杀"的多阶段副本**。
  1. 「被囚」阶段：操作受限（可用行动点极少），唯一任务是**借炼化碧焰酒悄悄积累修为**（进度条即破境线）；
  2. 「炼宝」阶段：玩家被强制注入木灵力（**资源被抽走**的负反馈），间歇性被要求"按节奏提供灵力"（简单小游戏），其间偷偷攒一瓶"掺毒灵液"作为底牌；
  3. 「反杀」阶段：触发毒液 → 放虫群 → 优先**啃噬物防最低的毒蛟**（血毒会反噬虫群，需在"虫量见底"前咬穿）、用啼魂兽收蛟魂、抢风雷翅、踢妖入火、脱身。
- **技能绑定**：**风雷翅**是本批最重要的新法宝——提供**雷遁（瞬移位移）**，代价是消耗可耗尽的"辟邪神雷"；同时开放**换形决**（易容，伪装状态下只能用七成法力）与**剑影分光术**（飞剑数目×4）。
- **机制绑定**：**妖体/护体宝物**概念首次登场——八级及以上妖兽"妖体即法宝"，常规飞剑难破，逼玩家转向"用毒、用虫、用神雷克制"的多解法；`自治之体`（再生的龟妖）则提示"必须斩首或碎丹"。
- **奖励**：风雷翅、蛟魂（炼器材料）、乌黑龟壳 + 血红鳞片（可炼甲）、三头六臂妖修功法（收藏）。

### 单元 10-E《重返内海·还魂术护法》（seq 449–464）｜触发：`结丹` 后期、抵达「皇明岛 / 内星海」
- **叙事**：二闯妙音门 → 范夫人凭辨气识破身份 → 诱杀云天啸、妙鹤搅局、换形失效败露 → 裂风兽再现、极限逃上传送阵 → 回到内海、误被当"执法使" → 被卷入青阳门追缉元瑶的任务 → 反手救元瑶、得灵液与阵法 → 为元瑶的还魂术护法、惊退群修。
- **玩法**：
  - **诱杀关**：把"引敌人入屋 + 一击必杀"做成**潜行刺杀小关**，要求玩家把云天啸与妙鹤"分开"（距离判定），妙鹤进入视野即失败、转为"硬接元婴一击"的高难变奏；
  - **大逃杀关**：全批节奏最紧的一段——韩立被 `妙鹤 + 风希` 双线追杀，玩家在"**风灵劲发作间隔**"的倒计时里抢时间飞行，必须边跑边压制体内暴走（QTE），抵达传送阵即通关；妙鹤/风希追击按**限时事件**表现（不必击败）。
  - **护法关**：**塔防式守卫**——元瑶施法为倒计时，玩家在谷口布阵、放傀儡、用虫群与剑气拦截一波波来探的修士（低阶筑基→结丹），"吓退"与"击杀"两种处置都算成功，但击杀会拉高凶名。
- **技能/系统绑定**：**伪身份系统**接通——玩家顶着"妙音门厉长老"与"青阳门执法使"两个假身份，被识破即触发追缉；**拘灵阵**（隐匿洞府灵气）作为新的据点升级项解锁。
- **奖励**：万年灵液（限次瞬回法力）、青阳门阵法典籍（含拘灵阵等多阵）、啼魂兽祭炼符（后续可升级啼魂兽）。
- **留白**：还魂术成否、妍丽是否复生，本批不揭，留作后续伏笔。

### 单元 10-F《六道传人·金光神焰》（seq 465–470）｜触发：单元 10-E 护法期间、`结丹` 后期遭遇战
- **叙事**：兽车降临，逆星盟六道极圣高徒温天仁携绝色少女（紫灵仙子）而来，逼韩立归顺神鸠堂未果，双方由此爆发**同阶顶尖对决**：紫云敛形 → 金针克虫 → 六极真魔功 → 阴魔斩破局 → 八门金光镜 → 金光神焰。本批停在此战未分胜负处。
- **玩法**：**双阶段高难 Boss 战**（同阶第一人级别的"境主战"）。
  1. 「真魔」阶段：温天仁的紫云能移形换位，普通飞剑穿云无效，玩家须**先逼出真身**（用虫群试探 + 花篮古宝接应），再以**阴魔斩**破除其位移（一次性大招，冷却极长）；
  2. 「金镜」阶段：温天仁祭出**八门金光镜**与金光神焰，远程光柱点杀 + 金焰持续灼烧灵力；玩家必须用**雷遁**闪避光柱、并用**护罩强化**（狼首如意参悟所得）抵抗灵力燃烧，**本关目标是"撑住"而非击杀**，撑到剧情触发即过关。
- **机制绑定**：**辟邪神雷**在此确立为"魔功克星"的核心身份（专破六极真魔虚影）；**青冥针符宝**（一次性符宝）作为限次道具引入。
- **角色植入**：**紫灵仙子**重磅登场——她认出韩立（辨出辟邪神雷源于当年她所赠天雷竹），神色复杂，成为后续剧情的关键人物。
- **奖励**：本批以**未完结的战斗**收束，作为下一批的悬念钩子（"金光神焰"之下的生死局）。
