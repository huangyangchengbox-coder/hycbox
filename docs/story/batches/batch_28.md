## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批整体挂在**化神境界**这一大阶段上（韩立由化神初期进阶中期）。

### 单元 28-A《灵地与洞府》（seq 1321–1325）｜触发：`enterMajor = huashen`（初入灵界）
- **叙事**：以"夺得灵地"开场，交代天渊城"灵地即修炼根基"的新规则；建双洞府（一明一暗）作为玩家**新手据点**的灵界版本。
- **玩法**：复用现有打坐吸灵气机制，把"洞府"做成**可升级的家园面板**——明府掩人耳目、暗府藏灵虫灵药；仙草移栽、灵虫催培为轻度经营循环。
- **奖励/技能绑定**：解锁"**啼魂兽**"召唤单位（化形/巨猿/恶鬼三态切换），并埋下"**掌天瓶**在灵界出液更快、异象更弱"的设定（打坐收益与隐蔽性双向增强）。
- **触发钩子**：单元尾声以"混沌万灵榜浮现玄天斩灵剑"的远景画面收束，作为全段最大悬念的引子。

### 单元 28-B《雷纹·拍卖会》（seq 1326–1339）｜触发：`huashen` 初期中段 / 首次坊市
- **叙事**：沼泽巡查（蛮兽人）→ 天渊坊市 → 雷木悟纹 → 恶客逼婚 → 三年一度蛮荒拍卖会。一段"边打架边搞钱"的**经营成长线**。
- **玩法**：
  1. **巡查关**：以"异灵盘"为雷达，巡逻途中随机遭遇圭虫群、古兽与蛮兽人，做成**波次防守**（韩立只出一次手，让玩家体验"队长镇场"）。
  2. **雷纹玩法**：把"天雷成木断面电丝"做成**轻解谜/拼图**——按切口顺序复原雷纹，成功即合成雷符道具。
  3. **拍卖会**：新增"**竞价 + 抵押**"小玩法，玩家以万年灵草作价竞拍真灵鳞片，体验"灵石即是战力"。
- **奖励/技能绑定**：解锁 **辟邪神雷·雷纹锦帕**、**雷纹之珠**、**雷袍**（本段核心输出与防御装），以及 **冰晶剑·噬灵天火灌注** 的强化玩法。
- **触发钩子**：`bossDefeated: huashen（蛮兽人）` 后开放坊市三区（药铺/太玄殿/拍卖行）；"真灵世家"幕后戏做成**片尾彩蛋**，为后续陇家线埋线。

### 单元 28-C《洞府取宝·骨手》（seq 1340–1347）｜触发：`huashen` 洞府事件 / 首次 `入侵警报`
- **叙事**：万珑珠监控发现入侵者 → 潜入莫名空间 → 玉骨人魔脱困、空间崩裂 → 抢骨手、得玉书。本段是**悬疑 + 秘境**的双结构。
- **玩法**：
  1. **监控玩法**：万珑珠阵把地图做成"**雷达图**"，玩家读光点、判方位、做取舍（先撤还是先探）。
  2. **秘境关**：空间障壁无法硬破，必须靠"太一化清符（虚化）"穿过——做成**限时隐形潜入**，虚化状态可移动但攻击即破。
  3. **脱困关**：与炼虚化身"搭便车"逃出，做成**追逐+拼贴合**（元磁神光粘附）；
  4. 收尾以**空间风暴**做演出级灾害事件（无需玩家操作，纯紧张感）。
- **奖励/技能绑定**：得 **骨手**（奇物）与 **百脉炼宝决** → 正式开启 **法体双修** 成长线，游戏内落地为"**肉身强化树**"（黑白双手 = 元磁山与五子同心魔的肢体化）。
- **触发钩子**：`huashen` 阶段触发一次 "**六十年闭关**"时间跳，宣告大事件（异族攻城）临近。

### 单元 28-D《异族疑云·飞升修士》（seq 1348–1353）｜触发：`huashen` 中期 / 天渊城日常
- **叙事**：绿影之战 → 异族频出、百族大战之忧 → 天广殿听道 → 飞升修士聚会与"危险任务"抉择。
- **玩法**：**守城段的主循环**。以"绿影讨伐"作为一次**狩猎 Boss 战**（影族克雷、破隐、分身三阶段）；聚会段落做成**多分支对话/情报交换**，玩家选择是否接危险任务。
- **奖励/技能绑定**：**成熟体噬金虫**在此首次亮相（并以"神念暗耗"设定**平衡其强度**）；**天广殿听道**做成一次性天赋加成或符篆解锁。
- **触发钩子**：`bossDefeated: huashen（绿影）` 且 `flyingYet 飞升修士好感 ≥ 阈值`，解锁"**危险任务**"入口，正式转入 28-E。

### 单元 28-E《五人组队·横穿蛮荒》（seq 1354–1363）｜触发：接取"危险任务"
- **叙事**：五人组队（陇东、筱虹、白眉青年、叶颖）→ 灵云舟远行（暗流：筱虹图谋叶颖天凤之血）→ 雷龟/雷暴 → 双皇猎龟 → 巨蜥毁舟 → 芝龙果夺果分果。
- **玩法**：
  1. **组队远征**：新增"**小队同行**"模式——五人各有专长（石化/血剑/黑凤/傀儡），玩家可**临时调度同伴技能**。
  2. **雷暴逃逸**：做成**限时冲刺关**（合力驱动灵云舟甩开雷暴）。
  3. **夺果战**：把"诱敌—取果—脱身"做成**三段式 Boss 机制关**（引开双怪、虚化取果、雷珠断后），是"引怪偷宝"型设计的样板。
- **奖励/技能绑定**：**雷纹之珠（批量）**、**血影遁**、**万年碧灵木**；同伴系统与"**互种标记**"作为组队信任机制。
- **触发钩子**：进入南艮大沙漠即触发转场 → 衔接 28-F。白眉青年在暗流中"心怀鬼胎"，为后续剧情反转埋伏笔。

### 单元 28-F《影族伏击·黑叶森林》（seq 1364–1370）｜触发：进入南艮沙漠 / 任务后半段
- **叙事**：沙海小城 → 紫云上人揭破（满城是蜃兽幻化）→ 沙漠激战 → 噬金虫立威 → 一线天汇合 → 独闯黑叶森林。
- **玩法**：
  1. **小城识破关**：以"火眼/明清灵目"识破幻境的**辨伪玩法**（在看似正常的人与景中找出影族傀儡）。
  2. **沙漠激战**：一场高强度的**多敌遭遇战**——同伴各自迎敌，玩家主导**韩立对赤影**的决战（蜃兽幻化 + 隐袭 + 破幻）。
  3. **噬金虫杀手锏**：成熟噬金虫做成"**限时爆发技能**"，威力极强但有**神念消耗代价**（符合原著设定）。
  4. **黑叶森林潜行**：以"梦罗树监测炼虚以上存在"为规则，做成**潜行关**（压低存在感、夜间行动、避开巨人巡逻）。
- **奖励/技能绑定**：**噬金虫群（爆发）**、**定风珠**；得"梦罗树·木族情报"这一**主线关键道具**。
- **触发钩子**：`huashen` 阶段收束点——取回木族情报推进主线，直接衔接下一批（seq 1371+）的木族/影族攻城主线。
