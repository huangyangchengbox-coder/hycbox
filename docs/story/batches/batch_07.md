## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。本批整体处于**筑基后期→结丹初期**，是「海外立足 → 结丹大成 → 炼成第一件本命法宝」的长线成长弧。

### 单元 7-A《登仙阁与小寰岛》（seq 271–273）｜触发：`enterMap = 魁星岛 / 小寰岛`
- **叙事**：以破旧登仙阁与挑剔的阁主交代"定居换修炼地"规则；韩立偏选灵气最薄、要自掏护岛灵石的小寰岛，只求一处不被打扰、可私用掌天瓶的窝。
- **玩法**：新增轻量「**定居选地**」——在圣山地图上白光点里挑修炼地，峰顶灵气高但常年有人挑战，小寰岛灵气稀薄却完全独处；系统提示"灵气−，安全+，需自担护岛灵石"。承接上批的灵地争夺。
- **机制绑定**：「**催药—打坐**」循环升级：因灵气稀薄，本段把升境收益进一步压到"丹药流"上，复现原著"靠服药而非吸灵气"的路线。
- **触发钩子**：抵达魁星岛后经顾家主线进入登仙阁；选中小寰岛即开启"孤岛苦修"时间跳。
- **备注**：以一段"四季流转·二十余年"过场直接横扫 273 章的长闭关，避免拖节奏。

### 单元 7-B《六连殿与婴鲤兽》（seq 274–283）｜触发：`bossDefeated: 婴鲤兽`
- **叙事**：天都街购物 → 六连殿以"降尘丹"为酬雇假丹修士协猎 → 布六遁水波大阵困住水系婴鲤兽 → 极阴岛乌丑半途夺丹、鬼头令牌暴露，敌方杀人灭口 → 韩立反杀结丹长老。
- **玩法**：做一场**多阶段 Boss 战「大阵伏妖」**：① 主持阵位关（六人各守阵门，挡住"水罡神雷"的密集弹幕，护住光罩读条）；② 触发剧情反水（乌丑夺丹、两名结丹长老转追杀），切换为**逃亡关**；③ 终局"**以阵杀结丹**"——把结丹长老引入预先布好的碧水青甲阵，借阵法压制后用飞针与一剑收尾，突出"以弱胜强靠阵法与预判"。
- **奖励 / 技能绑定**：**符宝（金剑符、蓝蛟符）**、五级内丹、中阶灵石；**混元钵**（首件可用的实打实法宝，映射为结丹期武器的过渡装备）。
- **触发钩子**：天都街白水楼对话触发委托；乌丑登场即转入遭遇战。建议做成"**限一次**"的剧情 Boss。

### 单元 7-C《海猿岛结丹 · 天星城》（seq 284–291）｜触发：`lianqi → jiedan` 破境前夜
- **叙事**：韩立择海猿岛闭关，曲魂先结煞丹、韩立自认无望；返小寰岛意外收得噬金虫；遭执法修士围杀、曲魂结丹威震；远赴天星城租下圣山三十九层洞府，安顿噬金虫与血玉蜘蛛。
- **玩法**：① **育虫 mini 循环**——测试虫粮/五金/灵石/奇虫死卵，只有"奇虫死卵"能让噬金虫略增，提示玩家"这虫子要吞奇虫才进化"，为后续大规模繁殖埋线；② 天星城作为**新主城/枢纽**开放，圣山八十一层按层给灵气加成，层数越高租金越贵。
- **奖励 / 技能绑定**：**噬金虫（群攻召唤）**入库但暂不可控（数万只仍弱），**血玉蜘蛛**升阶；**圣山洞府**给长期灵气加成。
- **触发钩子**：海猿岛闭关→结丹异象作过场；抵达天星城开放坊市、星空殿（传送）与后续租赁系统。

### 单元 7-D《外星海杀妖取丹》（seq 292–297）｜触发：`enterMap = 外星海妖兽岛`
- **叙事**：韩立购齐资料、拼单传动凝翠岛；以"霓裳草"诱妖、三阵合围，五年间斩五级妖兽数以百计；知足收手回城，两年炼药、散功修三转重元功，六十年闭关终金丹大成。
- **玩法**：核心是**"守株待兔"式刷怪关**——玩家在环形珊瑚岛布三阵，靠滴绿液催霓裳草展叶散发"诱妖味"把妖兽一只只引进阵；五级妖兽入阵后以傀儡阵、飞针与蛛网火蛇围杀。年份额过高会引来六级强敌（鸡冠蛟），教玩家"控制诱妖范围"。
- **机制绑定**：**三转重元功**落成"**散功—重练**"支线：主动把修为散回筑基初期再重练，换取更高的结丹成功率（数值上体现为"结丹判定加成"）。
- **奖励**：**金丹（结丹成功）**——本批的**破境终点**，解锁"丹火炼宝""中期法术/中级符箓"，寿元与境界阶跃。
- **触发钩子**：凝翠岛传送+霓裳草入手后开启；结丹异象作为本单元的收尾演出。

### 单元 7-E《妙音门劫案与极阴祖师》（seq 298–310）｜触发：`majorEvent: 极阴岛圈套`
- **叙事**：妙音门以天雷竹为酬请韩立助拳剿劫匪 → 夜袭"隐煞门"老巢却撞破圈套，乌丑实为极阴祖师**附身**，赵、孟长老倒戈，赤火老怪临阵反戈 → 韩立借妖尸脱身，天雷竹落空 → 紫灵仙子以另半截带根天雷竹聘他为"名义长老"。
- **玩法**：做一场**三方混战·附身 Boss**——玩家先与"隐煞门"误斗（可做一段"敌我难辨"的乌龙战），极阴祖师以附身之体登场后进入**多方乱斗关**：扛住"天都尸火"（高伤、点名秒杀，需走位躲）；赤火倒戈是**脚本级突变**，触发后立即切成**逃亡关**（被十八天都尸拦截，用傀儡与蛛网火蛇缚住再遁）。
- **奖励 / 技能绑定**：**天雷竹（带根）**+妙音门**长老腰牌/名义长老**身份（映射为"借势震慑、减少野外骚扰"的声望增益）；世界观图鉴收入"极阴岛/玄阴经/虚天残图/封灵柱"等条目。
- **触发钩子**：妙音门范静梅当街相邀开启；"附身"与"倒戈"两个反转做成连续的剧情节点。

### 单元 7-F《青竹蜂云剑与古遗址》（seq 311–320）｜触发：`enterMap = 古修士遗址`
- **叙事**：韩立以绿液把白雷竹催成**金雷竹**，易容开"青竹小轩"入世二十年、钻研炼器阵法，炼成七十二口**青竹蜂云剑**；乱星海暗流涌动，应金青之邀探古修士遗址，以阵破阵、斗"洪荒古宝"怪人，**噬金虫显威**，终见"封灵柱"。
- **玩法**：① 「**入世经营**」轻系统——青竹小轩卖自炼法器/符箓、观察凡人悲欢以磨心境（对应大衍决第四层的入世要求），同时积累炼器/阵法熟练度；② 「**炼宝**」玩法——布法阵、喷丹火、控七十二根火柱塑剑胚、滴精血与辅料，最后逐把刻微型法阵，做成一条**节奏化的多步炼器小玩法**；③ 「**以阵破阵**」关卡——用北斗两仪阵反向破解古阵，破到末层需用水属性法器对付"翅恶"火灵。
- **奖励 / 技能绑定**：**青竹蜂云剑（七十二口本命飞剑，可合化巨剑）**——结丹期核心输出装；**噬金虫（成熟群攻）**正式可驱使，一战吞尽"洪荒古宝"法器；**花篮古宝 / 封灵柱线索**与一幅神秘画轴作为钩子留白。
- **触发钩子**：天雷竹入手后开放"炼宝"；金青持珍珠来访触发古遗址线；噬金虫显威作为本批**战力检验**的高光点。
