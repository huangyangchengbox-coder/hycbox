## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 8-A《七霞莲陷阱》（seq 321–324）｜触发：`enterArea = 乱星海·海岛密殿`
- **叙事**：推倒封灵柱、下地洞见白骨与"仙草"，再由贪心采宝瞬间翻成剧毒惨案——一段典型的"古修遗址十步一杀"气氛。
- **玩法**：做**采宝解谜小关**——推柱（连点蓄力/机关）→ 厅中辨识真假灵药（观察白骨断指的伏笔）→ 采摘 QTE（失败即触发毒池伤害）。随后转**妖冠蛇 Boss**：可用血灵钻破其妖冠、再以飞剑钉首。
- **机制绑定**：尸变诈尸做成**事件惊吓 + 白骨傀儡精英怪**；胡月之死作为"队友可永久损失"的演出。
- **奖励/道具**：通关得**脂阳鸟画轴**（一次性/限次召唤，克鬼雾类敌人），为下一单元的鬼物战预埋手段。

### 单元 8-B《玄骨上人萧诧》（seq 325–328）｜触发：8-A 通关后剧情
- **叙事**：绿影鬼修登场，一眼看中韩立肉身 → 曲魂被夺、玄魂炼妖重塑少年 → 金雷竹灭魔箭登场 → 老鬼自报活了近千年的"玄骨上人"。
- **玩法**：做一场**机制剥夺式剧情战**——玩家可操控的召唤物（曲魂）被敌方夺占，短暂"敌我同源"，逼玩家在飞剑被克（黑雷压制）下撤离；血条归零可判"败而不死"续接剧情。
- **机制绑定**：本战把既有**辟邪神雷**设为隐藏克星（对鬼道敌人特效），同时**削弱**它（连用后需长时间静养）。
- **触发钩子**：老鬼遗留的**残图锦帕**入库，作为下一单元的导航道具；「萧诧」作为长期恩怨对象回调（其为极阴祖师之师）。

### 单元 8-C《虚天殿·聚宝大厅》（seq 329–336）｜触发：`enterMap = 虚天殿`
- **叙事**：故人重逢（文思月/文樯）→ 依图入漂浮仙殿 → 正魔元婴高手汇聚对峙 → 星宫执法长老立规矩 → 进第二关鬼冤之地。
- **玩法**：大厅做成**安全区/社交区**（禁用法宝，只能打坐与传音）——玩家在此"看戏"、收集情报、结交紫灵；进入鬼冤之地则转为**护送 + 探索关**：护住修为偏弱的紫灵，躲避游荡厉鬼。
- **系统绑定**：以大厅的"三百年一开"和阁楼规则，向玩家交代**限次取宝**的世界观；蛮胡子抢柱做成一次**不可抗的压迫演出**（忍让值 / 后续复仇伏笔）。
- **角色植入**：紫灵（同盟）、元瑶（神秘）、玄骨（危险盟友）、极阴（大敌）四条关系线同时铺开。

### 单元 8-D《鬼王合体之战》（seq 337–345）｜触发：`bossBattle = 鬼王（鬼冤之地）`
- **叙事**：鬼雾深处的鬼王历经五段变化——鬼影困敌、附灵合体成三首怪虎、怪笑震场——直到韩立解禁辟邪神雷一击灭魂；黑袍女修掀罩现出元瑶。
- **玩法**：做**多阶段 Boss 战**，核心是"**憋大招**"节奏：
  1. 一阶段：鬼影以玄阴鬼珠封法宝，逼玩家切换近战/傀儡；
  2. 二阶段：双头虎器灵（正面对拼）；
  3. 三阶段：附灵合体三首怪虎（怪笑=持续掉元气 debuff，克噬金虫）；
  4. 斩杀窗口：怪虎徒手抓剑时释放**辟邪神雷**电网，一次打空（并让飞剑进入冷却）。
- **奖励**：通关结好元瑶（后续啼魂兽、鸣魂珠来源）。
- **镜像机制**：噬金虫群啃食无形鬼体的设定，同时给出"会被吼声震落"的弱点提示。

### 单元 8-E《九曲灵参·玄骨暗计》（seq 346–352）｜触发：8-D 后、`event = 独立空间探宝`
- **叙事**：独立天地 → 小石山捕参 → 玄骨授网授阵 → 暗中定夺舍之计 → 当场反脸、阴魂丝封法 → 辟邪神雷反杀、逼交灵参。
- **玩法**：拆成两段——
  1. **捕灵小游戏**：以金丝网 + 布阵（四象玄武阵）困住灵参化身白兔；玩家需自行核验/替换阵旗（识破"阵旗做手脚"的细节）；
  2. **反杀剧情战**：玩家被人为封住法力，须靠"寄生鬼修自爆突脸"时的一次精准反制（辟邪神雷）翻盘。
- **机制绑定**：**盟友背叛**做成系统事件——玄骨的"合作"在取宝后自动转为敌对；灵参（九曲灵参）作为**结丹→元婴的破境辅助道具**入库，呼应后期凝婴目标。
- **奖励**：九曲灵参 + 与玄骨续盟（危险盟友状态），为下一单元的被迫拜师做铺垫。

### 单元 8-F《冰火道·内殿之门》（seq 353–370）｜触发：`enterMap = 冰火道 → 内殿`
- **叙事**：血玉蜘蛛暴露 → 被迫拜极阴门下 → 托天魔功登场、分宝立约 → 冰火道（熔岩/玄晶双线）→ 黑沙漠铁火蚁 → 宝光阁盗宝 → 极妙幻境 → 内殿开启、螳螂黄雀。
- **玩法**：本单元挂四个小机制——
  1. **双路线选择关**：熔岩路（火焰地形 + 罗烟步冲刺）与玄晶道（冰封地形），各带专属环境伤害与宝物需求；
  2. **虫海塔防/清剿**：噬金虫 ⊗ 铁火蚁的规模战，可升级为"虫群编队 vs 蚁群变形（长矛/利箭）"的对抗玩法；
  3. **限时取宝**：宝光阁球形光罩内只能取一件，玩家可尝试"黑甲"操作一次性拿两件（高风险高收益，失败即被传送）；
  4. **幻境心境关**：以仙音、幻象、亡故亲人白影层层试探；持有**婆罗珠/大衍决**为通过条件，考验玩家的"心志值"而非战力。
- **奖励/道具**：五色铜环（缠缚困敌）、暗红披风（高遁速但难控）、炼晶（强化法宝的材料）、婆罗珠/青冥针符宝/皇鳞甲（限时借用的保命符宝）。
- **触发钩子**：内殿石门开启 + 星宫二长老暗中尾随，作为**下一批（seq 371+ 虚天鼎取宝与多方夺宝）**的强钩子；元瑶"青火雷/三阳老魔"线留作后续。
