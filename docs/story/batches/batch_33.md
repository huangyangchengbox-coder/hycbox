# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 33 批

- **对应原著**：seq 1571–1620（原章号 1692–1744，"灵界百族 · 广寒界探宝篇"）
- **游戏映射**：`lianxu 炼虚（初期 → 后期顶峰）`，即**灵界首个"遗迹探宝 + 灌体跃迁"高潮段**

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 33-A《影晶窥敌 · 太乙青光》（seq 1571–1574）｜触发：`lianxu` 初入遗迹副本
- **叙事**：借映影晶远观巨傀儡与异族死战，角蚩族横插一脚；三人合破太乙青光禁制，韩立暗夺太乙青山。
- **玩法**：新增"**侦查**"轻机制——以映影晶远距标记敌群（即雷达/视野扩展），随后是**三人协力破禁**的多段节奏关（元磁符文逐层下坠，中断即前功尽弃）。
- **技能绑定**：强化 **元磁神光**（专克五行护盾）与 **噬灵火鸟**（吞灵破罩）；太乙青山落为**炼器材料**，指向第二座元磁极山。
- **触发钩子**：组队副本入口，需"元磁之体"标签；角蚩黑幕幻术做成**敌情不明**的压迫演出。

### 单元 33-B《仙府探宝》（seq 1575–1585）｜触发：遗迹副本 · 登山段
- **叙事**：禁空石阶的取宝之争、紫电封门、偏殿寺观、万剑图、药园"一触即灭"——一段紧张的**限时搜刮**。
- **玩法**：**限空登山**小关（离地越高越沉）；广场幻阵做**迷宫限时关**；药园采药做**采集挑战**（可移植的成片灵药 vs 一离土即灭的独株，考验操作与取舍）。
- **奖励**：甲衣草蒲团、黑幽冰香、万剑图、红罗果、蚀毒草、银色莲蓬；**惊蛰决 · 山岳巨猿**变身在此解锁（掷山破柱）。
- **触发钩子**：入紫殿即启动倒计时，石昆/柳水儿作**竞争者 AI** 抢宝。

### 单元 33-C《屏中洞天 · 灌体进阶》（seq 1586–1597）｜触发：主殿破门 / 首次"灌体"事件
- **叙事**：虚灵丹分宝、屏中洞天得丹、星空图幻境、光柱灌体一跃进阶、洞天崩塌逃生。
- **玩法**：**分赃/谈判**分支（虚灵丹归属）；**灌体修炼**做成高风险高收益机制——以"痛楚条/损血"换取修为暴涨，超时即爆体；星空图做**幻境意志关**。
- **技能绑定**：破境奖励 **炼虚中期 → 后期顶峰**；金身强化、**玄天残刃/玄天果实**（一斩碎金盘）；代价是法力尽失的**虚弱期**（限时 debuff）。
- **触发钩子**：`bossDefeated` 后触发；曲儿偷丹作**隐藏收益**彩蛋，奖励三百六十口飞刀。

### 单元 33-D《角蚩追杀 · 巨猿灭敌》（seq 1598–1602）｜触发：逃脱战 / 单人强敌战
- **叙事**：崩界分逃→角蚩金角青年一路追杀→银尺对剑阵→白钟颠倒乾坤→巨猿捏碎头颅。
- **玩法**：**1v1 多阶段强敌战**：躲阴灵矛 → 反破春黎剑阵 → 应对钟鸣的"颠倒乾坤"位移混乱 → 近身巨猿处决。
- **技能绑定**：**巨猿变身（近身爆发）**、梵圣金身**夺宝/吞宝**机制；战利品含混元尺。
- **伏笔**：小钟自爆牵出"角蚩图谋"，埋**跨界阵营大战**的线索。

### 单元 33-E《飞虹鱼 · 炼神术》（seq 1603–1613）｜触发：野图探索 / 潜入关
- **叙事**：巨湖飞虹鱼毒潮、混元尺炼成、救援月仙子、潜入密洞夺"炼神术"。
- **玩法**：**群怪毒潮关**（用克毒真火清屏）＋**挖矿/炼器**经营（矿石→混元尺）＋**潜行潜入关**（太一化清符虚化，避哨卫与预警巨刃）。
- **技能绑定**：**噬灵火鸟（金乌真火）**克毒；**混元尺**；**洞漩金光**（吞噬敌修）；**炼神术**（神念/侦测范围增幅的长期成长线）。
- **触发钩子**：月仙子/胥老者支线，地图玉简作**任务道具**；偷听哨卫触发"广寒令解禁"情报。

### 单元 33-F《出界 · 云城之乱 · 各得其所》（seq 1614–1620）｜触发：世界事件 / 大版本过渡
- **叙事**：参悟炼神术、击暗兽夺丹、被送出广寒界、云城陷落、虚灵宝鼎托付、伏蛟城灵药换宝。
- **玩法**：**世界事件"云城之乱"**（大战场演出 + 撤离任务）；**交易系统**（用灵药换灵丹/材料/晶月液/极品灵石）。
- **技能绑定**：豹麟兽**吞噬升级**（暗兽妖丹）；超级传送阵作**跨地图钥匙**（雷鸣大陆→风元大陆）。
- **触发钩子**：大乘翁姓青年发布**长线任务**（送信冰魄仙子）；向之礼"青蛟峰之约"埋钩，衔接后续批次。
