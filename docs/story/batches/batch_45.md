## 二、游戏情节设计（本批 · 终章）

> 设计原则：**不推翻现有玩法**。本批既是"真仙入侵"的下半场，也是全书收束段；除常规"叙事插入 + 关卡目标绑定"外，**单元 45-F 额外承担游戏终局演出（道祖大圆满）**。

### 单元 45-A《真仙降世·风元危局》（seq 2171–2173）｜触发：`enterMajor = dasheng`（进阶大乘后）
- **叙事**：开场即"灾难片"——真仙马良几乎无伤屠灭一族、抹平商盟据地，用"不可战胜"的压迫感为终章定调。
- **玩法**：做一段**非对抗的压力演出关**：玩家在有限时间内撤离 NPC，躲过血河横扫（擦边即重伤），全程无法反击，只能"看"。
- **奖励/线索**：解锁"两仪灭尘阵"世界观条目；埋下韩立"提纯辟邪神雷可破虚空"的伏笔（作为后续破界关卡的门票）。

### 单元 45-B《天外天·两仪灭尘阵》（seq 2174–2183）｜触发：`bossDefeated: dasheng`（首次）
- **叙事**：群强齐聚、引君入瓮、阵眼死局——韩立从"被当弃子的守阵人"打成"亲手破局的斩鹿者"。
- **玩法**：**双线关卡**。
  - 主线：玩家先镇守阵眼，以**布阵小游戏**（在金柱上放置灵纹节点）把自身设为"豁免区"，此为后续活命关键；
  - 支线：斩阳鹿战——以"金罡砂对黄沙"的**属性克制**阶段开场，中段破巨掌，终段变身**真魔之体三阶**（三头六臂 + 玄天斩灵剑）收尾。
- **技能绑定**：解锁 `真魔之体` 变身与 `辟邪神雷` 破空；`血契` 系统升级为**可对同境界目标生效**（六翼一战的教学）。
- **触发钩子**：单元完成即锁定"阵眼弃子"隐藏剧情（明尊与影子的密谈回放）。

### 单元 45-C《真仙之身·血玺与自爆》（seq 2184–2190）｜触发：45-B 完成后
- **叙事**：真仙解封 → 灵域压场 → 血玺逞威 → 群强尽陨 → 大阵自爆。这一段是**全书规模最大的"群像覆灭"演出**，务必做出"强者如蝼蚁"的落差。
- **玩法**：
  - **必败协作战**：玩家与数名 NPC 大乘共同抵挡万灵血玺（BOSS 血条不为零，只求撑时限），逐个看着同伴倒下；
  - **献祭逃生关**：阵眼自爆倒计时内跑向"豁免区"，跑错区域直接团灭（对应韩立与云淡月梳的不同结局）；
  - **金蝉脱壳小游戏**：操控噬金虫王在金色甲士围困中脱身（限时、闪避向）。
- **奖励**：`掌天瓶` 线索正式回收——马良手中"盗天瓶"与玩家所持瓶身共振，引出**瓶灵**关键词。
- **触发钩子**：任意结局分支后均进入 45-D。

### 单元 45-D《斩仙·天魔契约·第一大乘》（seq 2191–2196）｜触发：45-C 完成
- **叙事**：斩仙三部曲（断指—破幻—斩首）+ 天魔契约 + 威震灵界。终章的第一个大高潮。
- **玩法**：**三阶段终局 Boss 战**，对应原著三章：
  1. **斩仙（上）**：青蟠剑阵牵制血龙，玩家以玄天斩灵剑消耗真仙护体；
  2. **斩仙（中）**：破银笛幻境（玩法为**心魔清屏**——用元婴清凉之力点亮神识）、瞬移追击；
  3. **斩仙（下）**：真魂丹爆发 + 天外魔头并肩的混战，用"洞漩金光"定身 + 一剑斩首。
- **机制绑定**：战后与**魔光、火须子**缔结契约——二人成为可切换的**随行战斗单位**（魔光偏控制/吞噬，火须子偏火焰 AOE），契约附加"精血维护"的资源消耗。
- **奖励**：`真魂丹` ×2、`本命牌`（开启下一段支线的关键道具）；境界评定更新为"灵界第一大乘"。

### 单元 45-E《瓶灵·龙岛·道果》（seq 2197–2205）｜触发：45-D 完成 → `enterMajor = dasheng` 后期
- **叙事**：了结封印仙人旧案、魔源海七日夜收回瓶灵、龙岛交换会与道果大会夺牌。为飞升做**资源与力量的总决算**。
- **玩法**：
  - **瓶灵收服战**：非致命"追逐/融合"小游戏，瓶身不断弹开瓶灵，玩家逐步缩小包围圈（七日七夜被压成一场多阶段缠斗）；
  - **道果大会 = 限时夺牌竞技场**：以掌天瓶为主动技能（符文牵引、锁链束缚、冰封道具牌），在有限时间内从 NPC 强者手中夺满道牌；
  - **交换会**为**交易/图鉴系统**的一次展示（以真魂丹换取"真麟留影"，可预览飞升天劫的实战样片）。
- **奖励**：`广灵道体`（回蓝/回灵永久加成）、`炼神术·第三层`（解神识隐患）、`元合五极山`全件；`天魔契约`随行单位扩至双灵。

### 单元 45-F《归途与飞升》（seq 2206–2211）｜触发：`enterMajor = 飞升`（终局）
> **本单元为游戏终局演出**，对应 `daozu 道祖` 大圆满。

- **叙事**：八千年一瞬——先回人界了却旧缘（故人凋零、宗门兴替），再于荒岛迎战飞升天劫，最后在光柱中消失。基调由"征战"转为"告别与登临"。
- **玩法（三幕结构）**：
  1. **第一幕·了却旧缘（叙事怀旧层）**：可自由重访早已解锁的地图（七玄门、黄枫谷、乱星海、坠魔谷），触发旧人旧事的回忆贴片；收集"北极元晶"完成最后一件本命法宝。此幕**无战斗**，只做情感收束。
  2. **第二幕·飞升之劫（终局无尽车轮战）**：**天劫三段式车轮战**——天罡风（持续削减的灵气条）、熔岩雨+冰火巨鸟（属性相克解谜）、紫金雷劫（`元罡罩`格挡 + 元合五极山吸雷）。全程不再有"逃"的选项，只有硬扛；每渡一劫，境界评定跳一档，直至满格。
  3. **第三幕·登门（终局演出 / 道祖大圆满）**：最后一道七色劫雷落下——玩家所持玄天斩灵剑**当场断裂**，屏幕白屏；随后仙界之门开启，光柱裹身，所有随行单位（魔光、火须子、蟹道人、噬金虫王）依次没入其身；镜头拉远，南宫婉等人自远处赶来却只能望见遁光消失。终章滚动字幕，定格于"在下高升，欢迎道友飞升来到北寒仙域"，**游戏主线完结，境界定格 `daozu 道祖` 大圆满**。
- **奖励 / 结算**：`飞升者`称号、全图鉴解锁、随行单位合体技"诸灵归一"、结局画廊回放（可单独回看人界旧地探访与三幕天劫）。
- **触发钩子**：通关后开启"轮回"存档位（继承少量资源重开），并解锁隐藏结局文本（瓶灵、蟹道人前主人心愿等待补完的悬念）。
