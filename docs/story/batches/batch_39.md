# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 39 批

- **对应原著**：seq 1871–1920（实物顺序；原书章号自 1875 直接跳至 1877，缺 1876，故本批 50 章的原章号区间为 1871–1921；另有三章原文未标章号，按实物顺序计入）
- **游戏映射**：`合体（中期）` → `合体后期前夜`，即**灵界"魔灾爆发 · 天渊城—倚天城连环保卫战"段**
- **剧情弧**：深海血茧青年出关、木族圣地震慑大长老 → 魔斑破界、群魔立城 → 韩立交付擎天巨舟并留守天渊城首战（七星精火）→ 与银光仙子驰援倚天城，途中三魔追杀反被全歼、夺得太古秘宝"镇魔锁"→ 倚天城外万象魔骑围城、五阳化月之日总攻 → 韩立破七层宝塔、血光圣祖隔空传念
- **说明**：梗概均为原创改写，非原文摘录

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。

### 单元 39-A《魔劫前夜 · 与世家的交易》（seq 1871–1875）｜触发：`合体中期` 达成 / 首次 `bossDefeated: 合体`
- **叙事**：冷开场——深海血茧与蛮荒墨虫青年出关闭环"真灵之躯"线；木族圣地被白裙女子压倒，暗示敌方高层格局。随后转回韩立：迁府、托孤、以灵乳换巨舟。
- **玩法**：主界面新增"**魔斑倒计时**"条（本批全程可见，随剧情推进由绿转红）；"迁府"做成一次**资源搬运小玩法**（在限定步数内把门人与物资装上巨舟）。
- **奖励/技能绑定**：解锁功能型载具**擎天巨舟**（可乘可守，需数百门人共同驱动的"人海炮台"）；解锁**龙灵丹**（破境概率小幅加成）。
- **触发钩子**：`enterMajor = 合体`，且完成一次与"世家权贵"的**讨价还价对话小游戏**（三回合让价，成功可省一批材料）。

### 单元 39-B《群魔破界 · 立城》（seq 1876–1880）｜触发：单元 39-A 完成后强制过场
- **叙事**：敌方的"开场演出"——蝠翼少年、牛头巨汉、童子与魔蟒、百万魔虫、上百座三角巨塔、血光圣祖登坛布魔气。
- **玩法**：做成一场**不可胜的观战关**（玩家操控韩立在城头遥望，目标是"存活并观察"而非击杀），期间穿插"魔气护罩"机制演示：进入魔气范围的敌我单位恢复加速，为后面战斗埋下地标概念。
- **机制绑定**：新增敌方族群图鉴条目（血蝠/雷牛/三目魔蟒/魔虫/石魔/珈轮战魔），击败对应敌人可逐步点亮，凑齐图鉴给永久属性。
- **触发钩子**：`storyFlag = 魔斑破界`；完成后解锁"据点守卫"日常玩法（在若干人族小据点中任选一处守城）。

### 单元 39-C《天渊城守卫战 · 七星精火》（seq 1881–1885）｜触发：首次进入据点守卫 / `waveCount >= 3`
- **叙事**：一次典型的"试探—硬拼—放杀手锏—对方改策略"四段式攻防，让玩家第一次直观看到魔族真正的战术（消耗战）。
- **玩法**：**塔防式多层防线**——金色光幕（可被洞穿）→ 阵盘电弧（对兽潮）→ 城墙傀儡/雷网 → 最后手动触发一次"**七星精火**"全屏清场技（每场限一次，冷却以"局"计）。
- **奖励**：通关得"**精火符**"（一次性全屏道具）与"金旭宝镜"碎片；连续守住 N 波可解锁"**轮值长老**"身份（获得城内资源折扣）。
- **触发钩子**：`bossDefeated: 兽潮波次`；失败不结束主线，但"据点耐久"会下降并影响后续奖励额度。

### 单元 39-D《驰援倚天 · 血战三魔》（seq 1886–1897）｜触发：`合体中期` + 完成"传送点伏击"小事件
- **叙事**：全批最完整的一段**追杀反杀**：险地伏击 → 血脉追踪 → 三魔围杀 → 逐个反杀。收尾留"镇魔锁"悬念。
- **玩法**：做成**三阶段连战 + 移动战**——
  1. 传送点伏击：定住弩箭后"反掷"的**限时反弹小游戏**；
  2. 追逃段：骑乘/飞行**追逐关**（韩立四翅银鹏 vs 血虹），命中足够次数才能拦截；
  3. 三魔战：**一对一→一对二→一对三**的三轮 Boss，敌方可变身（三头六臂/母魔）与召唤（天鬼/子母真魔）。
- **奖励/技能绑定**：解锁**辟邪神雷**（对魔族/阴鬼系克制）、**洞漩金光**与**玄天残刃**（法则一击，长冷却大招）；战利品"**修魔天鬼门**"可做成一次性召唤道具。
- **触发钩子**：`bossDefeated: 魔族尊者` ×3；通关后建议回调旧剧情节点（玲珑/银月线），为后续"传信"伏笔。

### 单元 39-E《倚天城 · 镇魔锁之谜》（seq 1898–1907）｜触发：进入倚天城地图
- **叙事**：先以万象魔骑围城制造压迫感，再转入两场"密室戏"——人族密议（血魂符/凶兽）与木盒探秘（车骑恭/镇魔锁），一攻一守的信息差是本段最大看点。
- **玩法**：
  - **木盒解谜**：轻量"**逐层拆封**"文字解谜（每破一层解锁一段世界观对话），共十三层，本批只开放前三层；
  - **问答交易**：与车骑恭的"一问换一问"做成**对话博弈**（每次提问与回答消耗/获取"情报点"，选错则对方动怒，需以言语化解）。
- **奖励/机制绑定**：获得道具"**镇魔锁**"（不可主动使用，作为长期任务道具）+ 世界观图鉴条目"混沌阴阳二气""黄泉地火/阴阳冥池"。
- **触发钩子**：`enterMajor = 倚天城`；持有"镇魔锁"后开放隐藏材料点"**黄泉地火**"（后续批次将据此展开抽取混沌二气的玩法）。

### 单元 39-F《倚天之战》（seq 1908–1920）｜触发：`五阳化月` 天象事件（一次性）
- **叙事**：本批总高潮，五幕结构——四魔尊叫阵 → 开战与斩杀最弱魔尊 → 阴阳二刹出手把主角关进七彩宝塔 → 我方放出凶兽合息兽 → 塔内突围与"圣祖魔音"逼退。
- **玩法**：做成**长线分区战场**——
  1. 城头篇：与万象魔骑/珈轮战魔的多波守城（引入"三禁"执法机制：临阵脱逃者扣分）；
  2. 尊者篇：四魔尊各有一套破法（火甲巨人怕控场、白袍少年怕火系、娇小女子怕高爆、黑甲大汉怕"巨力对拼"）；
  3. 塔内篇：**七层爬塔**（每层傀儡等级递增，琉璃层需先用灵虫吸灵力再强攻），并加一条"被偷袭"随机事件链；
  4. 决战篇：时间流速差的剧情演出 + "圣祖魔音"造成的**眩晕/操作失灵**负面状态（限时挣脱）。
- **奖励/技能绑定**：解锁**青蟠龙剑阵**（阵地战）、**紫纹噬金虫群**（吸灵力/啃甲）、**失神刺**（打断）；通关奖励倚天城四大宗门的"厚礼"（大批灵石与珍稀材料）与**合息兽**相关线索。
- **触发钩子**：`bossDefeated: 魔族尊者` 累计达 5；"五阳化月"仅触发一次，未通过则改为"据点陷落"分支（可重试但奖励减半）。
