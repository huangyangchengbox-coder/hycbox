## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「秘境入口 + 关卡目标绑定 + 势力同屏事件」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 21-A《阴阳窟寻马》（seq 971–981）｜触发：`yuanying` 中期、通关"坠魔谷"后
- **叙事**：以"培婴丹"为饵的组队悬赏——五名元婴中期立下冥河之页毒誓、佩紫幽珠潜入七大绝地之一的阴阳窟，猎取来无影去无踪的阴芝马。
- **玩法**：把阴阳窟做成**多人编队秘境**：三条分岔通道（分头探索）、"惊魄阴风"环境压力条（持续掉法力，需回富姓老者处续"紫幽神光"buff）；阴芝马是**限时追猎目标**（隐匿、逃逸、可被尸狼驮走）。
- **奖励/技能绑定**：新丹药「**培婴丹**」（服用需闭关，显著提升元婴突破率）；解锁环境型增益「紫幽神光」；拾取古蓝飞剑（炼器材料）与三块黑晶（阴属性材料）。
- **触发钩子**：地图解锁"万毒谷—阴阳窟"；第一块黑晶到手即开启"风穴支线"。

### 单元 21-B《银翅夜叉》（seq 982–989）｜触发：21-A 击退变异尸狼后
- **叙事**：小队被煞魂丝干尸割裂，元姓大汉一个照面丧命，韩立在困魔古阵中遭遇"人界炼尸中仅次于金身月尸"的银翅夜叉——境界再高也有克星。
- **玩法**：**四阶段 Boss 战**——
  1. 干尸群（煞魂丝吸灵力、污法宝，必须用辟邪神雷破招）；
  2. 幻术关（银瞳幻术，须以明清灵目找破绽，否则一直被"鬼打墙"）；
  3. 困魔法阵内"光球不死身"——只能用降灵符爆发 + 巨剑术 + 晶化飞针破镜；
  4. 金遁追击战（韩立雷遁 vs 夜叉风遁，限时拉锯，失败则脱战）。
- **奖励/绑定**：绑定并强化已有的**辟邪神雷 / 三焰扇 / 降灵符 / 冰焰之精 / 啼魂兽（食鬼）**；掉落"邪月幻镜"碎片（幻术·镜像类道具）。
- **伏笔**：银翅夜叉、玄岩龟、狮禽兽三妖与"困灵阵—本命牌"设定入库，为后续同屏事件铺线。

### 单元 21-C《昆吾山入场》（seq 989–1008）｜触发：21-B 通关 / `yuanying` 中期
- **叙事**：古阵异动把韩立抛入被巨大光幕封印的昆吾巨山——一座"资源岛"，却死气沉沉、灵气惊人，且同时涌入叶家、毒圣门、阴罗宗、天澜与诸多妖物。
- **玩法**：**开放式多层秘境**（白玉广场 → 十几条石阶分支），两条硬规则：**神识被大幅压制** + **禁空禁制**；支线小副本如"彩云幻境"（藏物化形，炼化五色珠破阵）、"铸灵堂 / 化灵殿"（解阵取宝、与通灵器物斗法）。
- **奖励/绑定**：道具线——**太阴真火**（人界三大真灵之火）、通灵火鼎（召火鸦群）、昆吾晶碑（未解古文，待后续水落石出）、金磁灵木与蛟龙火柱（顶级炼器材料）；关系线——"分丹"事件提升富、白二人好感。
- **触发钩子**：以"山洞传送阵"为回城点（单向，出去需另寻路）；北方石阶标记为昆吾殿方向，作为本批终局入口。

### 单元 21-D《各方汇聚·昆吾殿外》（seq 1009–1015）｜触发：完成 21-C 任一探索点
- **叙事**：乾老魔、毒圣门、天澜、化仙宗与三妖在昆吾殿前轮番登场，临时结盟又互相算计；叶家阵营内部古魔反水。
- **玩法**：**多方势力同屏的竞速/混战关**——玩家与 AI 势力比谁先破禁、先抵殿门；新增移动限制机制「**金磁重光**」（磁力加重，金属性法宝落地不可用，需以肉身/木石类法宝硬扛或砍树破阵）。
- **奖励/绑定**：**势力倾向选择**（随叶家 / 随三妖 / 独行）影响后续剧情分支与可拾取物；此处集中展示三焰扇的"一扇惊敌"定位技与降灵符的形态爆发。
- **触发钩子**：广场上现身的"天澜圣女"作为长期仇敌追踪事件，可做成跨批的追捕/悬赏玩法；"须弥五行壁""四象尺""日月梭"入库为后续道具线索。

### 单元 21-E《元刹圣祖与化龙玺》（seq 1016–1020）｜触发：21-D 通关 / 进入昆吾殿
- **叙事**：古魔灭杀叶家老者、唤出封在镇魔塔的元刹圣祖化身；昆吾殿内四方抢宝，残图中昆吾三老所留神念一击抹去木魁，最终化龙玺引出一柄玉尺化出漫天七彩佛莲。
- **玩法**：**终局"夺宝"复合玩法**——
  1. 穿越"北极元光"（无对位道具即秒杀，需两仪环一类宝物开路）；
  2. 圣殿遗念试炼（殿图残念自动护宝，误触即遭反噬）；
  3. 四方夺宝限时混战（韩立 / 木夫人 / 乾老魔血影 / 三妖各抢不同物件，按件计分与结算）。
- **奖励/绑定**：关键道具「**化龙玺**」（控制昆吾山封印）、备用「天晶碑」、血色木牌与红光书卷、降魔杖；世界级 Boss 预演「**双首银狼·元刹圣祖**」（下一批的正面对决目标）。
- **触发钩子**：引出"上古巨魔"主线与"封魂咒解咒"支线（韩立盯上乾老魔所修的逆情断天与阴罗宗解咒法决）。
