## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情挂在「关卡之间的叙事插入 + 关卡目标绑定」上；每个单元对应一次触发，境界节点对齐 `结丹` 段。

### 单元 9-A《虚天殿取宝》（seq 371–381）｜触发：`结丹` 首次进入「虚天殿」副本
- **叙事**：以蛮胡子砸碎狼首傀儡开道，把"内殿是元婴老怪的猎场、结丹修士只是随行"的压迫感立住；金丝蚕借天青花作弊拖鼎失败、正道去而复返，随后是元婴混战与古宝分飞。
- **玩法**：做成**多目标限时副本**——玩家操控韩立，目标不是打赢，而是"跟着大佬走 + 捡漏"。傀儡残骸为可拾取收集物（用于后续傀儡研究）；台上金丝蚕拖鼎是**一次失败演出**（进度条拉到 60% 后强制崩断）。
- **奖励**：狼首傀儡残骸、绿宝石、三只半废金丝蚕、狼首玉如意（古宝，本批最重要道具）。
- **触发钩子**：`bossDefeated: 结丹初期` 且持有[虚天残图]，开放"虚天殿·内殿"；古宝之争做成**抢宝小玩法**——火狼在场上游走，玩家用花篮/五行环时机判定捕获，失败则被 NPC 夺走。

### 单元 9-B《补天丹·玄骨之死》（seq 382–389）｜触发：单元 9-A 通关
- **叙事**：全批最高潮——星宫化身符突袭斩血玉蜘蛛、补天丹被元婴夺走又反夺、玄骨逼盟再取宝鼎、翻脸合炼修罗圣火、圣火反噬身死。
- **玩法**：**两阶段 Boss 战**。
  1. 「取宝」阶段：玩家操作蛛丝张力条，与玄骨的鬼火黑莲配合分离乾蓝冰焰（左侧焰压、右侧拉力双轨）；
  2. 「玄骨」阶段：以辟邪神雷对抗乾蓝冰焰/修罗圣火，核心乐趣是**神雷见底与圣火失控的赛跑**——一味拖延必败，逼玩家在最后时刻引爆电网脱身。
- **机制绑定**：新增**古宝槽位**（五行环·锁定 / 花篮·收物 / 狼首玉如意·召唤），并引入「辟邪神雷」作为**可耗尽的限次资源**。
- **奖励**：虚天鼎（封印态收藏品，暂不可用）、乾蓝冰珠（高阶火种线索）、玄骨肋骨（后续解锁功法）、五行环固化为常驻古宝。
- **伏笔**：修罗圣火失控提示"强行合成的高级火种会反噬"，为后续乾蓝冰焰炼化留出成长线。

### 单元 9-C《画轴脱身与乱星海变局》（seq 390–400）｜触发：单元 9-B 通关、`结丹` 中段
- **叙事**：夹墙画轴暗道逃生 → 密室撞见元瑶 → 以养魂木根须与万年灵乳达成交易 → 出殿后得知逆星盟起兵、南明岛失守。
- **玩法**：**密室探索 + 谈判**双段。探索段走"画轴地图"限时潜行（避开老怪神识）；谈判段做成**无战斗的选择对话**，玩家在"独吞 / 交易 / 强抢"间取舍，影响后续资源与元瑶好感。
- **技能绑定**：**狼形器灵**（召唤红狼/黄狼，其中黄狼附赠土遁位移）、**噬金虫侦查**（用于查找身上暗记，可做成"扫身"小交互）。
- **奖励**：万年灵乳（瞬回满法力，限次）、养魂木根须（神识成长）、画轴（永久地图类道具）。
- **世界观入库**：天星令 / 逆星令 / 天星双圣 / 逆星盟，作为图鉴条目；庄重的"大战前夜"过场后，城门前给出**两条路线选择**（助战 or 闭门不出）。

### 单元 9-D《偷渡外星海》（seq 401–406）｜触发：单元 9-C 结束、`结丹` 中段
- **叙事**：星宫以"击杀一名同阶"为传送门槛；韩立转而钻营暗门——偷听、定计、乔装混入、要挟联络人，最终骗上真传送符离城。
- **玩法**：**轻潜入 + 伪装玩法**。玩家用炼气敛息术压低修为显影（UI 上修为标签可伪造），沿途避开盘查；关键节点是"要挟对话"——选择正确把柄（合谋抬价的情报）才能让 NPC 就范。
- **机制绑定**：新增**身份伪装系统**（可伪造姓名/修为/腰牌，被高阶神识扫描则暴露）、**传送代价机制**（跨海传送需付出古宝或完成击杀任务）。
- **奖励**：厌瑙兽情报（神识探测预警）、外星海航线图；隐患是"妙音门长老"这个假身份从此顶在头上，成为后续追踪线。

### 单元 9-E《黑石城·雾海立府》（seq 407–414）｜触发：抵达 `奇渊岛`
- **叙事**：黑石城的畸形繁华（禁斗、炉鼎拍卖、幼卵交易）→ 寸金阁问药得"伴妖草须取自八级妖兽身畔" → 远遁雾海择岛立府 → 整理虫室、以五色圆珠试虫、开玄阴经。
- **玩法**：把黑石城做成**主城枢纽**——拍卖行（竞宝）、原料铺（寸金阁问古药名，做成"古名对照"解谜）、情报铺（海图与妖兽出没）。出海前是**采集布置玩法**：在雾海岛上布幻阵、种灵草、开虫室。
- **成长系统**：**虫室经营**升级——噬金虫分两批培养（进化分支）、金丝蚕赌幻焰蛾（低概率高回报）、啼魂兽（抽魂专用）。
- **技能绑定**：**玄阴经**在此到手，解锁数门结丹期可修的魔道秘术（并附赠"天都尸火"弱点图鉴）；**霓裳草**成为引妖钓鱼的核心道具。

### 单元 9-F《化形之劫·虫魔之名》（seq 415–420）｜触发：`结丹` 后期、首次出海捕妖
- **叙事**：妖龟渡劫、毒蛟护法、三方围杀 —— 一场远超韩立层级的"神战"演出；此后他靠霓裳草布阵屠妖取丹七年，终成人人谈之色变的"虫魔"。
- **玩法**：**钓鱼式捕妖循环**（本批的主要 farm 玩法）：在珊瑚礁布四座法阵 → 种霓裳草按年份引妖 → 视妖兽等级决定"困杀"还是"弃阵撤退"。化形雷劫做成**限时旁观事件**，玩家可选择趁机偷袭或立刻远遁（偷袭击杀八级妖兽为高风险高回报的隐藏挑战）。
- **技能绑定**：**噬金虫·三色巨矛**（虫群聚形远程锁定）、**五行环**（配合阵法定身必杀）、**青竹蜂云剑**（炼晶完成后坚硬不可毁）。
- **奖励**：六级妖丹、虾鳌、琉璃兽皮（护甲材料）、凶名系统解锁——"虫魔"称号带来 NPC 遇玩家时的恐惧逃跑 AI，也是一种玩法资源。
