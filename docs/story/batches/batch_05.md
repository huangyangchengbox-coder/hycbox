## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每若干章归为一个**剧情单元**，每个单元对应一次触发。
> 本批承接第 01 批（seq 1–20）的"新手引导段"，进入游戏第一个以**副本式试炼 + 破境筑基**为核心的阶段。

### 单元 5-A《备战与七派聚首》（seq 171–179）｜触发：`lianqi` 达十一层、首次进入"试炼入口"
- **叙事**：开篇即以"两难抉择"定调——手握筑基丹，却要赌命去采药。随后切入七派聚首、结丹师祖以打赌开局，把"修仙界的残酷与实力至上"用一场师祖对话讲透。
- **玩法**：做一个轻量**准备关卡**（采购/整理法器、随机抽一件上品法器）+ 一段**押送过场**（乘银甲角蟒飞行），把玩家从黄枫谷带入"禁地外围"新场景。
- **关键设定绑定**：本单元正式引入**"破禁入场"**这一机制——风刃大阵由七尊师祖法宝强开通道，玩家须在通道收窄前冲入（限时穿越大门）。
- **伏笔**：穹老怪、血线蛟内丹、掩月宗"异常年轻成双"的弟子，全在对话里埋线，供后续单元回收。

### 单元 5-B《禁地乱战·丝线与封岳》（seq 180–190）｜触发：进入"禁地"副本后第一次遇敌
- **叙事**：随机落点 → 旁观他派厮杀 → 一线天遭围 → 透明丝线初显锋芒 → 遭遇十三层狂人封岳，靠天雷子险胜 → 意外拾得踏云靴。
- **玩法**：把禁地做成**Roguelike 式乱战副本**：随机传送落点、隐藏资源点（寒烟草/未成熟灵药）、游荡的敌对弟子 AI。核心战斗目标"在有限法力下连战或绕行"。
- **技能/道具绑定**：本单元解锁两件关键物——
  - **透明丝线**：绑定"近身瞬杀"技能，对无护罩目标一击致命，呼应丝线斩首、灭口、斩赤脚大汉三处名场面；
  - **踏云靴**：绑定**位移/闪避强化**，把"身法快到近乎隐形"做成可操作的高机动状态（短期爆发、有体力条）。
- **Boss 战**：以**封岳**为单元小 Boss，设计"黄罗伞反弹 + 高速位移"的压迫感，逼玩家祭出一次性的**天雷子**（消耗型大杀器）收尾——让玩家亲自体会"底牌有限"的资源焦虑。

### 单元 5-C《中心区与环形山》（seq 191–203）｜触发：抵达"中心区"后，与 NPC 钟吾交互
- **叙事**：花园外层 → 与钟吾虚与委蛇互换资料 → 月阳宝珠驱雾、环形山现形 → 采药支线（紫猴花·诱杀巨蜈蚣）→ 救菡云芝 → 与武痴一战 → 灭口与无忧针。
- **玩法**：
  - **"资料交换"系统**：可与其他门派 NPC 交换图鉴，但对方给的资料可能不完整——呼应原著"心照不宣的遗漏"，给探索加不确定性。
  - **采药小玩法**：以"未成熟幼苗 + 催熟"为核心——玩家在场景里优先采集价值低的幼苗，回谷后用**掌天瓶**绿液催熟（复用第 01 批已埋的掌天瓶钩子），构成独特的"低价值资源→高价值产出"策略链。
  - **妖兽战**：巨蜈蚣设计为"不可硬拼、须诱入陷阱开膛"的机制战（利用地形/预设利刃），区别于正面输出型敌人。
- **剧情选择挂钩**：救菡云芝 → 武痴比武 → 灭口抉择——可在对话里给玩家一个**"保命优先"的默认分支**，并用"无忧针/忘尘丹"的设定把"秘密不该外泄"具象为一段可跳过记忆的演出。

### 单元 5-D《墨蛟之战与南宫婉》（seq 204–209）｜触发：进入"地下沼泽"绝境副本
- **叙事**：本批高潮。石殿地道 → 地下沼泽观战 → 墨蛟化蛇为蛟、通道被封 → 韩立与南宫婉被迫联手 → 合一战一景 → 破禁回归。
- **玩法**：
  - **双人协作机制（首次）**：首次引入**"借法"**设定——南宫婉把法力暂渡给韩立，使其临时升到十三层。可做成"限时增强 buff + 双人合击"：玩家用南宫婉的法宝拖住墨蛟，自己在窗口期以金光砖输出。
  - **Boss 设计**：**墨蛟**做成本批最主要 Boss，具备**形态进化**（一阶→二阶化蛇为蛟）与"紫液秒杀"机制，逼迫玩家走位与把握输出窗口。
  - **绝境"通道封闭"**：用"小五行须弥禁法"封死退路，制造"不打也得打"的强绑定，比单纯的战斗更有压迫感。
- **边界处理**：原著此处含成人向描写，**游戏中以"暧昧过场 + 黑屏转场"淡化处理**，只保留"结缘/约定守口"的剧情节点，不呈现具体内容。

### 单元 5-E《赌局揭晓与拜师》（seq 210–212）｜触发：出关返回"禁地入口"
- **叙事**：清点灵药、一波三折的赌局 → 掩月宗反超夺魁 → 韩立因贡献巨大被李师祖收为记名弟子 → 回谷揭破"谢师礼"真相。
- **玩法**：做成**结算/评分类关卡**——玩家上交副本所得，系统按数量与稀有度打分，与其他门派 NPC 比拼排名；名次影响后续奖励（灵药、灵石、以及"拜师"剧情）。
- **奖励绑定**：拜师 -> 解锁**《青元剑诀》**与顶级法器**碧光刀**；同时揭示"记名弟子"这一身份带来的**隐性减益**（奖赏被抽成一半），把"靠山"与"代价"一并教给玩家。

### 单元 5-F《炼丹·筑基·洞府》（seq 213–220）｜触发：`lianqi` 满层、进入长线"炼丹/破境"环节
- **叙事**：地火屋炼丹 → 八丹冲关破境成筑基 → 因药力未化被迫修炼青元剑诀 → 得洞府与迷踪旗 → 双瞳鼠引路、觅得灵眼之泉。
- **玩法**：
  - **炼丹小游戏**：以"控火候 + 把握开炉时机"为核心操作，失败出废丹、成功出筑基丹；韩立因"反复炼同一种丹"而成功率意外高，可在游戏里做成"熟练度成长"曲线。
  - **破境机制（筑基）**：把原著"多枚筑基丹累积冲关"做成**数值积累 + 阈值暴发**的破境流程——积攒药力，达阈值后进入冲关演出，成功即由 `lianqi` 跨入 `zhuji`。
  - **洞府系统（新）**：解锁"自开洞府"——迷踪旗布置护府法阵，`double-eyes` 双瞳鼠作为寻宝探子寻找**灵眼之泉**（洞府灵气加成来源），为后续长线养成铺路。
- **技能绑定**：青元剑诀的**剑芒**与**护体剑盾**作为筑基期过渡技能解锁，并明确标注其"散功缺陷"，提示玩家这只是权宜之计。
