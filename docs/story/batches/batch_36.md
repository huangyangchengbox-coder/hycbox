## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。

### 单元 36-A《混元尺与角蚩之谋》（seq 1721–1728）｜触发：`lianxu` 后期 · 跨大陆副本"广寒界"终章
- **叙事**：禁地爆炸分头逃亡 → 一路追杀的角蚩金角青年 → 金身夺宝、钟声颠倒乾坤 → 巨猿真身定胜负，并顺手破坏角蚩族"五分之一"的大计。
- **玩法**：一场**多回合追逐-遭遇战**：先做"甩不掉"的压迫感（跟踪锁定机制），再转为"停下来反打"的阵地战。敌人宝物可被**夺取**（金身吞尺），做成"缴械"型机制——夺来的银尺立刻化为玩家武器。
- **奖励 / 技能绑定**：通关解锁**混元尺**（可虚实切换的中距离尺影武器，幻招骗判定）；湖中一战解锁**噬灵真火·金乌火**（毒属性克星，遇毒成雾）。
- **触发钩子**：`bossDefeated: lianxu·广寒界终局` 后开放"藏矿双峰"采集关，产出**混元尺通宝诀**与黑紫矿材。

### 单元 36-B《戎族与炼神术》（seq 1729–1738）｜触发：单元 36-A 完成、`lianxu` 后期稳定
- **叙事**：救月仙子、连灭四戎族 → 得知密洞金篆文 → 化清符潜行、逐个无声擒敌 → 与背巨刃大汉的硬仗 → 三枚广寒令破禁取文 → 习得金篆文、得完整炼神术。
- **玩法**：本单元主打**潜入**——化清符虚身做成"不能被攻击命中，但一旦被术法类伤害扫描即现形"的潜行规则；岔口处可用**阵旗+符宫**预先设伏，形成"引敌入阵"的战术层。
- **技能绑定**：金身新神通**洞漩金光**（吸附+致死漩涡，对精英与 Boss 的高伤终结技）；**元磁极山**升级为可瞬移镇压的空间收容（活捉而不杀，避免惊动他人）。
- **奖励**：**炼神术（第一层）**功法卷轴作为毕业奖，直接为后续"神念驱动"类玩法（驱使噬金虫、布阵、炼丹）提供数值与容量加成。
- **触发钩子**：`bossDefeated: 戎族巨刃大汉` → 开放"密洞遗迹"可重复探索副本（限时取文，失败则禁制重置）。

### 单元 36-C《别雷鸣·重返天渊》（seq 1739–1751）｜触发：`lianxu` → 跨大陆转场事件
- **叙事**：广寒界关闭、云城陷落 → 受翁姓大乘之托（虚灵宝鼎之缘）→ 以仙界灵药换灵丹材料 → 青蛟峰识破"旧识"实为血影附身并诛除 → 借超级传送阵离雷鸣 → 漂泊百年 → 回天渊城入城。
- **玩法**：做一段**过场串联 + 一次"似是而非的旧友"战斗**——故意让 NPC 表现为友善，玩家在交付物品时触发反转（符箓变邪丝、对方肉身炸裂露出血影），主打"防不胜防"。血影可设计为**免疫普通宝物、只被特定火焰/法目克制**，逼玩家切换已解锁手段。
- **机制绑定**：引入"**血魂 / 附身**"图鉴词条，为后续许家"血魂"线做概念铺垫（本批 1769–1770 回收）。
- **触发钩子**：`enterMajor: heti` 前置；跨大陆后解锁**天渊城**新场景与"坊市买卖"经营循环。

### 单元 36-D《炼神一层·进阶合体》（seq 1752–1757）｜触发：`heti` 破境（**本批最高潮**）
- **叙事**：择灵脉驱散散修 → 傀儡开府、灵兽护山 → 炼神术冲关引巨目天象 → 山岳巨猿吞尽元气、心魔来袭 → 元婴归体，正式踏入合体。
- **玩法**：把"破境"做成**分阶段境主战**：
  1. **护法阶段**：守住洞府外围（灵兽 + 傀儡协防，抵挡被惊动的散修与凶兽）；
  2. **吞元阶段**：巨猿形态下持续吸收天地元气，同时闪避/打断紫色电蛟与心魔幻象；
  3. **斩心魔阶段**：以留存的**宝香**压制、**辟邪神雷**击散"天外魔头分神"，血量归零不判负，仅推进剧情。
- **奖励 / 技能绑定**：晋级 `heti 合体`，解锁**元气化形**（零耗蓝的远程弹幕）；**念剑诀**（剑阵可随心瞬布）；神念相关权限全面扩容。
- **表现层**：天象全程走全屏演出（风雪→金银天→巨目），是天然的"破境仪式感"素材。

### 单元 36-E《旭日峰之邀与许家迷阵》（seq 1758–1767）｜触发：`heti` 初期 · 势力外交线
- **叙事**：天渊城与谷家同来招揽 → 重选灵皇/真灵大典的时代背景交代 → 以真灵残血隐患为动机接下谷家"临时出手一次"之约 → 托旧识寻妻、访金越禅师 → 赴天元境许家，一眼点破迷蜃幻境的破绽。
- **玩法**：**外交选择系统**——玩家可在"入长老会 / 入谷家 / 都不入"之间取舍，选择只改附属奖励与后续事件分支，不影响主线。**迷蜃幻境**做成一次"看破即通"的解谜关卡：识破残缺处可直接穿行，未能看破则需强行破解（消耗道具）。
- **技能 / 资源绑定**：解锁**通灵傀儡"娃娃"**（自行行动的炼虚级协战单位）；开放"真灵大典""万宝大会"两个未来事件预告。
- **触发钩子**：`heti` 初期 + 持有[真灵血脉] → 触发谷家玉牌线；`持有洛府之托·玉盒玉简` → 触发许家行。

### 单元 36-F《许家·血魂之秘》（seq 1768–1770）｜触发：抵达许家 · 隐藏支线开启
- **叙事**：以乾蓝冰焰验明血脉 → 交出血魂瓶与金篆玉简 → 精血化符、连夜开坛唤醒血魂 → 血月当空，韩立于客居处参悟天戈符、隐隐窥破真相。
- **玩法**：做成**"交付 + 观察"两段式**：前半为安静的剧情交互（验身、赠物），后半由玩家在夜里"发现异常"——赤月、血光、阵法波动皆可点击探查，逐步拼出"许家正进行血祭"的推断（悬案钩子）。
- **技能绑定**：仙界**银蝌文符篆**体系登场，可参悟出**天戈符**（金阙玉书中唯一的攻击符，蓄势型大招）的雏形。
- **触发钩子**："血魂仪式"作为下一批（seq 1771+）的**悬案接续点**：血魂唤醒后揭示冰魄仙子当年的下落与失踪真相，与"虚灵宝鼎—虚天鼎同源"线索合流。
