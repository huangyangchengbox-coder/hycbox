## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批整体映射到 `huashen 化神` 段，玩法核心是**真灵变身**、**阵营外交**与**异族副本探索**。

### 单元 30-A《须弥洞天降雷兽》（seq 1421–1428）｜触发：`enterMajor = huashen` 中段
- **叙事**：以"接单降兽"包装一次短副本——外披交易外衣、内藏杀机的雇主，与雷兽登场时的雷电压制感。
- **玩法**：**雷电蓄力合击关**。玩家与两名 NPC 同时向受缚的雷兽注入雷电，需按节奏键保持输出且不被雷球反噬，中途雷兽挣脱则进度回退（对应原著"坚持到我说停"）。
- **机制绑定**：把店主的"引雷珠"做成**背刺陷阱事件**——结算阶段出现可被识破的暗算判定，识破则全额拿取报酬，未识破则吞下一次重伤。
- **技能/道具**：本单元解锁**惊蛰十二变（初阶）**——三种真灵形态切换（大鹏/孔雀/金猿），形态间互有位移、远程、破防侧重。
- **奖励**：青罗果核（炼药素材）、灵石、啼魂兽强化材料。

### 单元 30-B《天鹏族·圣子试炼》（seq 1429–1436）｜触发：`huashen` 升层 / 支线"天鹏之誓"
- **叙事**：留名誓约 → 玉皇顶群雄 → 较技场试探 → 地渊之门前，一条完整的"入场资格"线。
- **玩法**：**非致命切磋关**（对阵虹纱/祝音子），胜负不判负，仅影响后续周目好感与阵营态度；配套**阵营外交界面**（赤融敌意、五光友善、联席长老会中立）。
- **机制绑定**：**四煞化甲术**落成一件"煞气护甲"——消耗体内煞气值抵挡一次致命伤，煞气不足则只能挡半伤（对应原著"煞气太少威能有限"）。
- **道具**：**雷蛟剪**为可夺取型武器（剧情被夺后需追回），是本段唯一"高威力但易被抢"的特殊兵器。
- **触发钩子**：`天鹏之誓`留名成功后开放"地渊副本"入口，并解锁"神念压制"环境规则（视野与锁定距离缩短）。

### 单元 30-C《地渊一层·巨灵花》（seq 1437–1445）｜触发：完成单元 30-B 剧情
- **叙事**：从坠渊入地下世界的压抑感，到被"幻化绿洲"骗到的第一课——此地的危险不只在妖物。
- **玩法**：**探索+波次混合副本**。第一层地图分密林/沙漠/绿洲三块，其中：
  - 阴蛛蜂为**数量压力关**（用范围火系清场，检验 AOE 手感）；
  - 巨灵花为**识破型 BOSS**（需先击杀怨猿兽、破坏幻化根基再输出本体）；
  - 黄风族伏击为**多目标混战**（1 打 3、后续援军入场）。
- **机制绑定**：**啼魂兽预警**——进入"神秘山脉"时小地图出现持续扰动提示，选择绕行可避免一次高难度遭遇（把"改名绕路"做成玩家决策）。
- **奖励**：幽香花蜜（炼药）、黑翎（后续黑焰类技能材料）、冥焰果试炼线开启。

### 单元 30-D《冰煞之地·豹麟兽进阶》（seq 1446–1452）｜触发：进入地渊二层
- **叙事**：小兽贪食冰煞 → 被迫就地进阶 → 引来全地图妖物 → 强敌接连上门，是最典型的"守点"叙事。
- **玩法**：**守兽波次战**。玩家布下"十方灭炎阵"与"大庚剑阵"（两份可升级的场地技能），在进阶倒计时内抵御低级虫群、中阶妖物与高阶 BOSS 的连续冲击。
- **BOSS 设计**：**冰煞妖王**（化冰凤形态，被击碎后需阻断其重聚）→ **三连血傀儡**（无限复活一次，需用噬灵天火彻底清除）→ **碧木妖+侏儒**（可战可退，退走则留后续复仇钩子）。
- **奖励**：**豹麟兽进阶为化神级召唤兽**（新增吞噬冰煞、追寻隐匿单位的天赋），并解锁"麒麟血脉"外观变化。
- **支线钩子**：敖青与费夜的婚约之争在暗线推进，为后续"同辈第一人"对决埋线。

### 单元 30-E《血蛟·冥河禁制》（seq 1453–1463）｜触发：取得冥焰果后
- **叙事**：从"护送完成任务"急转为"被妖王盯上、被擒、被软禁"，本批最大的一次主动权丧失。
- **玩法**：分四段——
  1. **天罡血雷硬抗关**：五层护盾（元磁神光/青丝网/剑影/雷袍/煞甲）依次被破，玩家需分配护盾顺序与血量，最后以拳影硬接（高风险高奖励判定）；
  2. **追击与传送**：被黑色光阵截获，强制失败演出（不判负，推进剧情）；
  3. **软禁自由探索**：在阁楼与木精洞范围内自由活动，随时间推进"限时探索"（木精洞禁地与翠吟园为不可进入区）；
  4. **渡劫关**：第二次小天劫——以新悟辟邪神雷化解青色天雷，并**收集天雷炼制雷珠**（一次性大威力消耗品）。
- **技能绑定**：**驱雷之道 / 祭雷之术**升级——辟邪神雷由普通雷系技能升格为"破魔特攻"，对魔气、邪灵类目标大幅加成。
- **限制机制**：四妖王在体内留下"印记"，形成**不可逃离状态**——玩家无法传送/离开指定区域，需靠剧情推动解开（对应原著"临时遮蔽"的权宜之计）。

### 单元 30-F《四大妖王·木精洞》（seq 1464–1470）｜触发：冥河之地前置（本批收尾）
- **叙事**：以"被雇为工具人"为主视角，穿插元瑶重逢的隐线、木青本体的秘密，收束到"冥河之地即将开启"。
- **玩法**：**铭印符阵协作小游戏**——地血演示符阵时玩家需在指定节拍向符阵眼注入辟邪神雷，过程中分心会前功尽弃（把"不得一丝分心"做成注意力挑战）。
- **收集系统**：**灵侍**（舞女/乐师/护卫三类）作为可收集的"半傀儡侍从"，通过"融灵入物"秘术合成，附带家园展示功能。
- **技能绑定**：**甲元符**（一次性复制本体部分神通与修为的分身符）与**九宫天乾符**（困敌符）在此正式入手，配套符箓炼制界面。
- **奖励**：**五色孔雀真灵之血（半份）**，可与惊蛰十二变联动解锁第四种变身，并获得"五色神光"雏形（对五行单位施加短暂禁制）。
- **关键钩子**：木青私藏本体、洞中疑有内奸的伏笔，指向**下一批 seq 1471+ 的冥河之地大副本**；元瑶、妍丽的再会作为情感支线保留。
