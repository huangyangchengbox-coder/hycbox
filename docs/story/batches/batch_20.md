## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情挂在「关卡之间的叙事插入 + 关卡目标绑定」之上；每个单元对应一次触发。本批引入本作第一个**召唤物体系**（傀儡 / 灵兽），是"元婴中期"阶段的核心成长点。

### 单元 20-A《皇清观·炼器殿》（seq 921–927）｜触发：`enterMajor = yuanying 中期`首个支线
- **叙事**：一段"被命运推着走"的插曲——本想入书院，却被一句"略懂炼器"拐进女观炼器殿，从最低阶的杂役做起。
- **玩法**：把**炼器殿**做成一个轻量**生产副玩法**：接月度提炼任务（材料提纯小游戏：控火温度区间 × 时长区间），达标得灵石与贡献，超额触发韦老额外传艺。
- **机制绑定**：嵌入**明王诀锻体**作为被动成长——打坐时角色会出现"剧痛抽搐"演出，代价是移速/攻速短时下降，换来**体魄条上限永久提升**（对应原著的痛感与收获）。
- **奖励**：解锁"血丝银/土属性材料"两条材料线，为后续傀儡、扇子材料清单开第一格。
- **触发钩子**：接到"严尧病故"消息 → 弹出**离去抉择**（留 / 走），选择影响本单元结算奖励，但不改主线。

### 单元 20-B《岳阳宫夺翎》（seq 928–931）｜触发：持有[诱妖草] 且 寻宝任务"昊阳鸟长翎"开启
- **叙事**：一次精密的**猎捕演出**——不以力取，而以"布置陷阱、引兽入瓮"取胜，呼应原著韩立"能不动手就不动手"的性格。
- **玩法**：做成**布阵关卡**：玩家在桃林小谷先后放置诱饵（灵草/珊瑚/光源）、阻断法阵、幻阵与伏兵，按顺序正确即可"零伤害捕获"目标；顺序错则引来兽潮，转为混战。
- **机制绑定**：**霓裳草（诱妖草）** 作为一次性消耗品入库——放置后吸引范围内妖兽（首次引入"引怪"概念），可复用为后续驯兽、刷怪的关键道具。
- **奖励**：**昊阳鸟火翎**（三焰扇材料之一）；意外掉落的**土甲龙**作为"待收服灵兽"进入灵兽栏（显示为锁定状态）。
- **演出**：结尾给一段"岳阳宫老妪扑空 + 两大宗门互相猜忌"的过场，作为世界事件的**余波**。

### 单元 20-C《晋京·天机阁与黑市》（seq 932–945）｜触发：进入 `晋京` 地图
- **叙事**：从"路上偶遇故人"到"被认出身份"，再到"反手敲诈反杀"，一段节奏紧凑的城市潜行线。核心张力是**"捂着身份走钢丝"**。
- **玩法**：新增**易容 / 敛息**机制——进入坊市地图后可手动切换三档气息（结丹 / 元婴 / 凡人），气息越低越不引战、但部分交易与被挑衅事件无法触发；被高阶NPC"神识扫描"时留有扫描条，暴露度满即强制战。
- **经营**：**天机阁以物易物**做成交易UI（无灵石定价，须用清单内材料置换），可购得**天机府**——功能上等同**可召唤的随身洞府**（回血/存物/重铸装备的根据地），以"空间裂缝"设定解释其稀有度。
- **道具**：**感应珠**（天澜圣女预警，百里内提示方位与距离）——本质是一个**限时敌情雷达**，过期失效；**寒髓**作为稀有素材入库，解锁传说级配方"回阳真水"（长期目标，不在此批可做）。
- **小高潮**：**敲诈反杀战**——一个限时短战，敌人先以"我喊人你就死"进行威胁演出（有咆哮读条，需在3秒内打断），随后以噬金虫破防 + 神识刺击晕完成终结。

### 单元 20-D《大拍卖会与古魔重逢》（seq 946–956）｜触发：单元 20-C 完成 + `地下交易会`开放
- **叙事**：本批最大的场面——一明一暗两场拍卖、四处势力互相窥伺，最后落到一场"打不过只能跑"的古魔遭遇。基调是**喧闹后的寒意**。
- **玩法**：把拍卖做成**竞拍回合玩法**：每件拍品有隐藏心理价位，玩家可选择"稳加价/跳价压制/放弃"，跳价压制能秒杀对手但会大幅消耗灵石并引来注意（引战值上升）。灵石与材料是本单元的双货币。
- **BOSS 战（非胜型）**：**古魔分魂**作为"不可战胜的压迫型敌人"登场——
  1. 阶段一：他会**一个照面秒杀**来抢宝的第三方修士（作为实力展示的演出）；
  2. 阶段二：玩家只能躲避与其瞬移追击，撑满计时段；
  3. 阶段三：触发**血影遁逃脱**（消耗精元换取一次脱战位移），由大衍神君外放"惊神刺"打断对方施法，方能退场。
- **奖励**：**平山印**作为可见不可得的"通天灵宝仿制品"做图鉴条目（世界观锚点）；玩家实得为 **墨金 / 五行玉 / 庚精 / 眩光晶 / 玉橡胶** 五件傀儡与宝扇材料，此为**本批最大资源收获**。
- **伏笔**：古魔分魂掳走的两口本命飞剑、以及"韩长老"这个同名身影，作为**下一批的追杀线**与**身份谜团**。

### 单元 20-E《天符门与屠蛟》（seq 957–963）｜触发：持有[降灵符] 且 到达 `华云州`
- **叙事**：从"送还旧物"的小人情，转成"海上一战"的大场面。中段插入一个**惊悚级彩蛋**——那位扫地看管典籍的老人，可能是一位滞留人界的化神期存在。
- **玩法**：**藏经阁翻阅**做成"典籍收集"轻玩法（限时翻页，翻到特定玉简得制符配方）；**屠蛟大会**做成**多人协同的搜索-围猎事件**：先在海图区域搜索妖踪（概率触发），再进入**海上战场**。
- **BOSS 战：八级赤火蛟**（三阶段）
  1. 火焰场压制——全场火海，须用冰属性技能（雪晶珠/紫罗天火）开辟安全区；
  2. 本体近战——蛟身巨尾横扫，考验闪避与反击窗口；
  3. **真假分身判定**——蛟尾钳住本命飞剑、喷妖丹，玩家须用"灵影术"三身骗过它，从侧面完成断首。
- **机制绑定**：**灵影术**（分身诱敌，短时三体，只一体为真）作为新技能；**雷火弓 / 蛟魂**作为材料入袋（前者是傀儡的杀招工件，后者是高阶精魂库存）。
- **彩蛋处理**：向之礼相关场景**不给战斗、不给结局**，仅给一句意味深长的独白与图鉴解锁——保持"不要招惹此人"的悬念。

### 单元 20-F《傀儡大成·苦竹岛·南下》（seq 964–970）｜触发：集齐[傀儡材料] 全清单
- **叙事**：一段带告别意味的成长线——大衍神君以裂魂换取"看傀儡一眼"，然后安然坐化；韩立收下遗愿与遗经，踏上下一程。
- **玩法**：新增**召唤物系统**首个正式单位——**人形傀儡**：
  - 定位：高防御 / 高爆发 / **消耗品驱动**（每次全力输出消耗一块高阶灵石，灵石耗尽则退回待机）；
  - 技能三件套：**元罡盾**（主动格挡反弹）、**五行罩**（持续减伤）、**雷火弓**（蓄力一击，高风险高收益）。
- **BOSS 战：苦竹老人**（**可"认输"收场**的特殊战）——目标是"打到对方服软"而非击杀：傀儡以盾抗剑阵、以雷火弓蓄力施压；对方血线/气势跌至阈值即主动罢手，双方无伤亡，交易达成。此战用来**演示傀儡强度**，也为后续"以势压人、不战而取"的玩法范式定调。
- **收服玩法**：**土甲龙归顺**做成一个**条件谈判**小交互（出示寒髓 → 对方动摇 → 施加压力 → 屈服），成功后**土甲龙**进入灵兽栏，功能为**寻宝/探材**（提升材料掉落率）。
- **收尾钩子**：韩立南下双蝎山赴九幽宗之约，峰顶**收雷火**、以三焰扇为下一个大目标——**下一批直接衔接"三焰扇"与"千竹教/封魂咒"两条长线**。
