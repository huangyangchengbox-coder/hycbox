## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 22-A《北极元光·降伏圭灵》（seq 1021–1022）｜触发：`enterZone = 北极元光` / 首次捕获高阶妖兽
- **叙事**：元光迷阵中遇上玄岩龟妖，一场"本命元牌易主"的收服戏，把妖兽从敌人变成仆从。
- **玩法**：新增"**灵兽收服**"系统——以本命元牌 + 分裂元神达成契约，可复用为通用捕妖机制；战斗做成"**环境即武器**"，玩家可引动场内元光银丝替自己输出。
- **奖励/技能绑定**：解锁灵兽位"**圭灵**"（高防肉盾 + 巨斧爆发）；获得"**两仪环·阳环**"（操控环境元光）。
- **触发钩子**：`enterZone: 北极元光`，且已完成"昆吾殿取宝"前序。

### 单元 22-B《劫杀乾老魔》（seq 1023–1027）｜触发：单元 22-A 完成
- **叙事**：老魔血影不灭、血魔珠、五子魔反噬饲主——一场"以环境和协作为核心"的围杀。
- **玩法**：**多阶段 Boss 战**——①血影形态（近战无效，须以环境光丝破防）；②血魔珠形态（高速位移，需"预判拦截"）；③元婴出逃（追击 + 收网）。
- **奖励**：乾老魔储物袋、阴罗幡（可作藏品/素材）、金刚罩封镇的"五子魔"封印球（召唤或材料）。
- **伏笔**：与阴罗宗结下大仇；"十八杆阴罗幡"作为世界观图鉴条目入库。

### 单元 22-C《镇魔塔·八灵尺》（seq 1028–1033）｜触发：`yuanying` 中段、`enterZone = 镇魔塔`
- **叙事**：塔内尸横遍地、血刀疑云、旧识重逢（白瑶怡），直至第八层众修混战与八灵尺现世。
- **玩法**：**塔层探索**（逐层下行的关卡链，越深越凶）；石傀儡大阵做成"**协作破阵**"玩法——多 NPC 同攻一点、傀儡可复活，需先清傀儡再破阵。
- **奖励**：白瑶怡好感支线（后继小极宫之约）；八灵尺线索（本单元不得手）。
- **触发钩子**：`bossDefeated: 乾老魔` 后解锁塔内探索入口。

### 单元 22-D《元刹圣祖·黑风旗》（seq 1034–1046）｜触发：推进至镇魔塔第八层（第一波高潮）
- **叙事**：场外化神级修士入场、珑梦/雪玲/银月的分魂真相、元刹圣祖借玲珑肉身脱困、黑风旗对九真伏魔阵的大战。
- **玩法**：**环境级 Boss 战**——把"黑风旗飓风"做成场地机制（可移动风柱、视野压缩、神识失效），玩家须在"夺宝"与"保命"之间反复权衡。
- **奖励/机制绑定**：确立"**辟邪神雷克制魔气与空间**"的属性克制关系，写入战斗克制表；解锁"空间系"情报条目（黑风旗、混沌开天）。
- **伏笔**：玲珑 / 雪玲 / 珑梦 / 银月的**四身关系图鉴**；敖啸妖王与灵界设定开篇。

### 单元 22-E《破壁反目·叱念真雷》（seq 1047–1052）｜触发：单元 22-D 的 `wallBroken` 事件
- **叙事**：合力破壁 → 友军反目 → 用噬金虫秘诀做交易 → 以叱念真雷落禁，一段关于"代价与约束"的博弈戏。
- **玩法**：把谈判做成"**限时对话选择**"（以屈指数数制造压迫感）；新增"**第三方背刺**"伏击事件——刚并肩的尸熊转头偷袭友军。
- **奖励**：**噬金虫催熟秘法**（加速虫群成长）、**叱念真雷**（对 NPC 的长期约束道具）。
- **触发钩子**：`wallBroken` 事件一结束即触发"反目"突袭。

### 单元 22-F《第九层·封魔与飞升》（seq 1053–1070）｜触发：**本批终章大型副本**（多幕）
- **叙事**：第九层封印之争——真魔之气、禁魔环、三宝联手、魔像降临、黑洞空间崩碎、天晶碑封印、灵魂吞噬、玲珑飞升。
- **玩法**：**分幕式长副本**（五幕：破阵 → 巨狼 → 魔像 → 空间崩碎 → 封印/飞升）。魔像战做成"**不可战胜的压迫关**"（目标只有保命与拖延）；空间裂缝做成"随机即死地格"；封印幕为**机制解谜**（借备用法阵吸尽魔气）；灵魂吞噬做成"**光球吞噬小游戏**"（呼应前批夺舍设计）。
- **奖励**：八灵尺（通天灵宝）、虚天鼎（保留）、黑风旗残段（稀有材料）、逆星盘资料（空间节点图鉴）、血刃与破界符。
- **技能绑定**：魔髓飞刀（高速刺杀）、失神刺（神识攻击）、化灵符（替身/免死）、封灵大法（记忆与信息封印）。
- **伏笔**：为下一批"离昆吾山 → 大晋/天南后续"留出钩子；玲珑飞升灵界即后期"灵界篇"的预告。
