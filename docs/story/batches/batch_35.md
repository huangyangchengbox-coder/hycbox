# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 35 批

- **对应原著**：seq 1671–1720（原章号 1671–1720，"广寒界·真仙遗址篇"）
- **游戏映射**：`lianxu 炼虚` 段（韩立以"上族七阶"入界，终局跃至**炼虚后期顶峰**），并为 **炼虚→合体（圣阶）** 的破境埋线
- **剧情弧**：跨界入广寒界 → 三族联手（柳水儿/石昆）合练元磁神光 → 横穿暗兽森林 → 凶虫之战与雷鹏废墟 → 遗址破禁得"太乙青山" → 登禁空石阶、破灭法目入屏中洞天 → 光柱灌体连破炼虚中期/后期 → 玄天之剑解围 → 遗址塌陷撤离
- **说明**：梗概均为原创改写，非原文摘录
- **附注**：本批原文中另夹有一节被误编为"第一千六百六十八章 天罡印"的章节（韩立受护送入殿、获翁姓青年所赠天罡印），实物位置在 seq 1672 与 1673 之间，属原书错号插入，内容可归入单元 35-A 前置。

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。

### 单元 35-A《入界·镇海猿》（seq 1671–1676）｜触发：`lianxu` 首次进入"跨界"节点
- **叙事**：以"持令撕开空间裂缝"过场开场，交代广寒界这一"限时刷宝秘境"；随后以一次海兽清场、一场元磁神光切磋、一头镇海猿的天吼演出，快速立起三名队友的人设与实力基线。
- **玩法**：新增**限时秘境**框架（一年周期、期满强制传送出界）。**小岛海兽**做成首个副本 Boss（不死不灭→须下潜打本体），**镇海猿**做成"不可战胜的压迫演出"——只许逃离，考验风雷翅式位移。
- **奖励/技能绑定**：解锁"[天罡印]"护体宝印（可挡一次巨力攻击）；确立"元磁神光·合击秘术"三合一技能组。
- **触发钩子**：进入广寒界时插入"广寒令"道具与地图（`guanghanMap` 图鉴）。

### 单元 35-B《暗兽森林》（seq 1677–1687）｜触发：单元 35-A 结束、需要"穿越险地"
- **叙事**：从"借图定位→发现身处绝地"的叙事压力，到取兽皮、学变面、撞兽王、被银目追杀、剑阵斩兽、七波堵截再到分头突围——一段完整的**潜行+狩猎+逃亡**链。
- **玩法**：引入**昼夜机制**（暗兽夜里战力翻倍，玩家应"夜行昼伏"）与**千变幻面伪装系统**（需先猎兽取皮，伪装后杂兵不主动攻击）。**王级暗兽**设为游荡的"不可正面硬拼"精英，需靠声响、走位引开。
- **技能绑定**：**春黎剑阵**（无声团灭/潜伏暗杀）与**元磁极山**（镇压+吞噬）在此发挥主场。
- **触发钩子**：`bossDefeated: 双首巨兽` 后开放"暗兽森林深处"高难图；豹麟兽贪食内丹可做成灵兽培养支线。

### 单元 35-C《玄天之秘·虫潮》（seq 1688–1691）｜触发：离开森林、遭遇"异族遭遇战"
- **叙事**：海王族"玄天圣器有感应"一句，把韩立的底牌（玄天残刃/果实）从"读者已知"推进为"外人已生疑"，埋下长线悬念；随后银潮虫之灾以"天敌化血蝶"解局，节奏绷紧。
- **玩法**：新增强敌**银潮虫潮**——以"虫潮追击"压力条呈现，需靠地形与"天敌相争"事件解围；**噬金虫**做成一次性清场技能（对虫类特攻，短时高伤但有神念消耗上限）。
- **奖励**：噬金虫群升级素材（银目暗兽内丹→银潮虫王元神）。
- **触发钩子**："海王族看破秘密"作为后续"玄天之宝争夺"支线的悬念钩。

### 单元 35-D《遗址·太乙青光》（seq 1692–1696）｜触发：抵达禁制遗址、`破禁` 关卡
- **叙事**：先以映影晶"看别人打"建立角蚩族这一第三方威胁，再集中火力写"太乙青光—元磁神光"的克制破解，最后以韩立"抢先收山"的机敏收束，突出其心性。
- **玩法**：设计**破禁节奏关**——十一重禁制"一重强过一重、必须一口气破完"，链式连打，中途停顿则前功尽弃（对应"破禁窗口"计时机制）。
- **奖励**：**太乙青山**入手——正是炼制"元合五极山"第二座极山的主材，绑定一条**极山收集/合成**长线系统。
- **触发钩子**：`bossDefeated: 禁制` 后开放"遗址内部"区域；第三方角蚩族作为"限时竞争"压力源。

### 单元 35-E《登山·破门取宝》（seq 1697–1712）｜触发：进入真仙宫殿、`破灭法目` 解锁
- **叙事**：一段层层递进的"寻宝解谜"——禁空石阶比肉身、幻阵比眼力、紫电比防御、药园比手段、金鼎比定力。重点写"平衡"：三人实力与信任的微妙制衡。
- **玩法**：
  1. **登山关**：石阶吸力递增，考验持续耐力（可消耗丹药/符箓/变身维持）；
  2. **幻阵关**：以"破灭法目+灵目"新神通破幻（新技能解锁）；
  3. **药园关**：掷山破柱的"蛮力解谜"+ 采集灵药（离土自灭者需"截果冰封符禁"）；
  4. **取宝关**：玲珑钥开鼎、虚天鼎收宝、按需分配（一次资源分配的抉择关卡）。
- **奖励/技能绑定**：解锁**破灭法目**、**山岳巨猿变身**（本批最强肉身增幅）、**梵圣金身**；获得太乙青山之外的万剑图、金葫、凝翠草、虚灵丹等宝物。
- **触发钩子**："虚灵丹"作为**炼虚→合体（圣阶）破境**的关键道具，直接挂到境界链。

### 单元 35-F《进阶·塌陷》（seq 1713–1720）｜触发：进入屏中洞天、`lianxu` 后期突破
- **叙事**：以"曲儿藏丹"的小反转开场，接"星空图淬心—光柱灌体连破境界—爆体危机—玄天之剑自救"的高潮，收在"遗址塌陷、三人仓皇撤离"的余韵。
- **玩法**：**灌体修炼关**——玩家在剧痛压力条下维持功法运转，逐级突破（炼虚中期→后期），越往后越险；**爆发救援**以"玄天之剑"一次性大招结束危机。最后接**限时撤离关**（塌陷倒计时，禁空失效、需速通传送阵）。
- **奖励**：修为跃至**炼虚后期顶峰**（大幅省去常规苦修）、**梵圣金身增强**（紫金符文）、星空图拓本（幻术研究素材）。
- **伏笔**：灵界深海骷髅神秘人察觉金光圆盘被毁而爆怒——作为**更高境界（合体/大乘线）的反派钩子**。
