# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 40 批

- **对应原著**：seq 1921–1970（原章号 1921–1970，文字量约 17.5 万字，"魔界之战·血光追杀篇"）
- **游戏映射**：`heti 合体（中期 → 后期临门）`，即**大乘之下最高张力的长线逃亡段**
- **剧情弧**：倚天城血战脱困 → 血光圣祖寄附降临 → 三具分元化身万里追杀 → 黄泉地火取混沌二气 → 黑雨上人陨落、元刹化身上位 → 遭遇魔族始祖宝花（宝树）→ 反杀埋伏、潜入魔界弃锁 → 回归人族，敖啸老祖与银月上岛
- **说明**：梗概均为原创改写，非原文摘录；原文此段章号错乱跳号（如 1955–1958 被写成 1755–1758、1966–1969 被写成 1666–1669、1950 缺失"第"字），本表**一律按实物顺序 seq 编排**，`原章号` 列保留其原始（错乱）编号

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。本批已进入「大乘之下」的顶级张力段，剧情以「长线追杀 + 阶段境主战」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。

### 单元 40-A《血光降临·万里追杀》（seq 1921–1928）｜触发：`enterMajor = heti`（合体中期）
- **叙事**：巨塔脱困（时间流速异常）→ 助战倚天城 → 血光圣祖以禁术寄附降临 → 三具分元化身紧追 → 布阵阻敌尽被破 → 以镇魔锁为筹码向车骑恭问计。
- **玩法**：先做一段**逃亡教学**——玩家沿途布下三层临时阵（大阵/傀儡/符箓），核心体验是"**明知无效仍须拖延**"的窒息感；随后引入**镇魔锁内空间**（可短暂进入、与"车骑恭"对话的剧情场景）。
- **机制绑定**：引入**时间流速异常**机制（同一次行为在"塔内/塔外"结算倍率不同），作为后续副本的通用规则。
- **触发钩子**：`enterMajor: heti` 首次触发；给出"分元斩尸大法"世界观词条，铺垫大乘级对手。
- **文案基调**：压迫、算计。

### 单元 40-B《血海困敌·退敌》（seq 1929–1935）｜触发：单元 40-A 完成（**合体境主战**）
- **叙事**：引念夺鼎 → 血海对轰 → 金网吼破光晕 → 万剑图逆转 → 一剑斩颅/鬼头替死 → 玄天残刃威慑退敌 → 封印战利品、痛惜万剑图。
- **玩法**：**多阶段境主战**——
  1. **引念**（弱交互）：在限时内把"引念晶球"充能满，触发敌宝易主；
  2. **拉锯**（常规打坐加速）：血海/剑阵互推，节奏关；
  3. **收束**：以"金网吼"音波与电网完成一次困敌判定。
- **奖励**：通关解锁**紫言鼎（封印态）**（可作为一次性夺宝道具）与**念剑诀·神识斩**（对精英怪额外神识伤害）。
- **代价设计**：**万剑图报废**——一次性消耗型强力道具，用完即失，强化"这一战赢得勉强"的叙事。

### 单元 40-C《黄泉地火·黄粱石灵》（seq 1936–1943）｜触发：`heti` 支线「捕灵」
- **叙事**：废城遇旧（许芊羽）→ 血灵取虚皇鼎 → 黄泉地火 → 天蝉与黑雨 → 陷阱 → 石灵噬雷涨功 → 血目幻术 → 韩立破幻擒灵。
- **玩法**：做成一个**独立支线副本「捕灵」**——
  - 前段**潜候**：在禁制与雷网中静待 BOSS 现身，考验资源管理；
  - 中段**幻术关**：屏幕反相/画面欺骗，玩家须靠"神识探测"找出幻境破绽；
  - 后段**擒获而非击杀**（目标改为"锁血捕获"，击杀则失败）。
- **技能绑定**：正式确认**破灭法目**（破幻/破隐身）与**辟邪神雷**（对魔物高倍伤害）的实战定位。
- **触发钩子**：完成后开启"祭雷术(上)"线索，指向下一批的**蛮荒寻残卷**支线。

### 单元 40-D《魔女现·大乘追杀》（seq 1944–1956）｜触发：单元 40-C 结束（**长线逃亡篇章**）
- **叙事**：风邪与牵机大法 → 魔女现（黑雨上人陨落）→ 新的大敌 → 石殿 → 大敌联手 → 拦截 → 狼狈 → 脱壳 → 声东击西 → 追婴 → 远遁 → 黑棺（六极苏醒）→ 遭遇蛮荒。
- **玩法**：把这一整段做成**限时逃亡大地图玩法**——玩家在中立地图上"忽东忽西"移动，靠**预感提示**与地形规避四大追兵，边逃边击杀古兽收妖丹**现场炼药**补给。
- **机制绑定**：
  - **方位感应条**（对应"残魂感应"）：追兵会周期性给出玩家大概方位，迫使玩家不断变向；
  - **金蝉脱壳**：一次性脱身技（预留"化清符"→虚化原地），可换取数回合安全。
- **叙事植入**：黑雨上人陨落作为**势力线过场**；六极苏醒（黑棺）作为**更高层敌人登场的演出**。
- **触发钩子**：本单元是**中转节点**，完成后进入"蛮荒"外圈与后续始祖线。

### 单元 40-E《花树与宝花》（seq 1957–1961）｜触发：单元 40-D 完成（**遭遇魔族始祖**）
- **叙事**：花树再现 → 玄天如意刃暴露（宝树）→ 幻日大法 → 神弓伤敌（落日箭）→ 脱身。
- **玩法**：做一场**借力脱身战**（而非硬拼）——玩家需与 NPC 雷云子配合，**两次充能"双重雷阵"**完成远距传送；过程中宝花以"幻日大法"覆盖战场，玩家须躲进阴影判定区。
- **机制绑定**：解锁**双重雷阵**（需双人协作的传送技，单体无效），与**天昙花**等稀有药引。
- **伏笔**：明确"魔族三大始祖"级别登场，为终局大乘线定调。

### 单元 40-F《炼化与圣岛》（seq 1962–1970）｜触发：`heti` 后期临门（**合体→后期过渡**）
- **叙事**：炼化之术（分段交易）→ 天渊城攻城 → 再入木族/潜入魔界弃锁 → 返程与魔族之谜 → 敖啸现身 → 殿议 → 银月与七星月体。
- **玩法**：
  - **炼化小游戏**：混沌二气的"轮回幻化"——玩家须在幻境中保有一缕预埋真力，限时自爆醒来（失败即回档），做成本批的**收尾挑战**；
  - **潜入关**：借木族与魔族的乱战缝隙，以"天凤破空"穿节点潜入，含搜魂问路的轻解谜；
  - **弃锁抉择**：把镇魔锁抛入地下冰河，作为一次性"了结心结"的选项，影响后续 NPC 线。
- **技能/成长绑定**：**进阶合体后期**在此挂上进度条；引入"圣岛/敖啸/银月"势力图鉴条目（含**七星月体**、**忘情诀**两个世界观词条）。
- **触发钩子**：本批以"银月与七星月体"收束——**银月线**与**敖啸老祖线**作为下一批的核心悬念（天奎狼王、狼王之位、圣岛奸细）。
