## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 27-A《木灵之体》（seq 1271–1273）｜触发：`huashen` 遭遇「银阶木灵」世界事件
- **叙事**：银阶木灵人树合一化作不死巨人，韩立诸般神通尽出而无功，最后靠噬金虫破局；战后清点战利品、重炼风雷翅。
- **玩法**：做一场**"常规伤害免疫"机制战**——巨人头顶有"木灵护甲"，正面输出归零，须靠玩家播撒"噬金虫"形成寄生 DOT 破防；虫群脱离越远神念消耗越大，逼玩家在"追击"与"收虫"间取舍。
- **奖励**：解锁**风雷翅重铸**系统（消耗风属性灵石 + 天凤之翎 → 获得瞬移/短暂无敌帧）；黑炎丹作为"破境概率道具"入库。
- **触发钩子**：木族任务结算后开启「灵宝重铸」面板。

### 单元 27-B《真蟾副本与夜叉血潮》（seq 1274–1279）｜触发：`huashen` 组队秘境「碧眼真蟾」
- **叙事**：二十余飞升修士组团剿真蟾取灵血，层层清虫驱兽，却撞上夜叉族大军过境、巨山被一掌劈开，胜利条件瞬间从"清怪"变成"活命"。
- **玩法**：三阶段副本——① 驱雾推进（躲怪禽酸液波次）；② 潜行段（檀鹤香作诱饵引出黑血蚁；玄涡兽**必须一击必杀，否则全图警报**）；③ 混战逃亡（地形崩塌、水位上涨，限时冲出）。
- **奖励**：真蟾血 / 真蟾液（化神后期唯一有效的修为丹药材料）；极寒"冰霜剑丝"剑诀。
- **触发钩子**：副本结算改为"活着撤离"，为下一单元的追杀战铺垫。

### 单元 27-C《猖奴追杀》（seq 1280–1282）｜触发：单元 27-B 撤离后的**追逐关**
- **叙事**：两位夜叉王以猖奴作赌具，放韩立与肖仙子先逃千里，再放出两只半鬼半妖的怪物追杀。
- **玩法**：**限时追逐 + 布阵反杀**双段——先逃（持续消耗灵力维持遁速，与搭档保持百里内绑定约束），再靠"大庚剑阵 + 银蝌文阵旗"布下光阵脱身。猖奴具有"血雾无形 + 免疫至阳"特性，须以极寒冰封配合雷电粉碎。
- **技能绑定**：金篆文大阵（传送）、冰霜剑丝。
- **奖励**：一次性**远距传送阵图**（可在后续副本中作为"紧急脱出"机制），肖仙子的日光佩（屏蔽神念侦察）。

### 单元 27-D《黑冥岛苦修与石墩》（seq 1283–1291）｜触发：`huashen` 后期**闭关经营段**
- **叙事**：韩立被远距传送抛入黑冥岛，开府苦修；以木铃花与当地妖兽以物易物，换来金髓晶虫与金母珊瑚沙炼体；又从珊瑚海灭杀宝光尊者、夺得令噬金虫变异的神秘石墩。
- **玩法**：**洞府经营循环**——药园催药 + 傀儡看守 + 妖兽以物易物交换表（木铃花 ↔ 晶虫/珊瑚沙）。外加"噬金虫变异"养成支线：喂食奇异石料后进入沉眠，觉醒后力大无穷。
- **奖励**：金髓晶虫（炼体 / 凝法相真身）、金母珊瑚沙、变异噬金虫；石墩作为顶级重金材料（可炼护宝或攻击宝）。
- **触发钩子**：交换表结算触发"天鹏族供奉"事件。

### 单元 27-E《冒充圣子·飞灵诸族》（seq 1292–1313）｜触发：`feiling` 飞灵族**阵营伪装线**
- **叙事**：力退赤融族后被认作天鹏遗族，混入圣城；遭大长老金悦识破，被迫冒充第三圣子；交易大殿寻青罗果、须弥洞天降雷兽，最终在玉皇顶的较技场上与祝音子首次交锋。
- **玩法**：**身份博弈 + 伪装度系统**——新增"天鹏气息 / 怀疑度"双条，气息在身方能混入圣城，做出异常举动则怀疑度上升。配套小游戏：交易大殿石柱信息墙（红字收购 / 绿字出售，限时竞价换物）、须弥洞天**降兽战**（黑星匕封雷源 + 五色天雷压制，三人协同注入雷力）。
- **技能绑定**：惊蛰十二变（真灵形态切换）、四煞化甲术（煞气凝甲）、鲲鹏舍利变身。
- **奖励**：惊蛰十二变、雷蛟剪（镇族之宝）、青罗果核。
- **触发钩子**：天鹏之誓留名 → 开启「地渊试炼」任务链。

### 单元 27-F《玉皇顶·地渊试炼开启》（seq 1314–1320）｜触发：`diyuan` 地渊试炼**准入准备**
- **叙事**：抵达玉皇顶，众圣子较技、祝音子反复试探；联席长老会公布试炼内容——三月内取回成熟冥焰果，随即开银门放众圣子入渊。
- **玩法**：**试炼前哨 + 准入教学**——较技场切磋（点到为止、禁止击杀）、煞气凝甲技能教学、地渊一至三层副本入口预告。
- **奖励**：雷蛟剪（限时借用的高威力法宝）、冥焰果采集任务链开启。
- **触发钩子**：本单元末直接承接下一批 **seq 1321+（地渊试炼正篇）**。
