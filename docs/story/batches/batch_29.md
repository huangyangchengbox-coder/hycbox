## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批为**异族篇**，故新增"潜入/伪装""群敌过境""无限强化战"三类演出，但底层仍是既有的打坐吸灵、挥剑斩妖、击杀破境。

### 单元 29-A《黑叶森林·木族之战》（seq 1371–1377）｜触发：首次进入 `黑叶森林` 区域
- **叙事**：潜入异族禁地取情报，却撞上木族伏杀；玉简被毁、银阶木灵围场、真灵之魄空战三连，把"任务顺利"直接翻成"绝境突围"。
- **玩法**：把"潜入"做成**潜行资源关**——避开第三妖目战兽的视野圈（对应既有敌人视野机制），被发现即触发围杀；木猿兽化树一节做成**地形随机变换**。
- **奖励**：任务达成后解锁 `太一化清符`（限时隐身道具）与"卧底情报"图鉴条目。
- **触发钩子**：`enterRegion: heiyelsenlin`；真灵之魄空战以**双形态切换**演出（玩家操控彩凤，冰风双属性切换）。

### 单元 29-B《天凤之翎》（seq 1378–1384）｜触发：单元 29-A 完成
- **叙事**：血剑夺血 → 生擒黑凤 → 啼魂变身吞鬼王 → 大庚剑阵磨血剑 → 血剑自爆 → 交换天凤之翎 → 噬金虫暗截灵血。本批**最密集的多线混战**。
- **玩法**：做成**多波次混合战场**，敌人分批上线（赤鬼群 / 陇家双修 / 无相鬼王 / 自爆血剑），强调"打到一半 Boss 变招"。血剑自爆前给出 3 秒预警圈，作为**强制撤离机制**。
- **技能绑定**：啼魂兽**二次变身**（可召唤的高级灵兽，绝招血色电弧对鬼类秒杀）；大庚剑阵升级为**对器物专用**的持续磨削手段。
- **奖励**：`天凤之翎`——风雷翅的第二炼材；`噬金虫·暗手`剧情道具（暗示"无物不噬"可反向掠夺资源）。
- **文案基调**：算计与反算计，韩立始终留一手。

### 单元 29-C《银阶木灵·人树合一》（seq 1385–1388）｜触发：单元 29-B 完成后首次遭遇"不可胜之敌"
- **叙事**：木瑞一路追杀，大庚剑阵、雷袍、雷珠、噬灵天火、飞剑齐上仍伤不了人树合一的绿色巨人，最终靠**替劫符 + 噬金虫啃噬**翻盘，再以强驱虫群换来重伤也要脱身。
- **玩法**：设计成**"无法击杀、只求逃脱"的特殊战**——血条不可清空，玩家目标是撑满倒计时并完成 3 次替劫判定；噬金虫作为"以命换命"的消耗型杀招，用完神念大损（进入短暂的 debuff）。
- **奖励与重铸**：通关后开放**风雷翅重铸**（材料：天凤之翎 + 风属极品灵石 + 五行灵石），成品为进阶灵宝，附带短距空间跳跃。
- **伏笔装备**：`黑炎丹`入库，作为化神→炼虚的**破境丹药**（一次可加两成成功率）。
- **情绪基调**：以实力差距制造压迫感，强调"境界差一阶就要付出代价"。

### 单元 29-D《碧眼真蟾清剿·夜叉降临》（seq 1389–1399）｜触发：`huashen` 中期、团队副本开放
- **叙事**：飞升修士结队猎真蟾，从"檀香引蚁、雷旗困虫"的顺利开局，骤然翻成夜叉夜叉族**斩山灭队**，再被两只猖奴追杀、靠传送光阵侥幸逃离、却传丢了方位。
- **玩法**：**三段式团队副本 + 逃亡关**——
  1. 协同清剿（檀鹤香引怪 + 旗阵困怪的分工玩法）；
  2. 一击必杀小关（玄涡兽不能触发警报，考验爆发与隐匿节奏）；
  3. 溃败与逃亡（斩山演出 → 无法取胜的围杀 → 传送阵抢先）。
- **机制绑定**：`猖奴`为**高速狡诈型追击怪**（免疫雷属性、需布阵或传送克制），是后续同类敌人的模板。
- **奖励**：`碧眼真蟾尸体`×9（可炼出真蟾血）、`金篆文阵盘`残片（解锁高级传送阵图鉴）、`日光佩`（屏蔽神念窥探的护符）。
- **触发钩子**：`bossDefeated` 完成后自动播片"夜叉大军过境"，把人族天渊城线的威胁前移。

### 单元 29-E《黑冥岛苦修》（seq 1400–1407）｜触发：传送落点 `黑冥岛`
- **叙事**：流落孤岛 → 检视赤魔海龟壳与海中妖物 → 认定黑冥雾为死地 → 开洞府**苦修一甲子** → 妖兽攻府、搜魂得知天鹏族供奉 → 除宝光尊者、得石墩异宝、噬金虫变异 → 与皓兽一族做晶虫珊瑚沙交易。
- **玩法**：把"苦修"做成**离线收益 + 定时事件**系统：闭关期间积累修为，期间随机触发"妖兽袭府"防守事件（用既有禁制/阵法抵挡）。交易环节做成**以物换物**的资源置换（木铃花 ↔ 晶虫/珊瑚沙），不引入货币。
- **养成绑定**：
  - `金髓晶虫`——炼体圣药（提升肉身强度，为梵圣真魔法相实体化铺路）；
  - `金母珊瑚沙`——淬体材料；
  - `神秘石墩`——超重异宝，后期可炼攻/防神器；
  - `噬金虫变异`——进化后力大无穷、可咬起千斤之物。
- **触发钩子**：`huashen` 中期瓶颈连续三次失败 → 引出"天鹏族供奉"线索，过渡到单元 29-F。

### 单元 29-F《天鹏族·圣子之路》（seq 1408–1420）｜触发：`huashen` 后期、黑冥岛剧情完成
- **叙事**：跟踪天鹏人 → 被赤融族困魔网顺带罩住、蜜蜂识破身份 → 力退赤融、借鲲鹏气息冒充族裔 → 入圣城、见封灵塔鲲鹏之灵共鸣 → 被大长老识破、受封"第三圣子" → 在交易大殿寻得青罗果与珍稀材料 → 以鲲鹏舍利与天鹏之誓副卷留名为条件，完成真血入体、化鹏成功。
- **玩法**：**异族潜入玩法**——用"幻化伪装"骗取身份（伪装值会被圣器/蜜蜂类道具识破，形成紧张感）；圣城内开放**多层级交易大殿**（以红绿信息柱发布买卖，玩家自主寻宝，青罗果等稀缺材料靠条件换取）。
- **机制绑定**：
  - `天鹏变身术`——解锁人/鹏双形态，鹏形态体型与威能随熟练度增长（对应"变身形态"这一新战斗维度）；
  - `鲲鹏真血`——血脉继承系统，与既有"境界链"并行的一条**血脉线**（凡→炼气…大罗→道祖 之外的横向强化）；
  - `青罗果 / 天罗丹`——与他丹同服可增三成药效，作为丹药系统的**乘法增益**。
- **奖励**：`鲲鹏舍利`（血脉继承道具）、`天鹏之誓副卷留名`（免于本族敌意的外交护身符）、`化鹏真身`（百丈巨鹏，威能堪比灵帅）。
- **伏笔**：地渊试炼提前、赤融族与渡鸦族联名施压、红云大长老残损舍利的隐患——三项皆为下一批（seq 1421+）的钩子。
