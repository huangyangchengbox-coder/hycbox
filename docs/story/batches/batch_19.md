# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 19 批

- **对应原著**：seq 871–920（"大晋篇"开篇：封魔 → 天澜草原 → 潜入大晋）
- **游戏映射**：`yuanying 元婴（中期）` 阶段，即**首个"跨境新地图开荒"段**
- **剧情弧**：大漩涡封魔埋盘 → 得灵岛修成第二元婴 → 远赴大晋途中于天澜草原遭突兀人围攻、煞气反噬封印修为 → 混入苍鹭部朝贡车队 → 苦毒与冯家密窟 → 天澜圣女携圣兽追杀、双鼎夺兽 → 假死漂入大晋 → 参王大会与炫王尸棺 → 雪陵山脉尸王乱战 → 白露书院求入宗门
- **说明**：梗概均为原创改写，非原文摘录；原文**章号错乱跳号**，一律以实物顺序 seq 为准（seq 874 原文重标为"第八百七十三章"，seq 888 原文误标为"第七百八十八章"，故 888 位为"危机"章）

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。本批是全书第一次"离开本土、跨境开荒"，剧情以「新地图解锁 + 阶段状态异常（封印） + 收容/夺宝」三种方式挂在既有钩子上。

### 单元 19-A《大漩涡封魔·得灵岛》（seq 871–876）｜触发：`enterMap = 大漩涡`
- **叙事**：三大修士请韩立深入魔气埋阵盘，他不卑不亢讨价还价，换来一座灵岛与四件退魔之宝；回来路上顺手用精纯魔气**修好一杆魔幡**。归宗后闭关数年炼成**第二元婴**，随即悄然离山，一走百余年。
- **玩法**：新增**深潜关**——玩家以"辟邪神雷"为护罩血条，向下穿越魔气；每下潜一段神雷消耗加快（对应原著"越深魔气越盛"），需择机回撤。
- **机制绑定**：阵眼处可搜索**魔髓钻**（稀有材料，一次深潜最多 3–4 枚）；在光幕外可开启"**修幡**"支线，用魔气把破损法宝重炼为可用兵器。
- **技能绑定**：**第二元婴**首次登场，作为"分身/额外血条"机制（战力翻倍，但附带反噬风险）。灵岛 = 扩张基地（新增资源产出点）。
- **奖励**：四件退魔之宝作为**一次性 buff 道具**入库。

### 单元 19-B《天澜草原·五鬼锁神》（seq 877–883）｜触发：`travel = 天澜草原`
- **叙事**：一次大意引来突兀人围杀，韩立重伤、煞气提前反噬，被迫自封修为（十之八九法力被封），扮作低阶仙师混进一支朝贡车队。
- **玩法**：新增**"封印"负面状态**——进入新地图后玩家**真实战力被大幅压制**（数值上的"重置感"），但保留"**第二元婴 + 稀有灵兽**"两张底牌。
- **核心循环**：**临机解封**——消耗"万年灵液"临时恢复满状态一个时辰，全程最多 5–6 次，用一次煞气侵蚀加重一分（**限次大招，需精算**）。
- **关卡**：**护车关**（苍鹭部贡品队）——车队遇妖禽袭击，玩家需在弱势下靠环境与灵虫取胜；教学玩家"以弱胜强"的节奏。
- **角色植入**：枫岳（身负家族血仇的大晋世家子弟）登场，作为下一单元的关键 NPC。

### 单元 19-C《苦毒与冯家密窟》（seq 884–892）｜触发：单元 19-B 完成 + `item = 银钥匙`
- **叙事**：韩立救枫岳、逼问冯家与佛宗渊源，换得**密窟钥匙**；途中又撞破大晋九仙宫追杀叛徒，夺得**金焰石**，并因阴罗幡被误认作"阴罗宗长老"而名动草原。
- **玩法**：**审讯小游戏**——以"梦引术/无忧针"（弱化版搜魂）在有限次提问中辨真伪、取情报，问错则损失线索。
- **战斗**：**伏击战**（对九仙宫一行）：解锁"**魔云吞宝**"机制——阴罗幡铺开后可将敌方法宝**收缴/失效**（对法宝型敌人压制）。
- **奖励**：**金焰石**（七焰扇仿品核心材料，长期收集目标之一）、冯家密窟线索。
- **势力绑定**：解锁"**天澜圣殿通缉**"——在草原地图上被高阶修士主动追猎（地图压力机制）。

### 单元 19-D《天澜圣女·双鼎夺兽》（seq 893–898）｜触发：`bossDefeated: 突兀大仙师`（首次）
- **叙事**：圣女召唤守护圣兽穷追韩立，韩立分兵诱敌、藏剑于云，最终以自家的**虚天鼎**反吸圣女**圣鼎**、连**圣兽**一并收走，血影遁脱身，随后**假死封冰**漂入大晋。
- **玩法**：**三段制追逐 Boss 战**——
  1. **分兵诱敌**：玩家操纵"幻身/化身"把追兵引开（镜像关）；
  2. **贴身缠斗**：紫焰/紫冰对银丝、"雷遁"躲八卦图（考验闪避与位移）；
  3. **以鼎制鼎**：识破"幻兽"诱敌后，抓住时机反向收服对方圣鼎与圣兽（**QTE/时机判定**）。
- **机制绑定**：**虚天鼎**首次实战化——"**吸宝/收容**"特效（可夺敌对法宝、可囚禁特殊单位）。
- **奖励**：通关得**圣鼎（辅助型灵宝）**与**圣兽（囚禁态）**；解锁"通灵之宝"图鉴条目。
- **失败代价**：本战用尽最后一次"临机解封"，战后进入**长期虚弱**（下一单元开局即为低战力）。

### 单元 19-E《大晋潜修·参王大会与尸王》（seq 899–912）｜触发：`enterMap = 大晋`
- **叙事**：重伤的韩立借商船与大晋低阶修士帮衬慢慢恢复，赴**冯家密窟**寻佛门功法，得《明王决》；途中卷入世家恩怨与一场**上古尸王**的暗流。
- **玩法**：**新大陆开荒段**——引入大晋特有的**交易/拍卖系统**（参王大会：自由交易 + 拍卖会，价格高于本土，产出"温石""火熔晶"等区域特色材料）。
- **轻玩法**：**鉴宝**——韩立凭对妖丹的敏感**识破"晶化妖丹"伪装**（外观与火熔晶一模一样的稀有真宝）；可做成"慧眼辨识"小游戏。
- **机制绑定**：**明王决**——本批核心技能，可将**"煞气"负面条反向转化**为可用资源（对应游戏里"煞气/煞力"资源系统）；需**金刚舍利**才可修习。
- **道具**：**金刚罩**（尸王舍利所炼护盾，需啼魂兽尸焰方能炼成）、**天尸珠**（炼体灵物）、**雪晶珠**（冰属性，培炼紫罗天火）。
- **伏笔**：三棺尸王（炫王 / 其子 / 玉华夫人）与金元被灭口，直接引出下一单元。

### 单元 19-F《雪陵山脉·尸王之乱》（seq 913–920）｜触发：单元 19-E 结束 + 离开密窟
- **叙事**：韩立出密窟即被卷入三方围杀"尸王"的漩涡，出手斩敌、救下炫王、索走天尸珠，全身而退；随后带走金刚罩、大晋地契，改头换面拜入**白露书院**。
- **玩法**：**多方混战关**（尸王 vs 二妖 vs 玩家）——三方互斗，玩家可"袖手/参战"自由选择，胜负不锁定主线结局。
- **机制绑定**：**克制关系**显性化——**啼魂兽**天生克制"阴气/尸气类"敌人（对落魂沙、尸兵类单位呈碾压），玩家需据此换将。
- **奖励**：**天尸珠**（炼体）、金刚罩成品；大晋**地契文书**作为"世俗身份/资源"系统入口。
- **收尾钩子**：白露书院 = 下一批（seq 921+）的**潜修宗门**；鲁大先生在场且有贵客，暗示新的悬案与人物线。
