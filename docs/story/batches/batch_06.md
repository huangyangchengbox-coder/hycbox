## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每章梗概归入一个**剧情单元**，每个单元对应一次触发。本批整体处于**筑基期中后段**，是「守家 → 出走 → 海外立足」的转场弧。

### 单元 6-A《星尘阁与秘店》（seq 221–227）｜触发：`enterMajor = zhuji` 后首次进入「坊市」
- **叙事**：韩立为护府阵具走进天星宗坊市，星尘阁只卖普通货，真正的精品藏在秘店竞卖会里；他靠一株灵草换来齐云霄的全套阵具与炼器心得。
- **玩法**：新增轻量「**坊市/竞卖**」子玩法——玩家持灵石在竞价条上出价，抢下「颠倒五行阵」阵具；出价过低被他人夺走，出价过高则灵石见底，影响后续炼器与补给。
- **奖励 / 技能绑定**：解锁**颠倒五行阵**（护府大阵，映射为「打坐时段自动护盾/免伤」类增益，对应原著的幻化藏形、困敌）。
- **触发钩子**：`enterMajor: zhuji` → 首次抵达「坊市」场景时弹出对话。
- **备注**：秘店可复用为「稀有兑换商店」，齐云霄作为可复访 NPC 埋后期的炼器线。

### 单元 6-B《千竹教围府 · 大衍决》（seq 228–233）｜触发：`bossDefeated: zhuji（首个筑基 Boss）`
- **叙事**：韩立炼出神风舟，途中撞见千竹教以傀儡围杀同阶修士；归洞即遭黄龙带四胞胎围府，最终靠颠倒五行阵撑到结丹修士雷万鹤降临解围。他从林师兄口中榨出大衍决之秘。
- **玩法**：做一场**守阵关**——玩家站在阵中，四面不断涌来傀儡士兵/机关兽，需在限定波次内守住阵眼、不让敌人贴到核心；波次结束由雷万鹤「救援演出」收尾。
- **奖励 / 技能绑定**：**神风舟**（飞行法器，映射为关卡间移动速度提升）；**大衍决**（神识/分神秘法，映射为「可召唤少量傀儡协同作战」的辅助技能，与后续傀儡系统联动）。
- **触发钩子**：首个筑基 Boss 击败后自动衔接；雷万鹤以过场演出登场，建议预留后续师门线。

### 单元 6-C《曲魂与金背妖螂》（seq 234–245）｜触发：`enterMap = 嘉元城 / 元武国`
- **叙事**：韩立先处理墨府旧怨（墨玉珠、缨宁、钻心虫暗手），再追查失控的曲魂，反被引入陷阱，面对四级顶阶的巨螳螂「金背妖螂」，最终以完整大阵耗杀之，并得绿煌剑与奇虫榜。
- **玩法**：两段式——① 潜入关（李府夜行，定神符/控神术潜行，失败则触发追兵）；② **Boss 关「大阵灭妖」**：玩家布阵困敌，靠傀儡与骚扰削血，再用一枚「符宝」收尾，突出「以阵法与消耗取胜」的差异化战斗。
- **奖励 / 技能绑定**：**绿煌剑**（原著首件法宝，映射为结丹期才能装备的高阶剑类，形成长期收集目标）；**奇虫榜/傀儡真解**（图鉴与召唤物扩展）；十余枚死卵作为后续隐藏道具伏笔。
- **触发钩子**：进入嘉元城/元武国地图时触发；妖螂作为该地图的强力野外 Boss。

### 单元 6-D《魔道入侵 · 撤离与传送》（seq 246–263）｜触发：`majorEvent = 魔道入侵`（宗门守卫失败）
- **叙事**：惊龙钟响，令狐老祖宣布七派大败、全门撤离；镇派残军的阻击战被「天火之术」反伏击，韩立突围后误救南宫屏、被其吸走修为，最终以古传送阵与大挪移令远遁。
- **玩法**：连续三小关——① 限时撤离（取物/破毁密室，可选带走灵眼之泉）；② 突围关（在熔岩雨下躲闪、撕裂鬼头杀出包围）；③ 传送关（守住传送阵读条，抵挡魔道修士破阵）。
- **剧情性 debuff**：误救南宫屏后**修为由筑基中期跌回炼气三四层**（对应「轮回真决」吸元），做成一次可视化的「跌落—重练」体验，回收本游戏「打坐→升境」的循环。
- **奖励 / 技能绑定**：**大挪移令**（一次性跨图传送道具）、灵石与「和元玉」材料；解锁**乱星海**新地图。
- **触发钩子**：宗门战失败/`enterMajor` 事件后强制推进；建议做成不可回头的**章节转场**。

### 单元 6-E《乱星海 · 魁星岛斗法》（seq 264–270）｜触发：`enterMap = 乱星海`
- **叙事**：韩立被传送到孤岛，随顾东主的海舟抵达魁星岛；为换取定居权与修炼之地，他替顾家参加三年一度的斗法挑战，靠身法一路瞬胜。
- **玩法**：① 过渡段——「学语/问俗」轻互动，引出乱星海三灾（妖兽、天风、鬼雾）与岛主制度；② **1v1 斗法擂台**：抽签配对、一次性定胜负，突出「炼气期低阶法术 + 身法隐蔽」的快节奏对决（对应原著罗烟步瞬杀）。
- **奖励 / 技能绑定**：**魁星岛永久居住资格与修炼之地**（映射为永久/半永久的灵气获取加成）；解锁「仙山/登仙阁」功能区与灵地争夺大会预告。
- **触发钩子**：抵达乱星海后经顾东主线触发；斗法胜利即开放定居与灵地系统。
