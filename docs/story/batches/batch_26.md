- **对应原著**：seq 1221–1270（原章号 1221–1270，"纵横人界·飞升灵界篇"）

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。本批跨越一次**大境界跃迁（元婴→化神）**与一次**世界切换（人界→灵界）**，全部新机制都以"关卡间叙事插入 + 关卡目标绑定"挂在既有钩子上。

### 单元 26-A《天机殿斗法》（seq 1221–1227）｜触发：`bossDefeated: 元婴后期` 且化神突破失败
- **叙事**：化神功亏一篑 → 远游大晋 → 混入游离空间中的天机殿 → 佛宗长老求斗 → 胜而得秘术。全段气氛"技惊四座"。
- **玩法**：做一场**切磋而非死斗**的竞技关（对手有金身减伤 + 幻影召唤），本关胜负不判死，用"压制血线到一定比例即胜"表达韩立的神通压制。
- **奖励**：解锁"**芥子空间**"经营模块——可开辟一处可存放资源、独立成长的私密空间（本批后期直接复用为韩立修炼元磁神光的闭关地）。
- **技能绑定**：展示三焰扇、虚天鼎、紫罗极火的组合连招，作为玩家进入化神前的**最后一轮能力清点**。

### 单元 26-B《阴罗宗之局》（seq 1228–1234）｜触发：单元 26-A 完成、持有灭仙珠
- **叙事**：擒王斩首 → 阴罗宗长老接连失踪 → 被化神风老怪追杀 → 向之礼调停 → 以灭仙珠与节点资料换合作。
- **玩法**：**潜入刺杀循环**（选目标、避开禁制、一击脱离），配一段"被化神追杀"的**高速逃亡关**（被咬住即重开，考验位移与减速道具）。
- **机制绑定**：灭仙珠落成一次性**同归于尽级道具**（高耗、极稀）；"化神禁条"作为世界观图鉴条目，并给玩家一个隐性的**行为约束提示**（不得肆意屠戮宗门）。
- **伏笔**：向之礼的"空间节点"成为本批后续所有剧情的总钩子。

### 单元 26-C《魔陀山救紫灵》（seq 1235–1243）｜触发：单元 26-B 完成后、好感系统激活
- **叙事**：赴魔宫赴宴 → 重逢旧识紫灵 → 交换赎身 → 硬接化神一击 → 啼魂进化 → 紫灵别去赴火狱。
- **玩法**：
  1. **纯防御生存关**（对应"硬接一击"）——不可闪避、不可反击，只能靠多层护盾与减伤硬扛回合制伤害；
  2. **护法/Carry 关**（对应翠峰）：玩家操控韩立，同时管理"巨猿 + 骷髅"两个召唤单位的站位与承伤。
- **奖励或技能绑定**：啼魂兽**吞噬妖魂进化**（永久提升吞噬类收益）；八灵尺八灵兽虚影作为**高阶防御终极技**解锁；回阳水的原料"寒髓"入库。
- **触发钩子**：紫灵作为**可招募/可送礼的长期好感角色**入库，其后续命运留作跨地图长线。

### 单元 26-D《火狱取精火》（seq 1244–1248）｜触发：单元 26-C 完成、拥有太阴真火
- **叙事**：雾海猎妖 → 布下巨阵、祭坛与乾蓝鼎 → 火灵诱捕 → 太阴火鸟与银翅小马缠斗 → 归谷炼火，玄天仙藤复生。
- **玩法**：**双火钳制捕捉关**——玩家在限时场地（蓝冰囚笼）内用"太阴火鸟（诱饵/驱赶）+ 阵法（封锁）+ 五魔寒焰（减速）"三线协作堵截高速游走的火灵，命中判定苛刻。
- **奖励或技能绑定**：捕获太火 → 解锁**回阳水（寿元）**与"**阴阳二火**"组合技；芥子空间正式启用。
- **隐藏钩子**：玄天仙藤复生列为**独立隐藏支线**（长周期成熟、成果逆天），呼应游戏里"催熟类小瓶"机制，建议做成长达数十关的慢线。

### 单元 26-E《斩二妖·飞升五龙海》（seq 1249–1261）｜触发：`lianqi→...→化神` 全链达成、进入"飞升准备"阶段
- **叙事**：外海设伏斩金蛟王与风希取金属性蛟丹 → 龙鳞果与淬骨决强化肉身 → 进阶化神 → 五龙海寻节点 → 与冰凤互下死禁 → 入节点。
- **玩法**：
  1. **设伏猎杀关**（先布控、再收网，可自由配置埋伏单位）；
  2. **进阶化神**做成一次**长线闭关小循环**（持续若干日夜的选择经营：修炼元磁神光 / 炼回阳水 / 照料灵药）；
  3. **入节点**为一关**高压生存冲刺**：护盾被逐层剥落，需提前备足宝物与符箓。
- **奖励或技能绑定**：**元磁神光**（灰光，可吸夺敌方宝器/飞剑）、**淬骨诀 + 龙鳞果**（永久强化肉身与金刚诀，白身手可举万钧）、**六丁天甲符**（引入天地灵气自动成长的多层护甲）。
- **触发钩子**：本单元结束即**切换地图**——从"人界"转场到"灵界"，为下一单元的境界归零做铺垫。

### 单元 26-F《飞升灵界·青罗沙漠》（seq 1262–1270）｜触发：单元 26-E 通关、`enterMajor = lingjie 灵界`
- **叙事**：坠入青罗沙漠、法力尽失、以凡人之身被商队所救 → 签血咒文书 → 护队御虫、以石块救人 → 抵安远城。
- **玩法**：做成一次**境界归零的"软重启"**——
  - 主玩法暂切回**凡人打坐 + 挥剑斩杀**（呼应游戏最初的凡人段），但敌怪换成沙虫兽、人蛇妖等灵界异虫；
  - 新增"**灵具**"操持系统：凡人经由持灵石的手套/手镯驱动灵具（对应游戏中"装备需耗灵石"的设定），韩立金刚诀肉身可用"以身为盾"承伤。
  - 新增"**血咒文书**"轻量契约系统：以限时效力任务（如 20 年/20 关）换取资源庇护，违约有惩罚。
- **奖励或技能绑定**：**金刚诀**与**淬骨诀**成为飞升后第一套可成长肉身功法；**灵界语言/图鉴**入库；旧宝物封存于沙漠地下，作为**后续回收任务**的钩子。
- **情感基调**：从"人界顶阶"跌回"灵界凡人"的落差感与陌生感——为后续"凡人再起"的全新篇章定调。
