- **对应原著**：seq 1771–1820（原章号同 seq，仅 seq 1776/1778 原文误标为 1756/1758）

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。本批对应韩立已入"合体初期"、主线压在"魔劫前夜"的中后期段落；剧情仍以「关卡之间的叙事插入 + 关卡目标绑定」挂在既有钩子上，每个单元对应一次触发。

### 单元 37-A《血魂与还鼎》（seq 1771–1775）｜触发：`enterMajor = 合体`、许家支线
- **叙事**：许家宗庙密殿、六角血池、冰魄血魂苏醒——一段"以血脉唤先祖"的仪式戏，收尾以韩立**主动归还虚天鼎**了结旧愿。
- **玩法**：做一场**仪式护法关**——玩家（韩立）需在大阵各阵眼按节奏注入灵力（对应游戏已有的"蓄能—释放"节奏条），法力不足时以第二元婴/豹麟兽"补位"，血魂凝躯进度条满即通关。
- **机制绑定**：新增"**心境/魔障**"轻量数值：还鼎后削减一层心障（表现为打坐收益小幅提升、或解锁一段心魔对话）。
- **奖励**：魔玉花（炼体/魔功增益材料）、血魂大法典籍条目（世界观图鉴）。
- **文案基调**：肃穆、宿命、释然。

### 单元 37-B《九仙山·万宝前奏》（seq 1776–1787）｜触发：`enterMajor = 合体` 后首次远行
- **叙事**：五年游历结识海大少、器灵子两个活宝；途中救人、遇圣皇车驾、识破冰髓之体、收下三名记名弟子、入住迎仙宫。
- **玩法**：把本段做成**多段并行支线**——
  1. **救人关**：荒山"南山三恶"事件，玩家先用"桃僵李代"式道具替身救人（潜入/救援小游戏），再与三恶对打（教学高阶战斗节奏）。
  2. **车驾演出**：天元圣皇车队过场，作为**全区服级"大人物巡游"视觉演出**。
  3. **收徒环节**：一个**选择式节点**（收/不收记名弟子），影响后续"弟子栏"开启。
- **技能/系统绑定**：开启"**记名弟子**"系统（海月天/器灵子/白果儿三位可培养位）；冰髓之体作为**长线支线钩子**（提示需要"冰属性"资源）。
- **奖励**：记名弟子位、炎阳玉、养精丹；首次获得"九仙山迎仙宫"安全屋（回血/整备点）。

### 单元 37-C《拍卖会·泣灵血木》（seq 1788–1801）｜触发：`合体` 段首个大会事件
- **叙事**：黑域交换会预告、天狐妖女与万骨的密谋、骖灵玄武巨城降临、万宝大会主拍场——以"竞拍"包装一次**群雄登场**。
- **玩法**：做一场**竞拍小游戏**（灵石竞价 + 出价时机博弈）：散场物包括炼器材料、压轴"泣灵血木"，玩家出价需在狼王化身与洞天鼠王的夹缝里捡漏（七千万封顶）。另做"骖灵降临"的**大地震演出**（镜头/震动反馈）。
- **机制绑定**：产出"**泣灵血木**"→ 可炼制**化劫傀儡**（一次性替死道具，对应游戏"复活/免伤印记"）。
- **奖励**：化劫傀儡、黑域大会牵引令（解锁隐藏会场）、红罗仙酒（可换资源的通货）。
- **伏笔**：陇家（真灵第一世家）作为本批**主要敌对势力**登场。

### 单元 37-D《陇家夺徒·巨猿战老祖》（seq 1802–1808）｜触发：单元 37-C 后、弟子被掳事件
- **叙事**：器灵子被掳、附心丝暗算、潜入陇家迎仙宫、以一化妖猿的身份大闹、与半龙化陇家老祖硬撼、全身而退——一次**"闯府救人"式高潮**。
- **玩法**：**潜入 + Boss 战**两段式——
  1. **潜入段**：破除空间禁制（对位小游戏：连线/消除银符文）、伪装妖猿避开守卫视野（潜行玩法）；
  2. **Boss 段**：巨猿形态对"半龙化陇家老祖"，主打**肉身对拼 + 短暂对轰**，血量归零不判负（剧情必退场），核心是演出"打不死的压迫感"。
- **机制绑定**：解锁"**化身/伪装**"玩法（惊蛰决·巨猿形态）；暴露"**圣岛**"设定（后续大版图钩子）。
- **奖励**：救回器灵子；二人转入"天渊城卫队"支线（离队打磨，后续回调）。

### 单元 37-E《黑域交换会》（seq 1809–1819）｜触发：持有牵引令、`合体` 段限时活动
- **叙事**：天狐秦氏姐妹、黛儿似曾相识的重逢、牵引使者引路、黑纱侍女、齐天锣现世、阴凤草换宝、孽云三换一——一段**群像式"黑市"戏**。
- **玩法**：把黑域做成一个**限时交换（以物换物）活动**——
  1. **入场**：持牵引令 + 随机入口 + 遮掩面目（匿名化）；
  2. **主会场**：以"自己手中的材料"换黑域压轴物（**齐天锣**：限次全队增益，用后敲者掉血；**奇宝胚胎**：未完成、长线培养）；
  3. **自由交换**：玩家间挂牌互换（可白嫖/被白嫖），埋点"金乌真火（稀释）""净明丹""孽云"等稀有件。
- **机制绑定**：**齐天锣** = 一次性全队修为增益（限 3 次）；**奇宝胚胎** = 超长线养成物；冰凤 = 灵兽/炉鼎位。
- **奖励**：齐天锣、奇宝胚胎、玄光刃换出的孽云 + 净明丹 + 金篆卷轴 + 冰凤。
- **触发钩子**：`持有牵引令` 且 `合体` 段，开放黑域隐藏地图；活动每日/每周一次。

### 单元 37-F《再见故人》（seq 1820）｜触发：单元 37-E 通关后
- **叙事**：放出冰笼中的冰凤，认出是当年同渡空间节点的"凤仙子"（人界冰海之主）；以真元解封、助其重化人形；故人相认、羁绊重启。
- **玩法**：一段**纯剧情 + 小交互**——用"注入真元"的蓄力操作替冰凤冲开体内封印（进度条 + 一次性判定）。
- **机制绑定**：冰凤加入随行位（灵兽/辅助），并绑定"人界旧识"图鉴条目。
- **情感基调**：怅然、温存，为后续"飞升/回人界"线埋线。
