## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。本批整体对应既有 `炼虚→合体→大乘` 阶段的**跨界面"夺宝—境主战"长线**。

### 单元 43-A《铁沙岭 · 青鸾真血》（seq 2071–2080）｜触发：`enterMajor = heti`（合体段开启）
- **叙事**：以"叶家少女求血"为引，把玩家从魔界荒漠带向铁沙岭的**潜行夺宝**支线，接一场"兽尊殿切磋"。
- **玩法**：分两段——① **兽尊殿拦路战**：一场"点到为止"的非致命斗法（对方兽化变身可作换形态的 Boss），胜后掉落**客卿邀请**与情报；② **熏香寨潜入**：新增"虚化符"潜行小游戏（时限内避开巡逻、触发搜魂线索、完成一次"得手即撤"的目标）。
- **奖励**：通关得**青鸾真血 ×1**，绑定"惊蛰诀·风系变身"——解锁控风位移/击退技，并令其他变身威能小幅提升。
- **触发钩子**：`bossDefeated: heti（兽尊殿长老）` 后开放"铁沙岭"潜入关。

### 单元 43-B《魔源海 · 苦灵岛雷海》（seq 2081–2085）｜触发：43-A 完成
- **叙事**：跨海远航 + 雷海闯关，营造"愈近目标、愈觉危机"的压迫感；途中以"黄金巨蟹"埋下大伏笔。
- **玩法**：做成**航行/护航关**——玩家操控灵舟顶住雷电洪流（躲避 + 消耗护罩），并限时识破"魔晶傀儡"伪装（侦察小游戏）。可选：狂化寒水犀、上古石傀儡两项**一次性道具**在此消耗。
- **奖励**：抵达灵岛，解锁新地图"苦灵岛"；回放剧情得**灵光回溯**（一次性情报技能，可揭示 Boss 弱点）。
- **触发钩子**：`mapUnlock: kuling`。

### 单元 43-C《洗灵池 · 三大始祖之战》（seq 2086–2100）｜触发：进入苦灵岛（**本批首个境主战**）
- **叙事**：全批最高潮。破禁 → 元魇始祖镇压 → 灵王分魂附傀儡自爆 → 宝花登场 → 涅槃圣体与玄天之剑亮相 → 以灵药换命。建议做成**多阶段长战**。
- **玩法**：**四阶段 Boss 战**——
  1. **破禁阶段**：三人合力攻无形禁制（蓄力打击）；
  2. **存活阶段**：对抗元魇的黑匕"黑丝"，比拼无敌帧与爆发窗口（对应替劫/金身保命）；
  3. **自爆阶段**：以"灵王分魂"剧情杀清场，玩家转为**躲避全屏自爆**；
  4. **谈判阶段**：战斗转为**交易对话/资源取舍**——以"灵药"为筹码换通行。
- **技能绑定**：解锁**涅槃圣体（二段变身）**与**玄天之剑（封印爆发）**两条终极技线；黄金巨蟹作为"可召唤援手"临时登场。
- **奖励**：得**天音雷核**、**太虚妙灵丹（虚灵丹）**等仙界灵药图鉴条目；世界观图鉴收录"陨界石""始印之地""魔界大劫"。
- **伏笔**：宝花所求灵药、涅盘圣祖与会伪造化露，均为后续"圣蟹反戈"与"蟹道人"埋线。

### 单元 43-D《洗灵池 · 脱胎换骨》（seq 2101–2105）｜触发：43-C 谈判达成
- **叙事**：安静而关键的"闭关蜕变"段——探池、采莲、洗髓，兑现"进阶大乘的一线机会"。
- **玩法**：做成**解谜 + 自动收益小关**：① 派傀儡下水探路（轻解谜）；② 潜入池底摘莲（路径/氧气压力）；③ **洗髓经易经**——限时"浸泡"事件，玩家需在"三日"限制内分配时间（采莲 / 吞虫吞噬 / 收水各占配额），到点自动传送离场。
- **机制绑定**：通关完成**属性洗髓**（肉身强度 +、骨骼紫金化 +、神念元婴壮大），并解锁**噬金虫群吞噬场**（可吞噬灵田换资源）。
- **奖励**：**净灵莲 ×1**、肉身/神念大幅成长；"神秘小瓶"（掌天瓶）**异动伏笔**——正式引出"双瓶"悬念。

### 单元 43-E《反戈 · 蟹道人》（seq 2106–2112）｜触发：43-D 完成
- **叙事**：从"脱身"到"灭仙令"追杀，是韩立由**弱者翻身成狠角**的转折段。
- **玩法**：① **脱身关卡**：以"临时分念"为赌注的**谈判小游戏**（真假难辨的心理博弈）；② **雷海截杀战**：金袍人（涅盘化身）+ 黄金巨蟹的组合战，玩家先挨一击（替劫判定），再以"绿液祭品"触发**反戈机制**——圣蟹转为友军，连击逼退敌手。
- **机制绑定**：获得**蟹道人**（高攻伪仙傫召唤/护道单位，可常驻出战），是后续开荒的核心战力。
- **场景**：灭仙令通缉（世界为敌）后转为"外紧内松"，新增**魔界城郊遭遇战**随机事件。
- **伏笔**：血光圣祖残尸（元婴被摄）指向"车骑恭、风邪"支线。

### 单元 43-F《蓝瀑湖 · 紫灵重逢》（seq 2113–2120）｜触发：43-E 完成
- **叙事**：以"收购血牙米/异魔金"串联蓝瀑湖市井线，末尾以"广源斋重逢紫灵"收束情感线，留下**六极圣祖**新钩子。
- **玩法**：① **玄天圣树演出**（宝花线过场，二魔祖围杀以剧情方式呈现）；② **蓝瀑湖经营/采集**——限购血牙米、大量收购异魔金（资源管理小玩法），异魔金可抽取"晶珠"强化修为；③ **广源斋考较**：一道"识破伪四象阵"的解谜，通关方可会见斋主。
- **奖励**：血牙米（肉身强化）、异魔金晶珠（快速增功）、广源斋声望与**跨界面商路**（可兑换仙界灵物线索）。
- **触发钩子**：紫灵登场 + "六极门下 · 备用化身"设定，开启下一批（seq 2121 起）**"紫灵之劫 / 血天大陆"**新篇章。
