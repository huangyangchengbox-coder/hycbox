## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。剧情以「关卡之间的叙事插入 + 关卡目标绑定」的方式挂在既有钩子上；每个单元对应一次触发。

### 单元 25-A《天南第一修士》（seq 1171–1176）｜触发：`enterMajor = yuanying（后期）`
- **叙事**：观礼大典 → 密殿一战传闻 → 至阳上人闭生死关；穿插"炼翅"的炼器日常。
- **玩法**：把大典做成一场**"灵压威慑"关**——不靠血条，长按蓄力释放元婴后期灵压，把镜头内所有逼近的敌修震退；胜利条件为"无人敢近身"。
- **机制绑定**：释放灵压消耗心神，蓄力越久范围越大，形成"以势压人"的国风演出。
- **奖励**：解锁**炼器系统**（风雷翅第一次强化）。
- **文案基调**：威势、克制。

### 单元 25-B《失落的第二元婴》（seq 1177–1184）｜触发：支线"三女失踪"（落云宗传讯）
- **叙事**：三女擅闯坠魔谷 → 被擒 → 血月觅灵 + 熔岩湖解救 → 赴万丈魔渊收婴。
- **玩法**：三段递进——
  1. **追踪关**（血月觅灵）：按指引穿越熔岩、冰缝与地下通道，限时定位目标；
  2. **解救关**：以紫罗极火潜行、辟邪神雷净化黑气、破迷幻法阵，救出三女；
  3. **收婴 Boss 战**：对半魔化的天煞魔尸——破"不灭之体"须用风雷翅瞬移绕后叠伤；其逃逸阶段触发"预设大阵封口"判定。
- **奖励/技能绑定**：**第二元婴**（可附身人形傀儡，成为可调度的"分身"单位）；**破灭法目**（看破幻术/削弱空间禁制）。
- **触发钩子**：`bossDefeated: 坠魔谷内谷 / 万丈魔渊`。

### 单元 25-C《化形雷劫》（seq 1185–1192）｜触发：进度"元婴后期稳固"且持有天澜圣兽
- **叙事**：安置门人 → 同化第二元婴 → 护送圣兽渡劫（连环天雷、独角蚯、取帝流浆）→ 以功法与宝物互市（化界珠 / 疾风九变 / 金刚决 / 帝流浆）。
- **玩法**：**守阵护送关**——玩家驻守外层，用银盾消减雷劫威力，内层圣兽自扛（消减过半、留小半给它自己接）；中段插入**变异独角蚯**野外 Boss（吸雷吸火 + 断体再生，需先用火索束缚再合剑斩之）；劫后接**"取液"限时小游戏**（容器在灵压中缓慢逼近月中圆月）。
- **奖励**：帝流浆（扩经脉、增体魄）、化界珠 + 疾风九变（位移/身法技能）、金刚决（炼体层数）。
- **触发钩子**：复用游戏既有的"天象/雷劫"通用事件（可让不同天象对应不同雷劫波数）。

### 单元 25-D《双修与暗谋》（seq 1193–1197）｜触发：韩立与南宫婉双修大典
- **叙事**：双修大典 → 鬼灵门求援献木灵珠 → 木生珠与合欢老魔暗算 → 二女旧识（董宣儿心魔线）。
- **玩法**：
  1. **声望/交易关**：收礼、决定是否替鬼灵门出面（多选项"代价"分支，可索取血肢丹/血魂镯/木灵珠）；
  2. **鉴定小游戏**：聚灵珠 → 木生珠的材料辨识与炼制；
  3. **心魔关**（董宣儿支线）：与"心魔韩立"对决或设法化解。
- **奖励/机制**：**木生珠**（一次性"不灭之体"保命技）；**木灵珠**设为"陷阱道具"——短期增益显著、长期提高突破瓶颈难度（对应原著弊处）。
- **触发钩子**：新支线"合欢宗暗算"，为后续"进阶受阻"埋雷。

### 单元 25-E《星宫之战》（seq 1198–1216）｜触发：万里符传讯（乱星海求助）
- **叙事**：星海之乱 → 闯风火天绝阵 → 圣殿谈判（索元磁神光）→ 暗杀旧仇立威 → 决战六道极圣（六极真魔功）→ 破阵决胜。
- **玩法**：**大型阵地战**，分三段——
  1. **破阵**：多段目标（清剿守柱小队 → 合剑成巨、劈断摩天巨柱），限时推进；
  2. **斩首 Boss**：六道极圣三阶段（附体双魔 → 魔器 + 四道魔影 → 三神白骨幡 + 五魔斗法）。核心机制为**识破分身**——用明清灵目/破灭法目标记真身，否则伤害全落到假身上；
  3. **大军割草**：逆星盟修士以波次呈现，噬金虫为清场 AOE，蓝氏双魔为"棘手的精英组合"。
- **奖励**：**五子同心魔**、黄沙须弥幡（瞬移古宝）、六道极圣遗留的魔道典籍。
- **触发钩子**：`bossDefeated: 境主战（万天明 / 六道极圣）`。

### 单元 25-F《元磁山·冲击化神》（seq 1217–1220）｜触发：星宫之战结束后
- **叙事**：探元磁山（五行之力）→ 识破"困地修功"的阳谋 → 定计赤魂幡 → 归天南闭关五十年 → 化神天兆。
- **玩法**：
  1. **互动谜题"收山"**：逐一尝试符篆、阵盘、强行灌注等收物之法，皆告失败，引导玩家自行悟出"须大威力空间宝物"；
  2. **炼器前置任务**：收集精魂与材料，为炼制赤魂幡做准备（可挂于后续批次）；
  3. **破境序章**：五十年时间跳过后，以"寒焰五魔"冲击化神瓶颈，触发化神天兆演出。
- **奖励/机制**：**元磁神光**功法（后续化神关键，附带"困守一地"的长期代价，做成可见的正面/负面双标签）、**赤魂幡炼制法**、**化神破境**入口。
- **触发钩子**：`enterMajor = huashen`，与下一批直接衔接。
