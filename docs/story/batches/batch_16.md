# 《凡人修仙传》章节梗概 × 游戏情节设计 · 第 16 批

- **对应原著**：seq 721–770（原章号 721–770，"慕兰入侵·黄龙山与边界大战篇"）
- **游戏映射**：`yuanying 元婴（初期）`，即**首个"以一敌众"的高阶修士段**

## 二、游戏情节设计（本批）

> 设计原则：**不推翻现有玩法**。本批以「大阵据守 + 十场囚笼赌战」为主线玩法改动，其余仍走"关卡之间叙事插入 + 关卡目标绑定"。

### 单元 16-A《令狐之邀·上古玉符》（seq 721–722）｜触发：`enterMajor = yuanying` 后首次入城
- **叙事**：旧门派的最后挽留与韩立的拒绝；末尾以三件重宝（蓝光盾、妖丹、上古玉符）收束，点到"玄化鬼手"的诡异。
- **玩法**：做一次**抉择对话**——回谷 或 婉拒并改换条件；分支只影响对白与最终到手的道具类型。
- **奖励/技能绑定**：**蓝光盾**做成可装备防具（对火属性伤害减伤）；**上古玉符**包装为一次性主动技"玄化鬼手"（抓取/缴械/定身）。
- **触发钩子**：`enterMajor: yuanying` 且首次进入阗天城。

### 单元 16-B《坠魔谷之约》（seq 723–724）｜触发：持有[两仪环·阴环]
- **叙事**：南陇侯与璇玑子道破两仪环与坠魔谷，抛出"火蟾古兽"这一难题，韩立以拖待变。
- **玩法**：**远期支线埋线**——本批只放"线索收集"三条（两仪环、入谷路线图、火蟾情报），不开启副本。
- **奖励**：图鉴入库"坠魔谷 / 北极元光 / 两仪环"；生成"延期承诺"任务标记，为后续批次留入口。
- **触发钩子**：获得指定道具后弹出预告式剧情层。

### 单元 16-C《黄龙山·千音幻化阵》（seq 725–743）｜触发：接取"驰援要地"任务
- **叙事**：支援 → 三场斗法（火灵化蛟／太玄八卦／天刹真魔功·附灵蛇怪）→ 破阵大战（雾海陷阱 ＋ 与乐上师、仲神师之战）。这是本批**最大的一段高潮**，建议做多波次结构。
- **玩法**：
  1. **斗法关（一对一）**——强调"属性克制换输出窗口"：辟邪神雷克魔功/邪修、乾蓝冰焰克火灵；
  2. **雾海陷阱关（阵法师视角）**——玩家操控禁制开关，诱导敌军深入，兼顾"不误伤己方修士"；
  3. **伪境主战（乐上师）**——"白莲＋青铜灯"双形态，主打"打不动、追不上"，必须靠**银月埋伏＋雷珠**才能破局；
  4. **不可战胜演出（仲神师）**——元婴后期登场，只走剧情，逼玩家用雷遁撤离。
- **技能/道具绑定**：解锁 **紫罗极火**（高阶冰焰，冻结）、**辟邪神雷**（克魔道/邪修）、**雷珠**（一次性破禁/破罩）、**噬金虫甲与虫云**。
- **奖励**：青竹蜂云剑强化素材（提前埋庚精线索）；银月好感提升，解锁其"潜行暗袭"指令。
- **触发钩子**：主线推进至"慕兰入侵"事件。

### 单元 16-D《名起与回归》（seq 744–748）｜触发：单元 16-C 通关
- **叙事**：血影遁逃出生天 → 半年服药闭关 → 回归落云宗 → "义妹"与双修之约 → 与天道盟谈条件。
- **玩法**：**声望系统**正式登场——"名声"变成可见数值，影响 NPC 称呼、任务开放度与商店折扣（用于换庚精的材料）。
- **机制绑定**：**血影遁**做成一次性高消耗逃生技（扣气血与元气、长冷却），呼应原著"以精血换命"。
- **奖励**：解锁落云宗据点（吕洛、红衫老者、宋姓女子）、天道盟议事殿任务线。
- **触发钩子**：重伤状态且被高境敌人神识锁定。

### 单元 16-E《庚精与赌战之约》（seq 749–760）｜触发：单元 16-D 完成、进入天一城
- **叙事**：紫灵的灵烛果/造化丹之约（远期支线）＋ 三大修士的十场生死赌战召集 ＋ 以妖材换庚精 ＋ 炼制降灵符。
- **玩法**：
  - **交易博弈**：与至阳、魏无涯做"材料对赌"，玩家可用稀有妖材（蛟鳞/龟壳）换庚精，也可"不给足就不接任务"；
  - **炼制小游戏**：降灵符炼制，失败会永久损失蛟魂魂力，最多三试，做成带惩罚的重复挑战；
  - **战前准备清单**：静室中备齐雷珠、降灵符与材料，备齐度影响下一单元的初始状态。
- **技能绑定**：解锁 **大庚剑阵**（远期）、**降灵符**（召唤毒蛟精魂一击）。
- **触发钩子**：`enterMajor: yuanying` 且完成天道盟条件任务。

### 单元 16-F《边界之战·血罗罩》（seq 761–770）｜触发：单元 16-E 完成后第七日
- **叙事**：赴营 → 敌我双方各自密谋 → 十场赌战被血罗罩反算 → 全面混战 → 韩立破罩、连救赌战修士，末遇锦袍大汉断章。
- **玩法**：
  - **十场赌战 = 囚笼关**：光罩即封闭战场，破局靠"道具解谜"（破禁珠先破、雷珠后成），而非硬打；
  - **混战 = 大规模战场事件**：以"战团"为单位的占点/护航目标，玩家不必全灭敌人，只需活着救出被困者；
- **奖励**：每救出一名赌战修士累积声望与后续盟约；雷珠熟练度提升。
- **触发钩子**：主线节点"七日决战"。
